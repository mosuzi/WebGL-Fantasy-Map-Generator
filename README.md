# FMG WebGL 地图生成器

这是一个面向世界构建者、TRPG 主持人、架空历史作者和地图爱好者的幻想地图生成器实验项目。它参考 [Azgaar/Fantasy-Map-Generator](https://github.com/Azgaar/Fantasy-Map-Generator) 的生成思想、数据结构和视觉表达，尝试用 WebGL 重新组织一次“山海初开”的过程：让地形、气候、河流、城镇、国家、文化、宗教、贸易和冲突在同一张可编辑的地图上生长出来。

我希望它最终不只是一个“生成一张图”的工具，而更像一张可反复进入的世界草稿。你可以先让程序给出大陆、山脉和诸侯，再沿着河流追踪城市为什么诞生，在资源和道路之间观察贸易如何变形，在文化、宗教和政治边界之间寻找故事的缝隙。地图不是背景板，而是世界设定本身的一部分。

## 为什么做这个项目

Azgaar 的 Fantasy Map Generator 已经证明了程序化幻想地图可以有多迷人：它把地形生成、政治边界、文化圈、河流、道路和标注组织成一个完整的创作系统。本项目从这份启发出发，探索另一个方向：

- 用 WebGL 承担大地图绘制和频繁视图切换，让画布更适合高密度编辑。
- 把地图对象尽量做成可追溯、可编辑、可导出再导入的数据，而不是一次性的渲染结果。
- 对中文世界构建更友好，逐步改善国家、城市、文化和宗教命名的中文语感。
- 为后续的贸易、军事、纹章、主题、测量、导入导出和叙事工具留下空间。

这不是对原项目的替代，而是一次带着敬意的重写和再想象。原项目像一座已经点亮的灯塔，本项目是在它照到的海面上继续试航。

## 现在可以做什么

当前版本已经可以生成并浏览一张 WebGL 幻想地图，支持高度、气候、河流、国家、省份、文化、宗教、城市、道路、资源点、贸易、外交和静态军事等基础数据。你可以切换专题视图，通过浮动面板选择、定位、创建、删除或编辑地图对象，也可以使用公开 API、快捷键、完整地图往返、PNG 裁剪和分层 GeoJSON 完成自动化与外部交换。

项目仍处在活跃开发期：现有能力已经形成可回归的产品骨架，但还没有到“最终产品”的稳定程度。下一步以[权威任务清单](./docs/current-plan.md#权威任务清单)为准，不从 README 的概览文字自动推导施工范围。

## 已经完成

- WebGL 地图主视图：支持地形、政治、政体、文化、宗教、外交、道路、河流、城市、资源点、军事等专题视图切换。
- 独立生成链路：地形、气候、水文、城市、国家、省份、文化、宗教、经济、贸易、外交和军事数据已经接入同一张地图。
- 对象管理面板：国家、政体、省份、城市、文化、宗教、河流、湖泊、路线、资源标记、外交、军事、名称库和备注等都有独立浮动面板。
- 轻量编辑能力：可以调整部分对象名称、颜色、政体（含分组批量套用）、首都、城市剪影、资源点、外交关系、军事态势、驻地/基地、兵种比例和高度编辑笔刷；国家、城市、河流和湖泊可按当前名称库对筛选结果执行显式重命名，选中的国家/城市标签、河流和湖泊也可只重命名对应目标并撤销。
- 经济与贸易：经济总览可查看商品、市场、交易、运距成本、供需缺口和静态价格传播信号，资源货物会影响适居度、城镇选址与静态路线权重；支持当前筛选结果 CSV/JSON 导出，地图可开启带价格信号的静态贸易流图层并查看贸易线详情。
- 军事战报档案：军事面板支持战报记录、导入、筛选、清理、展开链路、只读摘要，以及按范围导出 CSV/JSON；后续不再扩展动态战争系统。
- 高度图导入工作台：支持灰度和彩色色板导入、自动映射、手动赋高、profile 导入导出、待处理颜色审核、分页和批量加入。
- 导出能力：PNG 支持 1x～4x、当前视口/地图全幅/像素矩形/世界坐标裁剪和细粒度 overlay；完整地图 JSON/gzip 支持迁移往返；pack 与分层 GeoJSON 支持全图、当前视口和显式世界坐标 bbox，政治面支持 dissolve，并通过 100k Chrome、QGIS 和 geojson.io 验证。
- 自动化能力：`window.webglGeneratorApi` 已覆盖 11 个命名空间、186 个公开方法和 90 个编辑方法；常用操作已有统一快捷键、禁用条件和悬停提示。
- 编辑基础设施：统一 EditHistory、selection、定位/高亮、画布工具模式、删除预检、批量事务和派生刷新已经落地；路线、河流、湖泊、地区、通用标记和独立备注具备创建闭环。
- 运行时体验：生成与 WebGL 装载已有性能守门，首屏加载、面板懒加载、健康监测和本地 profiling 工具已经建立。
- 中文命名优化：国家、城市、文化、宗教等名称逐步向中文语感收敛，国家方位前缀会按同根国家相对位置校正。

## 本地运行

```powershell
pnpm install
pnpm run dev
```

默认开发服务器地址：

```text
http://127.0.0.1:5410
```

需要查看生成耗时、WebGL 统计和内部状态时，可以打开开发模式：

```text
http://127.0.0.1:5410/?debug=1
```

常用检查命令：

```powershell
pnpm run build
pnpm run profile:e2e -- --browser-channel chrome
pnpm run regress:rendering
```
