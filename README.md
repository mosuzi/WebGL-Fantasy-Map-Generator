# WebGL 幻想地图生成器

WebGL 幻想地图生成器适合世界构建、TRPG 主持、架空历史创作，也适合单纯喜欢地图的人。项目借鉴 [Fantasy Map Generator](https://github.com/Azgaar/Fantasy-Map-Generator) 生成和呈现世界的思路与视觉风格，应用本身从头独立开发。打开页面即可生成一幅完整地图，之后还可以继续查看、推演和修改其中的世界。

[在线体验](https://fmg.mosuzi.top/) · [快速开始](#快速开始) · [文档导览](#文档导览)

## 从地貌到人文

新地图先确定自然环境。陆地与海洋构成轮廓，气候、水文和地貌再影响河流与生物群系的分布。生成时不必预先规定每个细节。完成后，专题视图可以帮助了解这些要素之间的关系。

随后加入人文内容。聚落多出现在适居之地，道路把它们连接起来。国家和省份划出行政范围，文化与宗教形成各自的分布，经济、贸易、外交和军事则呈现各方如何往来与冲突。这些内容会互相牵动，查看或调整时可以放在一起比较。

完整介绍见[功能与领域总览](./docs/wiki/功能与领域总览.md)。

## 查看、编辑和保存

生成完成后，可以在地图和管理界面之间切换，查看专题信息，选中并定位地点或对象，再按需要调整局部内容。编辑操作有明确的作用范围。常用修改会进入撤销与重做历史；可能牵动其它内容的操作会先列出影响和确认条件，明确锁定的对象也会得到保护。

需要暂停工作或保留一个版本时，可以保存完整地图，日后接着编辑；也可以根据用途导出图片、地理数据或其它结果。旧地图有版本化迁移和兼容路径，但历史文件不保证全部无损转换。重要存档应保留原件，迁移后另存新版。编辑原则和格式细节分别见[编辑器与安全修改](./docs/wiki/编辑器与安全修改.md)、[存档与导入导出](./docs/wiki/存档与导入导出.md)和[旧图兼容](./docs/wiki/旧图兼容.md)。

## API 与自动化

项目也支持用脚本或 AI 工具处理地图，并提供了几种受控入口。页面内的 `window.webglGeneratorApi` 可读取地图、查找对象、进行分析和调用受控编辑。处理本地存档时，无头只读入口无需打开浏览器，适合批量查询和区域分析；确需修改文件时，独立的无头写入入口只开放经过约束的动作，并默认写入新文件，保留原存档。

AI 操作当前标签页前，须由用户在页面中明确开启受控桥。该桥默认只读，授权状态始终可见。高影响修改仍需经过预检、显式确认、版本检查和事务回滚，受控桥不提供任意脚本执行，也不能绕过地图自身的编辑规则。

README 只说明各入口的用途。精确方法、输入格式和安全边界见 [API 与自动化](./docs/wiki/API与自动化.md)；让 AI 接手地图的步骤见 [AI 接手入口](./docs/ai/README.md)。

## 快速开始

本地开发需要 Node.js `^20.19.0` 或 `>=22.12.0`、pnpm 10，以及支持 WebGL2 的现代浏览器。

```powershell
pnpm install
pnpm run dev
```

开发服务默认运行在 <http://127.0.0.1:5410>。需要生产构建时，运行：

```powershell
pnpm run build
```

完整步骤见[安装与快速开始](./docs/wiki/安装与快速开始.md)。不想在本地安装，也可以直接打开[在线版本](https://fmg.mosuzi.top/)。
