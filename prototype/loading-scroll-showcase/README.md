# 古代画卷加载页文字视觉深化概念稿

这是正式应用加载页的独立评审原型，只用于确认画卷材质、文字层次和动效方向；当前采用无高光的古朴古画风格，整张旧纸在左右两侧自行卷成厚纸筒，中央保留上下不齐的毛边，以哑光浓墨、干笔斑驳和旧纸污斑为主。卷面不再放“小字莫苏子”款识，品牌印面直接采用用户最终指定的 `莫苏子印3.png`：原图红色区域转换为暗朱印泥，黑色区域镂空并透出旧纸，终态保持轻微左倾。用户明确认可前，不会移植到正式 `app/webgl-generator/index.html`，页面内的定时演示也不会进入真实加载生命周期。

## 运行

```powershell
pnpm run start:loading-scroll-showcase
```

打开 `http://127.0.0.1:5402/`。

Vercel 统一构建后可通过 `/prototype/loading-scroll-showcase/` 访问。

## 评审操作

- “重新展开”：重播纸面、双轴、题字、墨线和落印时间线。
- “下一文案”：依次预览启封舆图、辨读旧卷、铺陈山川、点定郡国和山河成卷。
- “错误态”：预览旧卷未能辨读时的高对比提示。
- “静态终态”：关闭概念页动态效果，直接查看完整展开状态。

## 验证

```powershell
pnpm run regress:loading-scroll-showcase
```

原型只引用仓库内的本地印面图片，不依赖网络字体、外部图片或其它远程资源，并为窄屏与 `prefers-reduced-motion` 提供独立布局和终态规则。
