## 2. 搜索的现状与设计

[对象查询](../../app/webgl-generator/src/runtime/object-query-api.js) 已登记 20 类对象、字段白名单与分页，单页默认 50、上限 200。当前文本匹配只组合 name / text / label / type / kind，不代表白名单字段都可搜索；尤其备注 body、部分完整名称和关系端点需要专门补齐。NOTE 枚举目前只接收独立备注，绑定备注与孤儿备注不能假定已经覆盖。

**统一入口。** 在正式主界面提供带可识别搜索标识的入口，打开搜索框和分类型结果。空关键词显示输入提示，不一次性列出全图；类型筛选可用，名称、全名、标签文字、备注标题 / 正文及已定义可见说明可检索。快捷键若添加，须先核对现有键位并避开输入法和文本编辑。

**对象覆盖。** 按当前对象类型逐项核验：国家、省份、城市、文化、宗教、河流、湖泊、地貌、道路、洋流、地区、区域、市场、贸易流、军团、外交关系、标记、标签、测量、独立备注；资源点归标记，绑定 / 孤儿备注单独补文字来源与稳定身份。无自有名称的道路、贸易、外交使用已有端点、商品或参与方显示名；不扫描地形数组、错误栈或其它内部字段。

**结果与排序。** 名称精确 → 名称前缀 → 名称包含 → 正文或说明命中，次序稳定；全文命中显示短摘要。对全体候选排序后再分页，不能先截出 50 个再声称按相关性排序。结果键由地图身份、对象类型和稳定 ID / 备注键构成；同名、同 ID 跨类型和合法 0 均正确。

**查看与定位。** 先能查看详情，有位置才显示定位动作；孤儿备注保留可读正文和无位置说明，绑定备注定位到有效所属对象。湖泊 / 地貌等重叠语义来源明确，避免把同一引用重复索引成无法分辨的结果。隐藏内容仍可搜索，临时定位提示不永久打开图层或修改原样式。

**一致性与性能。** 索引只保留必要文字与引用，不复制点列和格子数组；编辑、重生成、撤销重做和整图替换后失效或按写集更新。输入法组合期间不触发选择；旧异步结果不覆盖新查询。长正文按纯文本显示；地图只读，revision / 历史不变。用多类型、小图与代表性 100k 证明输入响应、全局排序和分页完整性。

## 4. 五项精简规范

### 图标按钮

现有 [锁定工具条](../../app/webgl-generator/src/ui/vue/components/base/UiRegenerationLockActions.vue) 已提供图标、中文 title、aria-label 和 pressed 状态，可作为统一模式；[UiButton](../../app/webgl-generator/src/ui/vue/components/base/UiButton.vue) 复用现有组件库，不另外引库。

定位、显隐、锁定等优先使用一致图标；歧义动作保留图文。破坏性操作在确认时始终显示动作与作用对象；不能只靠红色区分。图标必须提供键盘焦点、中文可访问名称、鼠标 / 焦点可见提示、禁用与忙碌状态；触屏无悬停时也能理解。缩短标签不等于缩小命中区。

### 操作聚合

复用 [UiActionDock](../../app/webgl-generator/src/ui/vue/components/base/UiActionDock.vue)、UiPanelIoActions、UiSegmented 等既有组织方式。选择类、对象操作、列表操作、导入导出分别成组；互斥模式用选中态组，独立动作保持各自按钮。批量锁定与当前对象锁定作用范围不同，不因名字相近混成一个无范围按钮。高频动作保持直接可达，低频动作可收在单层“更多”中。

### 尺寸与间距

先统一少量尺寸档位：以现有 30～32px 紧凑控件为对照，行内约 6～8px、组间约 12～16px 作为设计起点，经真实内容调整，不是所有元素强制同宽同高。输入框、单位、颜色、按钮按内容设置最小宽度和弹性；长名称可省略但完整内容须可查看，编辑值不可被不可见裁剪。

检查长中文、负数 / 大数、单位、无对象、多选计数、错误和进行中文案；工具组合理换行，必要表格在容器内部滚动，避免整个面板横溢。窗口较窄或缩放后操作仍可达，不靠极小字体挤入。共用壳的拖动、尺寸保存与回到屏幕范围保持。

### 冗余操作

建立“旧入口 → 保留入口 → 相同回调与作用范围”的对应表，只有等价重复入口才可合并。既有标题栏撤销 / 重做不在内容区再堆大按钮；高度笔刷自身历史与全局历史区别保留。删除、清空、重置、重生成不是同一种动作，不能为了少按钮合并语义。保留取消、应用、定位和必要失败反馈，不把隐藏功能算作精简成果。

### 明亮主题

[现行样式](../../app/webgl-generator/src/styles.css) 根节点设 dark color-scheme、Element Plus 暗色变量，浮动面板还有直接暗色背景。需要统一面板背景、字段、表格、边框、阴影和文字的浅色语义，并覆盖 hover / active / focus / disabled / busy / warning / error。

菜单、下拉、颜色选择器和确认对话框可能挂在面板外，需沿弹层作用域获得同一明亮主题；不能只改浮动面板背景后留下暗色下拉。保持清晰文字与焦点对比，不将选中和错误状态变成浅底白字。界面颜色独立于地图 theme，地图、背景、标签实际配色、旧档内容和导出保持原值。不新增双主题偏好、自动跟随系统或地图配色重做。

## 5. 分阶段实施与验收

使用 run-lean-staged-delivery，由主线程唯一写入；第 396 项在同一独立分支内分阶段，不为每个面板重启流程。

1. 冻结实际面板 / 动作清单及旧新映射，核对共用控件、样式和弹层作用域，留原视觉基线。
2. 用城市和道路面板验证图标 / 按钮组、字段尺寸、明亮主题、空态和失败状态；同时验证共用壳与外置下拉，接受后固定规范。
3. 按第 3 节分组推广，每组核对全部动作可达和交互隔离；阶段验收后保存 checkpoint 与精简交接，不扩大业务范围。
4. 冻结后完成全清单外观检查与代表性操作链：桌面、690px 视口、200% 浏览器缩放，单独覆盖长文、各状态、键盘、焦点、取消及撤销重做。小图 / 100k、目标错误、性能与既有交互审计通过。

静态检查和专项先行；真实浏览器与视觉验收必须后续实际执行，截图本身不能替代操作。搜索的排序 / 索引专项与 UI 重构验收分开，第 396 项接入搜索外观但不重写搜索语义。用户已有地图须按精确标签页接管规则处理。
