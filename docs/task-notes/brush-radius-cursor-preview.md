# 画笔大小与光标影响范围预览

本文记录权威任务第 68 项的统一交互语义、覆盖矩阵和验收边界。活动状态与执行顺序仍以 [`../current-plan.md`](../current-plan.md#权威任务清单) 为准。

## 已确认的现状

- 高度、国家、省份、文化、宗教和生物群系笔刷常见默认世界半径为 `28`，经济市场归属默认半径为 `18`；各自面板已有不同命名和位置的滑块。
- 国家、省份和社会归属运行时直接比较 cell 中心与 `screenToWorld()` 光标圆心的距离平方；高度、生物群系和经济也分别使用自己的世界半径命中路径。
- 画布当前没有共享笔刷光标或半径轮廓。用户只能在已经产生预览变化后反推范围，落笔前无法判断影响面积。
- 因此本项不是只补一个新的半径字段，而是让既有半径控制可发现，并让视觉轮廓与真正的命中半径使用同一事实来源。

## 覆盖矩阵

下列连续圆形工具纳入统一治理：

- 高度抬升、降低、平滑、整平和扰动等普通半径笔刷。
- 国家与省份归属笔刷。
- 文化与宗教归属笔刷。
- 生物群系归属和经济市场归属笔刷。
- 高度选区的画笔拖选。

下列工具不显示圆形半径轮廓：

- 高度 Fill、线段、矩形框选和连通等高区单点选择。
- 城市 / 国家 / 省份等单点新增、删除或拾取模式。
- 湖岸修正、Zone 扩展等按图邻接圈数而不是世界距离命中的操作。
- 路线、河流、测量等折线节点编辑。

## 统一交互规则

1. 启用连续圆形画笔后，所属面板必须直接显示大小控制和当前值；不要求用户从隐蔽高级区推断默认半径。
2. 光标进入画布即显示非阻塞范围轮廓，不必先按下鼠标；拖动期间轮廓持续跟随，且不能截获画布事件。
3. 光标轮廓与命中算法读取同一个世界半径；相机缩放、适配视图和高 DPI 只改变投影后的屏幕尺寸，不能改变世界影响范围。
4. 陆地 / 水域、同国家、目标归属等领域过滤只决定圈内哪些 cells 可变，不改变外圈的几何含义。
5. 退出工具、离开画布、取消 stroke、关闭面板、切换地图或进入不使用圆形半径的动作时立即清理轮廓。
6. 悬停轮廓是纯 UI 反馈，不修改地图、selection、预览数据或历史；拖动仍沿用各领域既有预览、提交和回滚语义。

## 最小验收

- 覆盖矩阵中的每一种连续圆形画笔都有可见大小控制、当前值和统一的有限状态读取；最小、中间、最大三档的实际候选数在固定地图和固定圆心下单调不减。
- 适配视图和至少两个放大级别下，用 renderer 把世界圆心与半径边界点投影到屏幕，所得距离与轮廓半径误差不超过 `2px`。
- 实际变化 cell 的中心不得落在轮廓外；圈内 cell 可以因陆水、政治归属或目标相同等领域约束不变化。
- 悬停未落笔不改变地图 checksum 或历史；拖动中轮廓跟手，抬手后的命令数仍遵守各领域原有约束。
- 退出、取消、离开画布、关闭面板和切图后轮廓消失；所有排除工具均不出现圆形笔刷轮廓。
- 专项回归覆盖半径归一、工具覆盖矩阵、世界到屏幕投影和清理生命周期；相关画布模式与领域笔刷回归、生产构建和 `git diff --check` 通过。
- 同一 Chrome 中集中验证高度、国家、省份和至少一种文化 / 宗教 / 生物群系 / 经济笔刷的大小调节、未落笔悬停、连续拖动及缩放反馈。

## 明确不做

- 不新增画笔形状、硬度、纹理、压感、倾斜或吸附系统。
- 不改变地图数据格式、归属业务规则、历史命令结构或笔刷提交 / 取消语义。
- 不把按邻接步数、折线或单点命中的工具伪装成世界圆形笔刷。
