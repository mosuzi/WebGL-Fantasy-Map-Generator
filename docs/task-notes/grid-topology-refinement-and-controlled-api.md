# 现有地图网格拓扑细分与受控 API

本文冻结权威任务第 298 项的施工边界。目标是在当前地图对象上完成拓扑保持式细分，不调用 `generate.newMap`，也不以相同种子重生成替代现有地图迁移。

## 结构契约

- 受控快照版本固定为 `webgl-grid-structure@1`，只返回克隆后的 `points / boundary / cells.i / c / v / p / h / vertices`，不得暴露运行时数组引用。
- 快照绑定当前 `mapIdentity + mapRevision + sourceFingerprint`；写入前必须校验绑定、schema、长度、索引范围、邻接对称性、cell 多边形与顶点引用。
- `cells.p` 继续表示 grid point 索引，不得复用为母子映射。母 cell、子 cell 与来源指纹写入独立 `grid.refinement` 元数据。
- 公开入口分为摘要、快照、写入预检、事务写入、细分预检和事务细分。写入与细分都要求显式确认及最新预检令牌。
- `?debug=1` 的开发模式面板提供可见的两步式细分入口，仅负责调用同一 `grid.inspectRefinement → grid.refine` 契约，便于在受浏览器隔离保护的现有标签页验收；不增加第二套写入实现。

## 细分算法

- 保留全部旧点和旧 Grid Cell 编号，新点只追加；每个新点必须位于母 cell 的旧 Voronoi 多边形内。
- 新高度由母 cell 与原邻接闭包约束插值；旧 cell 高度逐项不变，新 cell 不得跨越母 cell 的海陆符号。
- 新邻接只允许发生在同一母 cell 或原邻接母 cell 之间；生成后再次全量审计，违反即拒绝写入。
- 人口等加总字段按母 cell 子项数分摊，分类语义由母 cell 继承；feature 与 pack 按新拓扑重建。
- 城市、Marker、国家 / 省份中心继续使用保留的旧 grid cell，并更新 pack 映射；河流与道路在相邻母 cell 的子图内补全路径；地区等 pack cell 集合按 grid 映射迁移。

## 事务与兼容

- 细分构造和校验在提交前完成；正式写入使用完整地图快照命令，失败恢复地图与历史。
- 撤销 / 重做必须重新装载完整渲染拓扑、对象拾取索引与面板状态。
- 旧存档没有 `grid.refinement` 时视为未细分地图；保存格式不强制迁移，新增元数据按现有对象序列化链自然保存。

## 验收门禁

- 固定约 10k 夹具扩展到约 100k，检查点数、母子覆盖、邻接闭包、海陆连通分量、旧高度、分位数、河流 / 道路骨架和对象引用。
- 覆盖错误 schema、过期版本、非法索引、非对称邻接、跨母 cell 邻接和故障注入回滚。
- 覆盖事务写入、撤销 / 重做、保存再读取、API 能力发现、生产构建和用户现有 Chrome 页面真实细分。
- 单列构造耗时、渲染重载耗时、峰值结构规模与 100k 页面四类错误。
