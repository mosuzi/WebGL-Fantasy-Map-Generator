# 第 425 项：国家政体弹框层级修复

## 范围与冻结验收

本项处理国家编辑的“调整政体”二级弹框被国家面板盖住，以及同一共享层级机制涉及的其它动作栏弹框。目标是连续切换二级动作、点击父面板、打开政体下拉候选和长会话反复激活后，顶层内容仍能看见、点击与按 Esc 关闭；不改变政体数据或第 402 项其它界面范围。主线程为唯一写者，独立调查只读。首个目标门为正式浏览器中颜色→政体切换的层级和命中点检查。

## 首败与调整

1. 当前 `0.5.145` 正式构建的浏览器夹具：国家编辑打开颜色后直接点政体，政体弹框仍标记 `overlayOpen=true`，但国家面板 `z-index=903`、弹框 `902`；两者重叠处 `elementFromPoint` 命中国家面板，弹框不可点。原因是主面板在 `pointerdown` 升层并阻断冒泡；共用弹框的托管监听只观察布尔“是否打开”，颜色切到政体没有重新激活，外点关闭监听也收不到父面板的点击。下一次只做共享层级和事件链修复：托管层在动作键变化时重新置顶，父面板升层时让已打开的高级浮层保持上层，层级计数有界；在捕获阶段处理二级框外点。目标复验同一颜色→政体真实点击、重叠命中、父面板外点关闭和政体候选可点击。
2. 静态首验误调用不存在的 `regress:panel-overlays` 脚本，产品构建和 diff 检查已通过；这是命令名错误，没有产生产品失败。改用仓库实际的 `tools/webgl-generator-panel-overlay-policy-regression.mjs` 直接跑层级专项，再执行浏览器目标复验，不重复构建。
3. 颜色→政体及下拉候选目标复验通过：国家面板 `903`、政体框 `905`，重叠点命中政体框；候选 `2017` 高于两者。扩展长会话夹具却把 `700` 次合成 `pointerdown` 放在同一个 `evaluate` 调用内，自己制造 `2408ms` LongTask，触发硬门。原因是测试模拟方式不符合逐次玩家点击。调整为每帧至多 `10` 次，并继续把压力阶段纳入观察；目标复验实际打开、候选点击和总观察窗均无 `>200ms` 长任务。
4. 分帧压力复验通过：`700` 次激活后国家面板 / 二级框为 `1011 / 1012`，政体候选 `2020`，最长 LongTask `108ms`、页面错误 `0`。集成复核提出父面板输入夺焦风险，真实点击筛选框后弹框已关闭且输入保有焦点；随后新增的单次 Esc 断言等待二级框关闭超时，实际原因是候选仍展开时第一下 Esc 留给了候选。调整夹具为先验证“第一次收候选、第二次收二级框”，并在另一轮直接点击候选以覆盖鼠标选择；同时给 `108ms` 长任务补阶段时间戳，确认是否由压力夹具产生。
5. 补完鼠标候选、两次 Esc 与焦点后，小图完整专项通过；阶段计时把 `97 / 67ms` 长任务定位在夹具的 `state-opening`，即同一同步调用内先开国家面板再改目标，二级弹框入口本身没有该长任务。将夹具改为先设目标再打开面板，模拟已选中国家的真实入口并避免一次任务内双重刷新；目标复验继续观察完整窗口的长任务、层级与点击。
6. 调整入口顺序后的目标复验仍有国家面板首次装载 `101 / 65ms` 两条 LongTask，颜色、政体、下拉、关闭和压力阶段均无新增 `>50ms` 任务；该次调整未消除此已有首开代价。按门禁记录精确入口、数量及上限，未超过 `200ms`，继续代表性大图层级验收；不把首次面板装载时间归给二级弹框。

## 最终结果

共享 `OverlayRegistry` 在父面板激活时把打开的高级浮层重新置顶，并在层级增长到 `1500` 前重基；共用 `UiActionDock` 在颜色、政体等动作键切换时重新登记二级框，捕获外点以避免父面板阻断冒泡。未改变政体数据或存档。

`0.5.146` 正式浏览器小图 / 十万格均通过颜色→政体、重叠处 `elementFromPoint`、下拉候选真实选择、点击主面板关闭、筛选框保焦、候选与弹框两级 Esc，以及 700 次分帧激活后的层级与候选可达性。修后首次切换国家面板 / 弹框 `903 / 905`；压力后 `1014 / 1015`，政体候选 `2022`。最长 LongTask 小图 `102ms`、十万格 `77ms`，页面错误均为 `0`。目标弹框阶段未见 `>50ms` 长任务；首开国家面板的两条残余任务已按上述失败与调整记录归因。截图存于 `Z:\tmp\codex\2026-11-17\secondary-overlay-layer\task-425-government-popup.png`。

共享层级、地图悬浮信息与动作 Dock Node 专项、既有桌面 / 窄屏浮层浏览器回归、核心类型、`1440` 模块构建、`709` 状态排版均通过；`impeccable detect` 对本项改动返回空数组。独立复核指出的筛选框夺焦疑虑由真实浏览器断言排除。其额外运行的 `responsive-focus-overlay` 旧断言仍停在此前已记录的国家字段计数 `12/10`，`state-government-panel-width` 旧断言仍引用第 424 项之前的固定默认宽度；两者均未改本项产品逻辑，也不计作本项通过。

独立最终验收结论为 `ACCEPT`，P0 / P1 / P2 阻断均为 `0`。
