# 高复杂度面板首层与高级区分层

本文记录权威任务第 58 项对高度、军事和导出面板的能力盘点与分层边界。当前批准范围和完成状态统一查看 [`../current-plan.md`](../current-plan.md#权威任务清单)。

## 分层原则

- 首次打开只呈现高频、低理解成本、能直接完成主要工作流的能力。
- 高级能力保留原入口与语义，通过默认折叠的原生 `details` 区域继续可达。
- 本次只调整信息层级，不改编辑命令、导入导出、撤销历史或公开 API 的行为。

## 能力盘点

| 面板 | 首层能力 | 高级区能力 | 默认状态 |
|---|---|---|---|
| 高度 | 启停编辑、笔刷动作、作用范围、全局微调、高度图导入 | 选区地形模板、多步骤程序、条件变换、模板库与 GPU 预览统计 | 高级区折叠 |
| 军事 | 国家/态势筛选、军团列表、定位、基础态势、兵种比例、军事导出、重新生成 | 战报档案、链路与结果筛选、战报编辑、轻量结算 | 高级区折叠 |
| 导出 | 一步导出 PNG、一步导出地图 JSON | 压缩 JSON、地图/要素 GeoJSON、PNG 倍率与裁剪、overlay 白名单、要素图层选择 | 高级区折叠 |

## 交互约束

- 高级区标题必须能说明内部能力，折叠时不能遮断首层主路径。
- 高度图导入属于常用输入路径，保留在高度首层。
- 军事重生成属于领域主动作，保留在军事首层并继续走共享重生成动作。
- PNG 与地图 JSON 保持单击即导出；其格式参数和低频格式进入高级区。
- 关闭按钮继续使用统一的 `×` 图标与可访问名称。

## 验收覆盖

- `pnpm run regress:complex-panel-layers`：检查三类能力分区、默认折叠和共享样式。
- `pnpm run regress:height-template-programs`、`pnpm run regress:height-brush`：确认高度编辑与模板语义不变。
- `pnpm run regress:military-regeneration`：确认军事重生成、镜像同步和扰动语义不变。
- `pnpm run regress:png-options`：确认 PNG 选项与 UI/API 接线不变。
- `pnpm run regress:complex-panel-layers-browser`：在真实构建产物上检查高度、军事、导出三条路径的首层可见性、默认折叠与高级能力可达性。
