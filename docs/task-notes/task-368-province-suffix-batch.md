# 第 368 项：显式批量调整辖下省份后缀

## 冻结产品契约

- 用户从国家管理界面显式触发“调整辖下省份后缀”；修改国家政体本身不触发该操作。
- 作用域固定为当前国家辖下全部有效省份，不重新生成省份，也不改变边界、国家归属、中心格、省会、颜色、城市、路线或稳定 ID。
- 可选值复用既有省份后缀词表；初始建议值复用当前国家文化的既有命名策略，不引入政体到省份后缀的新映射。
- 默认安全模式只改写标准全名：旧 `fullName` 缺失，或严格等于旧 `name + formName`。其余全名视为手工定制并跳过。
- 只有用户显式启用“覆盖定制全名”后，才把定制全名一并改写为 `name + 新后缀`。
- 一次确认是一个历史事务；`politics.provinces` 与 `pack.provinces` 同步提交，撤销 / 重做按 before-image 精确恢复。
- 结果区分 `changed / unchanged / skippedCustom`；没有字段发生变化时成功 no-op，不新增历史。
- 省份公开读取返回 `formName` 与 `fullName`；不开放绕过事务的新写入口。

## 非目标

- 不把国家政体变化与省份名称建立自动联动。
- 不增加按单个省份、筛选集合或跨国家批量调整。
- 不重构省份命名生成器，不改写省份基础名，不修改 `source/`。
- 不调查、引入或评估 GPU.js。
