| 当前阶段 | 已完成并归档 |

## 用户语义

- “重新生成”不是修补旧目标，也不是尽量保留旧布局；它等价于先把目标范围内未锁定数据视为不存在，再按当前上游数据生成。
- 只有用户明确锁定的对象可以跨重算保持对象内容；局部重算的范围外对象属于非目标，不参与删除。
- 数字 ID 可以作为新数组槽位重新分配，但旧对象不得因 ID、名称、位置、首都、省会或其它角色而被隐式复制回结果。
- 连续两次重算必须消费不同扰动序号；在存在可选空间时，未锁定结果的空间或属性指纹必须发生实质变化。

## 已确认根因

- 全图城镇重算 `rebuildPackSettlementsWithAnchors` 读取旧 `state.capital`、`province.burg`、旧城名和旧中心，先复建旧首都/省会，再只生成普通城镇。
- 局部城镇重算 `rebuildPackSettlementsInScope` 克隆完整旧城市与 burg 表，排除首都和省会，只替换普通城镇，并复用原 city / burg ID。
- 这使第 343、344 项虽然消除了拒绝和回滚，仍未满足用户对“重新生成”的产品定义；旧错误海中城镇可能通过行政锚点继续存活。

## 冻结实现边界

1. 城镇全图重算从显式锁快照起步，不读取其它旧城镇对象；从当前陆地 pack cells 选址后再选国家首都和省会，并同步 politics / pack / city / burg 镜像。
2. 城镇局部重算只保留范围外对象与范围内显式锁；范围内所有其它行政角色也先删除、后从新候选重选。
3. 新建与锁定城镇均通过陆水约束检查；未锁定新城镇的 `pack.cells.h[cell] >= 20`，港口只改变港口连接，不改变城市陆地锚点。
4. 逐类审计其余十个入口是否读取旧目标作为默认输入；锁快照参数允许，非锁的 `preserved*`、旧名称/位置/身份锚点不允许。
5. 失败不提交，成功单历史/单 revision；撤销精确恢复重算前存档。

## 验收指标

- 当前用户存档记录重算前城镇数、海中城镇数、未锁定身份/空间指纹、锁数量；第一次和第二次重算分别记录相同指标。
- 两次成功结果海中未锁定城镇均为 `0`；目标范围内旧对象没有被直接复制，新旧空间/属性指纹存在实质变化，第二次结果也不同于第一次。
- 显式锁对象深值不变；局部范围外对象深值不变；行政镜像、道路端点、港口拓扑和省会候选一致。
- 十一类入口通过静态审计与专项矩阵；Worker / 主线程回退结果契约一致；生产构建通过。
- 精确用户标签页只操作当前原存档，不调用 `generate.newMap`；正式 UI 连续重设城镇两次后撤销恢复基线。
