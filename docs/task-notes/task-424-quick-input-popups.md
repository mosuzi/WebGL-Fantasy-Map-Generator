# 第 424 项：单输入弹框去冗余与回车完成

## 范围与现状

用户截图中的国家重命名使用 `UiActionDock` 二级弹框。Dock 固定标题“编辑中 / 重命名”，正文另有“名称”标签；名称输入的 42 / 44px 标签列、8px 列距、Element Plus 包装内距与正文内边距叠加，让文字前方像有空格。`UiTextEditField` 已在回车时提交并处理输入法组合，但绝大多数宿主提交后没有关闭 Dock。

只读清点 `18` 个 Dock 宿主、`57` 个二级浮层：同类单行重命名恰有 `12` 个，位于国家、省份、城市、文化、宗教、河流、湖泊、标记、测量、军事、标签、备注面板。另有对象详情、洋流、名称库的 `UiTextEditField` 是常驻行内编辑；其余 Dock 浮层有多字段、颜色、备注正文、预览或附加操作，不套用本项紧凑提交规则。

## 冻结实施

- 主线程唯一写者；只改共享 Dock、单行输入控件、局部样式、必要回归夹具和本项文档。
- 单输入弹框只显示当前名称输入及取消入口，保留无障碍名称；打开后输入获得焦点，回车合法提交后关闭，焦点回到触发按钮。
- 保留空值不提交、输入法选字不提交、Esc / 关闭不提交、历史单次和复杂弹框原行为。
- 首个廉价门为 `node tools/webgl-generator-action-dock-contract-regression.mjs`；之后按输入专项、真实浏览器小图、代表性大图、构建与 709 状态排版升级。

## 验收与首败

1. 国家单项浏览器首跑在有效回车后等旧输入框的 `inputValue()` 超时。弹框已按新规则关闭，旧夹具的调试输出仍假定提交后输入框常驻；此前的标题、聚焦、紧凑尺寸和输入法不提交断言已执行，截图显示约 `288×52px` 的单行弹框。修正：调试输出只读取已提交名称和历史，不再访问已关闭输入框；目标复验继续核对提交后消失、焦点返回、单历史、空值与取消。
2. 第二轮去掉旧输入读取后，第二次 Enter 仍未改变国家名称，历史保持 `0`，等待名称更新超时。可能是输入法组合状态、事件传播或关闭时机，现有结果不足以归因；先在该浮层记录 Enter 冒泡时的 `defaultPrevented`、组合状态、输入值、关闭状态和状态反馈，并在名称未更新时立即输出诊断，不再空等 30 秒。目标是明确本次是否真正调用了输入组件的提交，再决定改产品或夹具。
3. 第三轮事件记录显示：组合输入时第一次 Enter 冒泡且未阻止默认动作，值为“回车测试国”；合成的 `compositionend` 后，Element Plus 把尚未进入模型的草稿还原为旧名“雁川”；第二次 Enter 因而提交旧名并关闭。根因是本轮把原有 `preventDefault` 移到组合判断之后，改变了既有 IME 路径。实质调整：恢复组合期阻止默认动作，并在此分支停止事件冒泡，确保 Dock 不关闭；正常 Enter 仍冒泡且关闭。目标复验合成选字不提交 / 不关闭、组合结束后新名确实写入并关闭。
4. 国家单项目标复验通过：合成选字不提交且不关闭，有效回车更名、关闭和焦点回到重命名按钮；单历史、同值、空值、撤销与取消均通过。弹框实测 `288×50px`，正文文字距外框左缘 `17px`，无横向溢出；最长 LongTask `63ms`、页面错误 `0`。随后把城市、文化和原有气候 seed 输入纳入完整专项。
5. 首次实际 200% 缩放专项在打开 Chrome 设置页之前失败：旧浏览器夹具用 `browser.newPage()` 创建独占上下文，Playwright 禁止在其 `page.context()` 再创建标签页，产品断言尚未执行。实质调整：夹具显式 `browser.newContext()` 后创建正式页和设置页，保持同一上下文；目标复验核对实际 Chrome 200% 下弹框不裁切、文字起点和 Esc。
6. 第二次缩放专项在清理阶段报 `Target page, context or browser has been closed`，覆盖了真实首败；非持久化浏览器上下文不能可靠打开 Chrome 设置页。重新检查仓库的 709 状态排版夹具，它使用 `launchPersistentContext` 才能调整 Chrome 设置。实质调整：本专项改用相同的独立持久上下文，并保留原始异常优先于缩放复位异常；目标复验实际 200% 与输入行为。
7. 第三次实际 200% 缩放的 DOM 几何与行为通过（视口 `680px`，弹框 `288×50px`，文字内距 `17px`，无裁切，最长 LongTask `64ms`、错误 `0`），但元素局部截图只得到纸纹底色，尚不能据此断言画面可见。可能是 Chrome 页面缩放后的局部截图裁切坐标异常或截图早于合成。实质调整：在两帧稳定后同时保存整页与元素截图、输入和可见性计算值。第四轮完整页截图清楚显示输入及关闭图标，输入值和可见性为正常、Longest `60ms`、错误 `0`；局部截图仍因 Chrome 缩放裁切坐标得到背景，后续只采完整页视觉证据。
8. 100k 国家目标浏览器行为通过，但观察窗内有一条最长 `174ms` LongTask（页面错误 `0`）。依仓库规则，`200ms` 内仍需一次归因、实质优化和目标复验。现有报告只保存时长，不能区分首开国家面板、重命名弹框与提交。实质调整：记录长任务开始时间和首开、弹框打开、回车提交等阶段时间戳；只跑 100k 目标诊断，确认热点后做一次窄优化。

阶段诊断复现 `170 / 176ms`，均在回车提交，`143ms` 在随后撤销；方法计时显示 `history.execute` 仅 `0.5ms`，改名时 `renderer.refreshLabels` 为 `120.5ms`、撤销为 `95.4ms`，整图标签重建是主因。针对国家单对象改名给命令标记 `state-name`，复用现有政治标签局部刷新：只重建目标国家及其省份标签，其它标签节点保留，仍统一重新排版。100k 目标复验 `renderer.refreshLabels` 改名 / 撤销为 `10.4 / 8.4ms`，最长 LongTask `67ms`；补充标签断言后又一次目标复验为 `10.7ms`、最长 `68ms`，目标国地图标签随改名和撤销恢复、其它国家标签对象保持，页面错误 `0`。

集成复核发现初版只凭非空 Enter 关闭，无法区分命令拒绝；军团宿主也无条件关闭。共享输入现在暴露已提交名称，Dock 只在同值无须改动或下一次 Vue 更新确认规范化新名已写回后关闭；军团按其命令保留内部空白，取消宿主自行关闭。小图目标复验临时让国家对象在提交时失效：弹框保留草稿、历史不变，恢复对象后按回车规范化双空白并关闭；军团双空白保留、可撤销。最终 `0.5.145` 构建上国家、城市、文化、军团与气候 seed 完整专项最长 LongTask `159ms`、错误 `0`。残余最长任务定位于首次打开复杂军事管理面板，两轮分别为 `113 / 159ms`；本项已针对可归因的国家改名标签重建作实质优化并目标复验。同步 / 异步调度专项均断言 `state-name` 只刷新目标政治标签；正式浏览器要求先找到另一条可见国家标签，再验证局部刷新后仍可见。

独立终验发现备注总览优先展示备注保存时的旧 `note.name` 快照：关联对象重命名已经写入，但输入模型不变，故弹框无法按成功条件关闭。改为对象存在时依次读取当前 `name / fullName / text / targetName`，仅在失联时回退快照名；备注关联的生成标签、手工标签、地区、军团、测量和洋流分派到各自现有名称命令，路线等无名称命令的对象禁用无效重命名入口。旧快照国家备注、`label:state`、`label:custom` 和军团备注均以正式浏览器实际导入 / 编辑路径验证 Enter 关闭、名称更新及撤销；军团备注保留内部双空格。最终小图完整专项最长 LongTask `108ms`、页面错误 `0`，独立 blocker-only 复核 `ACCEPT`。

备注领域专项首次运行失败于静态源码正则：它只接受旧版单行 `if (...) executeNotesDomainCommand(...)`，本项为返回命令结果而改成跨行三元式；领域命令和浏览器行为均已验证，失败并非运行时备注写入。实质调整：仅更新该断言为精确匹配当前 `OBJECT_KIND.NOTE` 到 `notes.set` 的跨行分派，继续要求走正式领域命令。目标复验只跑 `regress:notes-core`，再继续最终排版门。

实际 Chrome 200% 缩放专项量得视口 `680px`、弹框 `288×50px`、文字左距 `17px`，无裁切或横溢，整页截图确认输入与关闭入口可见，最长 LongTask `70ms`、错误 `0`。截图及临时性能记录放在 `Z:\tmp\codex\2026-11-17\quick-input-popups`。

`impeccable detect` 对改动目标报告的 5 条警告均位于未改动的既有样式段（侧边强调与 Arial）；本项新增的紧凑弹框样式没有该类命中。动作 Dock 静态契约 `18` 宿主 / `57` 二级浮层 / `12` 个单输入重命名、核心类型检查、刷新调度、备注领域与导入专项和 `0.5.145` 应用构建通过；最终完整排版门观察 `709` 个状态，问题 `0`。最终 `0.5.145` 构建上的 100k 国家复验：目标标签局部构建 `11.1ms`，最长 LongTask `69ms`、错误 `0`；独立终验 `ACCEPT`。
