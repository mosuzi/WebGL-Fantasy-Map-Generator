# 第 419 项：国家标签显示条件与国土内中点

## 首败与窄修记录

1. `regress:political-label-collision` 首次失败于静态源码断言。旧断言要求 `retainedPoliticalPlacement` 直接等于快照恢复调用；新实现为防缩放后锚点越出国土，先取得快照并核对中点，再决定是否复用。因此失败源于断言固定了旧代码形状，而非运行时碰撞失败。下一次只更新该断言以检查“快照通过国土检查后复用”的语义，并加入障碍消失回到基准候选、不可见盒不占位和 pack 多边形内点的目标断言；先复验此专项。
2. `regress:overlay-pan-stability-browser` 首次超过旧 `35ms` overlay commit 门，测得 `36.6ms`；政治标签移入、候选和坐标均通过。原因是新加的国土多边形检查也在纯平移时对每个保留快照执行，而相同缩放下纯平移不改变世界坐标。此次只让缩放快照复用前执行该检查，纯平移继续直接复用已验证位置；重建后单独复验平移门，同时保留缩放越界专项。
3. 补充 `regress:label-styles` 停在“两个控制页 tab 共享视觉 token”的静态 CSS 断言。此项未修改 `styles.css` 或控制页 CSS，失败条件与国家标签布局无关且属于仍冻结的第 402 项范围；不改写该门，也不以其失败代表本项标签功能失败。
4. 补充 `regress:overlay-text-interaction-stability-browser` 首次在 `page.goto` 报 `127.0.0.1:5411` 连接拒绝，测试脚本自身不启动服务，尚未进入产品断言。下一次先启动本地正式预览服务，再做一次该目标浏览器复验。
5. 独立复核发现局部城市图层刷新仍把预热标签计入障碍，缩放进入时透明标签立即占位，平移入场时旧政治快照可能压住新可见城市，pack 拾取猜测 cell 的一跳邻居也会漏掉真实国土内点。针对性修正为：局部刷新只读取实际可见标签；透明进入帧不占位，下一帧补排；政治快照仅在前序可见障碍集合未变时复用；pack 多边形使用按陆块懒建的空间桶作精确兜底，旧图缺多边形时按最近 pack 中心判断。下一步先跑国土与政治布局专项，再测平移和完整浏览器场景。
6. 修正后的 `regress:overlay-pan-stability-browser` 首次失败在旧断言“缓冲省份 #192 入场候选必须保持 0”，实际提交为候选 5。此时新可见障碍已进入布局，按本项新需求省份应重新避让，旧断言不再适用。夹具改为读取入场前后的可见障碍身份：集合未变才要求候选与坐标不跳动；集合变化允许一次避让，但提交首帧与稳定帧候选、坐标必须一致。下一次只复验该浏览器门，并继续检查 `35ms` 预算。
7. 上述目标复验第二次停在省份 #64 首帧与稳定帧透明度不同：新障碍使省份进入 `collision-fallback`，CSS 按既有 `180ms` 过渡从 `0.82` 到 `0.6232`，差值恰为 `0.82 × (1−0.76)`，并非未完成布局。提交时该标签始终非透明，候选与坐标已稳定。夹具现只对障碍未变的标签要求首帧透明度精确一致；障碍变化时确认首帧和稳定帧均可见。下次仅复验平移专项，并依据测得的 overlay 时间决定是否需优化。
8. 平移专项在更新后的语义下通过，但 overlay 提交耗时 `34.7ms`，此前同样构建测到 `35.3ms`，贴近既有 `35ms` 门限。分析为每个政治标签都复制此前可见障碍数组，产生重复分配；改为整次布局共享一个可见障碍序列，标签只保存引用与前缀长度，复用时逐项比对该前缀。该调整保持精确身份比较，减少内存分配。随后重建并只复验政治布局、平移和 10k/100k 浏览器场景。
9. blocker-only 复核补充指出：缩放时同一城市标签身份和可见性都不变，但屏幕间距改变，复用旧候选仍可与新城市 box 重叠。前序身份相同仅能保证纯平移的相对几何不变。现将快照复用限定为纯平移，缩放始终按当前 box 重排；浏览器夹具加入同一城市持续可见、缩小时从远离到靠近国家标签的验证。先复验这一场景，再复验原有缩放 / 平移交互门。
10. 扩展浏览器夹具首次在 `10000` 场景报 `overlay-label:label-items-reference`：夹具暂时把标签列表替换为两项后等待异步动画帧，期间应用自己的保留资源检查观察到非正式列表。这是夹具对运行时对象的异步干扰，不是正常用户路径。改为同步模拟透明帧移除及补排，再立即恢复完整标签列表，让真实后续动画帧只看到原列表；下次只复验此浏览器夹具。
11. 既有 `regress:overlay-text-interaction-stability-browser` 在缩放预览到提交断言标签锚点最大差 `≤1px` 失败，观测 `51.5px`。本项要求缩放后按当前可见障碍重排，某些政治标签必须改变候选，旧夹具把“避让导致的有意位置变化”也当成稳定性失败。保留未换候选标签的 `1px` 稳定门，并要求换候选的标签仍为政治标签；先针对性复验，若未换候选标签仍跳位则进一步排查产品逻辑。
12. 交互门按新语义复验后，未换候选标签稳定性通过，但平移 overlay 为 `35.2ms`，略高于原 `35ms` 预算。先在失败信息中加入标签、图标等分项耗时，定位具体开销，再对最重分项做窄优化；保持预算不变。
13. 分项诊断再次测得 `47.1ms`，其中标签循环 `14.2ms`、三类图标合计 `4.3ms`，剩余约 `28.6ms` 在标签循环前。原因是 `updateLabels` 在预览变换后强制读取 canvas DOM rect；国家候选又通过 `screenToWorld` 对每个候选重复读取 DOM rect 和执行 grid 拾取。canvas 的 CSS 尺寸已由 `resizeToDisplaySize` 缓存，候选所属可直接使用精确 pack 多边形。现用缓存尺寸做 overlay 坐标，在候选内按相同相机公式直接转世界点，以国家锚点 pack cell 为快速提示、空间桶为兜底，并把循环前耗时加入调试统计。重建后复验原平移门、文字交互门及 10k/100k 国土浏览器场景。
14. 上述窄优化后文字交互门通过：overlay `11.3ms`，其中准备 `0.1ms`、标签 `7ms`，未换候选标签缩放锚点最大误差 `0.36px`，慢平移候选变化 `0`。随后平移专项尚未进入产品断言就报端口 `5411` 占用，原因是文字交互夹具所需的独立预览服务仍在运行；已关闭该服务，再只复验平移专项。

## 改动范围

国家标签、城市与省份标签的可见占位，自动国家标签的候选与缩放快照，国土多边形内点校验。手工锁定位置、存档与标签样式含义保持。

## 完成结果

- 避让集合只加入画面中显示且不在缩放透明进入帧的标签；局部城市图层刷新使用相同条件。障碍消失时自动政治标签从避让候选回到基准候选；平移入场、离场按新的可见集合重排，缩放总按当前屏幕距离重排。
- 自动国家标签中点由所选陆块的 pack 多边形判定。近邻提示错误时从该陆块的空间桶精确查找；缺失 pack 多边形的旧地图按最近 pack 中心判断。显式手工锁定位置继续由用户控制。
- 标签更新直接使用已维护的画布 CSS 尺寸，国家候选直接按相机参数换算世界位置。文字交互门的 overlay 提交从问题复验的 `47.1ms` 降至 `11.3ms`，其中标签准备 `0.1ms`、标签循环 `7ms`；平移专项也是 `11.3ms`。
