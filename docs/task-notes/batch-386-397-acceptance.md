## 统一修正的产品原因

- 云端回执不再依赖会被操作结果展开丢失的非枚举字段，改为上传负载创建前捕获保存内容身份。
- 恢复点导入保留恢复来源，不将其误报成已有手动存档。
- 搜索对话框声明模态，避免全局快捷键抢走 Esc；大量交易索引复用编号映射，保留与原解析器相同的首个匹配语义。
- 明确 `pixelScale / scale` 时维持旧 PNG API 语义；界面导出显式传目标尺寸。
- 数字框的最小宽度不再挤压组件内部输入；锁列表头与正文列顺序一致；列宽拖柄不继承普通按钮尺寸。
- 国家入口迁都与城市属性入口共享新旧首都的关联更新记录。
