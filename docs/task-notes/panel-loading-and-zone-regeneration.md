# 面板加载恢复与地区重新生成

本文冻结权威任务第 242～244 项。用户截图中的两处加载失败已通过让对应动态 chunk 返回 `404` 精确复现；当前完整生产构建中的两个面板均可正常打开，因此先消除两处首次打开才请求独立哈希资源的风险，再补共享错误恢复，最后接通已有地区重生成能力。

## 第 242 项：地区管理加载与共享恢复态

- 地区组件随入口构建加载，面板本身仍延迟挂载，避免旧页面首次打开时才请求独立 `ZonePanel-<hash>.js`。
- 共享懒加载器区分动态模块获取失败和普通组件异常；前者显示版本更新说明、保存提醒、重试与显式刷新操作，后者保留原失败文案和开发日志。
- 不自动刷新、保存或覆盖地图；错误统计只暴露有界类型与消息。

## 第 243 项：云端存储加载与组件注册

- 云端组件同样随入口构建加载、延迟挂载，不再首次打开才请求独立 `CloudStoragePanel-<hash>.js`。
- `CloudStoragePanel.vue` 显式导入模板使用的 `UiButton`，保证真实按钮语义、禁用状态和样式。
- 不修改 OAuth、环境变量、令牌生命周期或云端文件语义，也不扩大真实账号联调声明。

## 第 244 项：地区重新生成入口

- 控制面板统一重生成目录和地区管理面板都提供“重新生成地区”，共同调用既有 `generate.regenerate("zones", {confirm:true})`。
- 复用现有地图快照事务、扰动序号、锁定保护、`buildZones`、自动无人区重建和对象索引刷新，不新增并行算法或公开方法。
- 空地区集合只表示当前没有地区，不得误判为“全部锁定”；地图具备 pack cells 时允许从零生成。
- 手工、自然和锁定地区按既有保留规则处理；全锁拒绝不推进扰动序号或历史，失败、撤销和重做必须恢复完整前后状态。

## 最小验收

1. 当前生产构建中地区与云端面板正常打开，入口不再对这两个组件发起独立动态 chunk 请求。
2. 普通懒加载 chunk 获取失败时出现可操作恢复态，不发生自动刷新；普通组件异常不被误判。
3. 地区 UI 与 API 走同一路径；固定地图重生成后 salt、地区摘要、对象索引与面板刷新，锁定对象不变。
4. `zones=[]` 和缺少独立 `map.zones` 的旧结构可生成；全锁、失败、撤销 / 重做、未确认 API 均符合现有事务契约。
5. 专项、API / 复合语义审计、旧数据兼容、生产构建、系统浏览器和 `source/` 零改动通过。
