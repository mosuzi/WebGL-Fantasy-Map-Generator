# 编辑器与统计面板清单

本文档用于盘点正式版 WebGL 地图生成器已经具备和远期可能需要的编辑器、统计面板及其边界。2026-07-16 已按权威任务第 10～81 项重新校准；原准权威 `Q-02～Q-08` 已经用户批准转为权威任务第 72～78 项，其范围、产品门禁和验收以 `docs/current-plan.md` 为准。其余“缺口”仍只作能力盘点，不自动成为活动任务。

## 总体原则

- 正式版编辑器和统计面板都使用普通 HTML/DOM 浮动面板，不使用 canvas 绘制 UI。
- WebGL canvas 只负责地图、专题、对象高亮、编辑预览和 picking。
- 面板通过 runtime/store 发出选择、定位、编辑命令，不直接计算地图命中。
- 对象详情面板只显示当前选中对象摘要，并提供打开对应领域面板的入口，不承载完整列表、统计或批量管理。
- 每个领域的全量列表、筛选、排序、统计、定位和批量操作应归入独立领域面板。
- 编辑操作需要沉淀为 edit command / undo command，而不是只在 UI 中临时改运行时对象。
- 动态军事系统继续暂缓；经济总览、市场归属编辑和受约束经济重算已由权威任务第 48 项完成。当前执行状态仍以 `docs/current-plan.md` 为准。

## 面板类型

### 生成与全局配置面板

- 面板性质：配置面板，同时带少量统计。
- 需要编辑器：是，编辑 seed、模板、目标 cells、地图尺寸、随机化选项和生成参数。
- 需要统计面板：是，显示生成摘要、耗时、checksum、当前生成选项和 source/candidate 对照状态。
- 优先级：中。
- 当前状态：`generation-panel` 已扩展为控制面板，`生成` tab 承载 seed、模板、目标 cells、地图尺寸、自动随机 seed、生成和换 seed；生成阶段、耗时、grid/pack 规模、checksum 和 source/candidate 对照仍保留在侧栏运行时统计和 baseline 文档中，不放入控制面板。

### 图层与专题面板

- 面板性质：控制面板。
- 需要编辑器：否，主要是切换视图、图层、透明度和 legend。
- 需要统计面板：轻量需要，显示当前专题字段来源、值域、可见对象数量和渲染耗时。
- 优先级：中。
- 备注：不要把对象编辑功能塞进图层面板。
- 当前状态：专题选择器、单位配置和图层开关已迁入 `generation-panel` 的 `视图`、`单位` 与 `图层` tab；固定侧栏不再承载专题、单位和图层控制。图层开关已改为管理面板风格按钮，并用高亮状态标识显隐；城市标签上限已提供滑动条，最大值会随当前地图城市总数动态设置；专题、图层显隐、“高度专题显示海底”、单位偏好和城市标签上限会持久化到浏览器 `localStorage`。

### 对象详情面板

- 面板性质：只读摘要与跳转入口。
- 需要编辑器：只保留最小“进入编辑”入口，不承载完整编辑器。
- 需要统计面板：否，只显示当前对象摘要。
- 优先级：已启动，继续维护边界。
- 备注：选中河流时可以显示长度、流量、源头、河口和按钮“打开河流面板”，但河流列表与批量统计必须在 `river-panel`。

## 地形与环境

### 高度 / 地形编辑器

- 面板性质：典型栅格编辑器。
- 需要编辑器：是。
- 编辑范围：抬升、降低、平滑、按鼠标中心衰减的笔刷、半径、强度、模式、撤销和重置。
- 需要统计面板：是。
- 统计范围：高度分布、陆地比例、海平面、山地/低地占比、被影响 cell 数、最近一次操作摘要。
- 优先级：高。
- 当前状态：高度编辑器已接入正式浮动面板、抬升、降低、平滑、整平、扰动、连通域锥形填充、两点线段山脊 / 沟槽和中心衰减；整平会锁定每次落笔起点高度，扰动使用稳定 stroke seed，填充会把可调高度容差内的陆地带或封闭水域塑造成锥形地貌，线段工具按两次点击、线宽和 signed power 生成直线山脊或沟槽并显示跟随指针的预览线。七种动作均支持“全部 / 仅陆地 / 仅水域”，普通笔刷的范围资格按 cell 首次修改前高度锁定；填充默认容差 `6`，并会拒绝开放海域、缺少边界标记、过小或超过 grid 20% / 5000 cells 安全上限的连通域，同时在 hover cell 变化时预检并显示有界候选数 / 拒绝原因，避免盲点地图；线段也使用同一大选区上限。面板还提供遵守当前陆水范围的全局平滑和稳定 seed 全局扰动，以及按原始高度闭区间执行加、减、乘、除、指数的条件变换；三类全局动作均改为预览优先，只有有效有界预检后才允许应用。条件与全局预览共用暖 / 冷 world-space GPU buffer；持久黄色地形选区支持当前高度区间、最后地图光标圆形、两角矩形、连通等高区和画笔拖选五种候选来源，均可执行覆盖、并入、交集和排除，空结果会拒绝并保留旧选区。圆形有独立半径和画布中心 picking 回退；矩形用两次地图点击完成并显示轻量预览；连通等高区先单击中心，再按独立容差沿共享边扩张；画笔拖选用连续圆形 stamp 累积候选，拖中只预览黄色组合结果、抬手才提交。空间来源都遵守当前陆水 scope。锁定选区现可暂存、恢复和删除，同图清除或继续组合后仍能回到快照，跨 grid 自动拒绝；还可沿共享边扩展或收缩一圈，扩展遵守当前陆水 scope，收缩为空会保留原选区。完整候选 ids / 合成 ids / Set / 暂存 grid 引用仅留在运行时，条件 / 全局工具可切换为仅作用于选区。选区与变化 preview 使用独立 buffer，可叠加显示，并分别提供有界 GPU 统计；新地图加载清除当前与暂存选区，同图高度命令、历史和派生重算保留 grid identity。扰动预览保留下一稳定 seed，命令成功后才推进。笔刷与全局计算集中在 `height-brush.js`，无变化 cell 不再虚增影响数；编辑结果通过 `height-edit-commands.js` 生成命令，支持撤销 / 重做。高度面板已显示高度统计、最近操作、有限提示和待派生数量；高度编辑提交和撤销会标记河流、路线、生物群系、聚落、政治与下游系统为待派生。面板既可单独重算河流，也可按基础与下游顺序重算。后续重点是边缘羽化和更复杂的模板工具。
- 2026-07-16 状态校准：边缘羽化和权威任务第 38 项多步骤地形模板均已完成；内置模板、用户模板编排、导入导出、固定 seed 复现和单历史应用已有专项回归。更大的地形脚本语言不在当前范围。
- 2026-07-12 模板第一刀：高度面板新增高原塑形、盆地塑形、阶地量化和破碎地形四个选区模板；都要求锁定选区，消费当前 scope 与羽化权重，先用暖 / 冷 GPU buffer 预览，再通过统一高度命令应用和撤销 / 重做。破碎模板使用稳定 seed，只有成功应用才推进；有限 snapshot 不包含 changes 或权重 Map。后续仍可扩展多步骤模板编排、用户模板保存 / 导入和更接近原项目整图模板的工作台。

### 气候面板

- 面板性质：统计为主，后续可扩展为参数编辑器。
- 需要编辑器：已开始，当前支持赤道/南北极温度、画布纬度和风带方向的运行时即时重算。
- 需要统计面板：是。
- 统计范围：温度 min/max/均值、降水分布、极端干旱/湿润区域、风带和纬度参数。
- 优先级：中。
- 当前状态：控制面板“生成”tab 已提供闭合地球投影、闭合画布多边形和六段风带按钮；调整温度、纬度和风向会立即重算温度、降水、生物群系和人口适宜度并刷新画布。国家、城镇、经济、军事、外交等下游系统只标记待派生，尚未受约束重算。
- 气候统计面板第一刀已完成，支持管理页入口、筛选、排序、选中详情，以及温度范围、平均温度、降水范围、平均降水、干旱 / 湿润陆地 cells、纬度和大气方向汇总；气候控制仍留在控制面板“生成”tab，下游系统仍只标记待派生。

### Feature / 水体 / 海岸面板

- 面板性质：统计和结构检查优先，编辑次之。
- 需要编辑器：中期需要。
- 编辑范围：湖泊、岛屿、海峡、海岸线修补、湖泊出口、feature 类型修正。
- 需要统计面板：是。
- 统计范围：ocean/lake/island feature 数、湖泊面积、岸线长度、haven/harbor 数、异常引用。
- 优先级：中高。
- 当前状态：水体与地貌统计面板第一刀已完成，支持管理页入口、筛选、排序、选中详情，以及 pack feature 类型 / 分组、cells、面积、岸线段数、海岸 / 湖岸长度、水位、补给、蒸发、haven / harbor 和 grid/pack feature 引用异常汇总；湖泊面板已支持安全填平湖泊、编辑真实河流出口，以及在半径 0～2 范围内有预检地扩展湖水或收回湖岸。局部修正会拒绝开放海域、城市、河道、路线、标记、边界、整湖删除和湖泊分裂，并同步 pack / grid 高度与 feature、岸线、haven / harbor、水文引用和派生标脏；UI 与 `api.edit.lakes / features` 共用可撤销命令。完整海岸雕刻器和任意 feature 类型转换不在当前范围。

### 生物群系与适居度面板

- 面板性质：统计与局部归属编辑。
- 需要编辑器：已完成目标 biome、陆水范围和半径笔刷第一刀。
- 需要统计面板：是。
- 当前状态：生物群系面板支持管理页入口、筛选、排序、选中详情，以及按 pack 语义层汇总 biome cells、面积、适居度、人口和城市覆盖；13 个稳定 ID 已共用中文专业名称与生态说明 registry，面板详情 / 搜索、颜色模式图例、拾取 / 悬停、气候 API 可读统计和 pack cell GeoJSON 均使用同一展示层，英文 canonical name 与数值 ID 继续保持兼容。归属笔刷可按目标 biome、陆水范围和半径预览并在抬手时提交单条历史，UI 与 `api.edit.biomes.assignCells()` 共用命令。数值适居度动作支持整数 `0～100` 直接设值、恢复自动基准、`land / water / all` 范围和共享半径光标，UI 与 `api.edit.biomes.inspectSuitability / applySuitability` 共用命令。提交后同步 grid / pack 适居度、人口承载和区域统计，并标记下游系统待派生；水域人口承载恒为 0。
- 统计范围：各 biome cell 数、人口承载、适居度分布、异常无人区。
- 优先级：中。

## 水文与线性对象

### 河流面板

- 面板性质：独立浮动管理面板，不能混入对象详情或固定侧栏。
- 需要编辑器：是。
- 编辑范围：选择河流、定位、红色闪烁高亮、改河道、调整宽度/流量因子、源头/河口修正、支流关系检查、撤销。
- 需要统计面板：是。
- 统计范围：河流总数、总长度、最大/平均流量、单河长度、单河流量、河段数、河口裁剪数、异常入海段。
- 优先级：最高。
- demo 对应：河流列表、长度/流量、定位和闪烁高亮已验证；正式版应先建立 `river-panel` 与 edit command 边界。
- 当前状态：河流管理和编辑链路已具备，基础河流线宽仍使用固定屏幕像素并带 `1.1 CSS px` 下限；随画布缩放投影制图语义宽度的整改已列为权威任务第 66 项。

### 路线 / 道路 / 海路面板

- 面板性质：线性对象管理与编辑面板。
- 需要编辑器：是。
- 编辑范围：道路、小路、海路的选择、定位、改线、端点重连、等级/样式调整、删除和重算。
- 需要统计面板：是。
- 统计范围：route 数、按类型长度、连接城市数、断路、穿水陆异常、港口海路覆盖。
- 优先级：高。
- 备注：可复用河流面板的列表、定位、高亮和线段编辑模式。
- 当前状态：路线管理已支持列表、筛选、排序、定位、选中高亮、单路线详情、创建、删除、道路重算、单点几何改线、城市端点重连和 `type / level` 样式调整。改线预检遵守陆路 / 水路地形与相邻拓扑，应用后同步 pack/grid cells、长度、资源诊断、picking 和 GeoJSON，并通过统一命令完整撤销 / 重做；基础道路线宽仍为固定屏幕像素，已列入权威任务第 66 项；不包含动态交通模拟。

## 政治与社会对象

- 面板性质：典型区域实体编辑器。
- 需要编辑器：是。
