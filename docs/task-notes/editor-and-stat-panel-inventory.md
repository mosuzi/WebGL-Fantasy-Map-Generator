# 编辑器与统计面板清单

本文档用于整理正式版 WebGL 地图生成器后续需要哪些编辑器、哪些统计面板，以及它们之间的边界。当前结论来自 demo 高度、河流、国家三类编辑器验证，以及正式版浮动面板架构约束。

## 总体原则

- 正式版编辑器和统计面板都使用普通 HTML/DOM 浮动面板，不使用 canvas 绘制 UI。
- WebGL canvas 只负责地图、专题、对象高亮、编辑预览和 picking。
- 面板通过 runtime/store 发出选择、定位、编辑命令，不直接计算地图命中。
- 对象详情面板只显示当前选中对象摘要，并提供打开对应领域面板的入口，不承载完整列表、统计或批量管理。
- 每个领域的全量列表、筛选、排序、统计、定位和批量操作应归入独立领域面板。
- 编辑操作需要沉淀为 edit command / undo command，而不是只在 UI 中临时改运行时对象。
- 经济和军事系统暂缓，不作为近期编辑器主线。

## 面板类型

### 生成与全局配置面板

- 面板性质：配置面板，同时带少量统计。
- 需要编辑器：是，编辑 seed、模板、目标 cells、地图尺寸、随机化选项和生成参数。
- 需要统计面板：是，显示生成摘要、耗时、checksum、当前生成选项和 source/candidate 对照状态。
- 优先级：中。
- 当前状态：`generation-panel` 已扩展为控制面板，`生成` tab 承载 seed、模板、目标 cells、地图尺寸、自动随机 seed、生成和换 seed；生成阶段、耗时、grid/pack 规模、checksum 和 source/candidate 对照仍保留在侧栏运行时统计和 baseline 文档中，不放入控制面板。

### 图层与专题面板

- 面板性质：控制面板。
- 需要编辑器：否，主要是切换视图、图层、透明度和 legend。
- 需要统计面板：轻量需要，显示当前专题字段来源、值域、可见对象数量和渲染耗时。
- 优先级：中。
- 备注：不要把对象编辑功能塞进图层面板。
- 当前状态：专题选择器、单位配置和图层开关已迁入 `generation-panel` 的 `视图`、`单位` 与 `图层` tab；固定侧栏不再承载专题、单位和图层控制。图层开关已改为管理面板风格按钮，并用高亮状态标识显隐；城市标签上限已提供滑动条，最大值会随当前地图城市总数动态设置；专题、图层显隐、“高度专题显示海底”、单位偏好和城市标签上限会持久化到浏览器 `localStorage`。

### 对象详情面板

- 面板性质：只读摘要与跳转入口。
- 需要编辑器：只保留最小“进入编辑”入口，不承载完整编辑器。
- 需要统计面板：否，只显示当前对象摘要。
- 优先级：已启动，继续维护边界。
- 备注：选中河流时可以显示长度、流量、源头、河口和按钮“打开河流面板”，但河流列表与批量统计必须在 `river-panel`。

## 地形与环境

### 高度 / 地形编辑器

- 面板性质：典型栅格编辑器。
- 需要编辑器：是。
- 编辑范围：抬升、降低、平滑、按鼠标中心衰减的笔刷、半径、强度、模式、撤销和重置。
- 需要统计面板：是。
- 统计范围：高度分布、陆地比例、海平面、山地/低地占比、被影响 cell 数、最近一次操作摘要。
- 优先级：高。
- 当前状态：高度编辑器已接入正式浮动面板、统一刷和中心衰减刷；高度笔刷结束时会通过 `height-edit-commands.js` 生成 `EditHistory` 命令，支持撤销 / 重做。高度面板已显示当前均高、陆地比例、低地比例、山地比例、海平面带比例、最近笔刷平均变化和待派生数量；高度笔刷提交和撤销会标记河流、路线、生物群系、聚落、政治与下游系统为待派生，面板已提供按当前高度重算河流的第一处派生入口。后续重点是局部地形工具、更多派生重算入口和更完整的地形编辑验收。

### 气候面板

- 面板性质：统计为主，后续可扩展为参数编辑器。
- 需要编辑器：已开始，当前支持赤道/南北极温度、画布纬度和风带方向的运行时即时重算。
- 需要统计面板：是。
- 统计范围：温度 min/max/均值、降水分布、极端干旱/湿润区域、风带和纬度参数。
- 优先级：中。
- 当前状态：控制面板“生成”tab 已提供闭合地球投影、闭合画布多边形和六段风带按钮；调整温度、纬度和风向会立即重算温度、降水、生物群系和人口适宜度并刷新画布。国家、城镇、经济、军事、外交等下游系统只标记待派生，尚未受约束重算。
- 气候统计面板第一刀已完成，支持管理页入口、筛选、排序、选中详情，以及温度范围、平均温度、降水范围、平均降水、干旱 / 湿润陆地 cells、纬度和大气方向汇总；气候控制仍留在控制面板“生成”tab，下游系统仍只标记待派生。

### Feature / 水体 / 海岸面板

- 面板性质：统计和结构检查优先，编辑次之。
- 需要编辑器：中期需要。
- 编辑范围：湖泊、岛屿、海峡、海岸线修补、湖泊出口、feature 类型修正。
- 需要统计面板：是。
- 统计范围：ocean/lake/island feature 数、湖泊面积、岸线长度、haven/harbor 数、异常引用。
- 优先级：中高。
- 当前状态：水体与地貌统计面板第一刀已完成，支持管理页入口、筛选、排序、选中详情，以及 pack feature 类型 / 分组、cells、面积、岸线段数、海岸 / 湖岸长度、水位、补给、蒸发、haven / harbor 和 grid/pack feature 引用异常汇总；湖泊出口、海岸线修补和 feature 类型编辑仍未实现。

### 生物群系与适居度面板

- 面板性质：统计为主。
- 需要编辑器：暂缓，后续可支持局部 biome 修正或适居度刷。
- 需要统计面板：是。
- 当前状态：生物群系统计面板第一刀已完成，支持管理页入口、筛选、排序、选中详情，以及按 pack 语义层汇总 biome cells、面积、适居度、人口和城市覆盖；局部 biome 修正和适居度刷仍未实现。
- 统计范围：各 biome cell 数、人口承载、适居度分布、异常无人区。
- 优先级：中。

## 水文与线性对象

### 河流面板

- 面板性质：独立浮动管理面板，不能混入对象详情或固定侧栏。
- 需要编辑器：是。
- 编辑范围：选择河流、定位、红色闪烁高亮、改河道、调整宽度/流量因子、源头/河口修正、支流关系检查、撤销。
- 需要统计面板：是。
- 统计范围：河流总数、总长度、最大/平均流量、单河长度、单河流量、河段数、河口裁剪数、异常入海段。
- 优先级：最高。
- demo 对应：河流列表、长度/流量、定位和闪烁高亮已验证；正式版应先建立 `river-panel` 与 edit command 边界。

### 路线 / 道路 / 海路面板

- 面板性质：线性对象管理与编辑面板。
- 需要编辑器：是。
- 编辑范围：道路、小路、海路的选择、定位、改线、端点重连、等级/样式调整、删除和重算。
- 需要统计面板：是。
- 统计范围：route 数、按类型长度、连接城市数、断路、穿水陆异常、港口海路覆盖。
- 优先级：高。
- 备注：可复用河流面板的列表、定位、高亮和线段编辑模式。
- 当前状态：路线管理面板第一刀已完成，支持列表、筛选、排序、定位、选中高亮和单路线详情；删除和道路重算入口已接入列表操作区；改线、端点重连和等级/样式调整仍未实现。

## 政治与社会对象

### 国家面板

- 面板性质：典型区域实体编辑器。
- 需要编辑器：是。
- 编辑范围：国家选择、cell 归属涂抹、颜色、名称、形制、首都、中心、扩张参数、合并/拆分。
- 需要统计面板：是。
- 统计范围：国家数、面积/cell 数、人口、城市、港口、省份数、边界长度、未分配或跨水异常。
- 优先级：高。
- demo 对应：国家涂抹、取色、连续刷、状态显示已验证；正式版要解决大面积变更后的边界和派生字段重算。
- 当前状态：国家管理和国家 cell 归属笔刷已完成第一刀；管理 tab 的“国家”重新生成已接入受约束重算，会在当前城镇中重选首都、重建国家和省份、同步城镇政区并重算道路。宗教、标记、区域、军事、经济仍标为待派生；国家合并/拆分和扩张参数编辑仍未实现。

### 省份 / 区域面板

- 面板性质：区域实体编辑器。
- 需要编辑器：是。
- 编辑范围：省份归属、名称、中心、pole、所属国家、边界修正。
- 需要统计面板：是。
- 统计范围：省份数、每国省份数、面积、人口、无 pole 省份、跨国家异常。
- 优先级：中高。
- 备注：可和国家面板共享区域刷、边界重建和统计表组件，但保持独立 tab 或独立面板。
- 当前状态：省份管理面板和省份 cell 归属笔刷第一刀已完成，支持列表、筛选、排序、定位、名称/颜色编辑、同国家内省份刷、统计刷新、center 兜底、pole 局部重算和撤销/重做；管理 tab 的“省份”重新生成已接入受约束重算，会在当前国家边界内重选省份中心、扩张省份、同步城市省份并重算道路。新增/删除省份、跨国家迁移仍未实现。

### 城市 / 聚落面板

- 面板性质：点对象管理与编辑面板。
- 需要编辑器：是。
- 编辑范围：新增/删除城市、移动位置、名称、人口、首都/省会/港口状态、文化/宗教/国家归属、标签可见性。
- 需要统计面板：是。
- 统计范围：城市数、港口数、首都/省会数、人口合计、各国城市分布、异常落水城市。
- 优先级：高。
- 当前状态：城市管理面板第一刀已完成列表、筛选、排序、定位、详情和名称编辑；第二刀 A 已完成城市人口编辑、EditHistory 撤销/重做、city/burg 人口同步、所在 cell 归属一致性检查、落水异常提示，以及低风险“同步归属到所在 cell”。本轮不做新增/删除、移动位置、自由迁国/迁省、港口重算、路线重算或首都/省会派生重算。

### 文化面板

- 面板性质：区域实体编辑器。
- 需要编辑器：需要，但排在国家/城市之后。
- 编辑范围：文化名称、类型、中心、颜色、扩张参数、cell 归属修正。
- 需要统计面板：是。
- 统计范围：文化数、覆盖 cell、人口、城市、国家交叉分布。
- 优先级：中高。
- 当前状态：文化管理面板第一刀已完成，支持文化列表、筛选、排序、快速定位、选中高亮、名称编辑、颜色编辑、继承父级编辑、独立连线树总览、覆盖 cells、面积、乡村/城市人口、城市数和主要国家分布统计；文化专题颜色会优先读取文化对象颜色。新增空文化和删除空文化已接入列表动作条与 `EditHistory`，删除只允许无 cells、无城市 / 城镇 / 国家关联、无子级的空文化。文化 cell 归属笔刷、中心迁移、扩张参数编辑和宗教联动重算仍未实现。

### 宗教面板

- 面板性质：区域实体编辑器。
- 需要编辑器：需要，但排在文化之后。
- 编辑范围：宗教名称、类型、中心、颜色、扩张约束、cell 归属修正。

## 跨领域基础设施

近期进入正式版编辑器前，必须先补以下基础设施：

1. 统一 edit command / undo command：记录目标对象、旧值、新值、影响范围和派生重建需求。
2. selection store：城市、路线、河流、国家、省份、文化、宗教、marker 和标签使用同一选择状态。
3. highlight / locate API：所有列表面板都能请求地图居中、缩放和闪烁高亮。
4. object table 组件：支持筛选、排序、虚拟滚动、点击定位和双击进入编辑。
5. 派生重建调度：cell 归属变化后按需重建专题颜色、边界、统计、标签和 picking 索引。
6. 面板持久化：位置、大小、打开状态、当前 tab、筛选词和排序字段按 workspace/session 保存。

当前状态：

- 摘要区、排序按钮、详情网格、历史操作区、筛选输入和表格滚动恢复已有公共 DOM 组件，国家、省份、城市、河流和路线面板已接入第一刀复用。
- 列表下的图标二级操作已统一通过 `UiActionDock` 打开独立 Teleport 浮层，重命名、调色、继承、人口、首都、剪影、宽度和外交关系等操作不再在当前列表面板内展开。
- 浮动面板位置、宽度和打开状态已通过 `PanelManager` 持久化；对象详情面板因依赖当前 selection，不恢复打开状态。
- 河流、路线、湖泊、地区、国家、省份、城市、文化、宗教、外交、marker、标签 / 命名、备注总览、测量对象、名称库总览、政体、经济和军事面板已通过 `panel-list-preferences.js` 持久化筛选词和排序字段。
- 控制面板当前 tab 和经济面板内部 tab 已持久化；其它有内部 tab 或二级筛选的面板仍按各自运行时状态处理，后续若要扩大需要单独拆项。
- `UiObjectTable` 已完成固定行高虚拟滚动第一刀，并在城市大表浏览器烟测中确认只渲染可视窗口、滚动换页和点击选中正常；空态动作第一刀已落地，测量对象面板空列表可通过标准按钮进入测量模式。

### 2026-07-08 基础设施现状盘点

## 验收标准

- 每个领域面板职责单一，不把完整管理功能塞进对象详情面板。
- 所有编辑操作都可以撤销，并能清楚记录影响范围。
- 列表定位必须能在复杂底图中给出醒目的地图反馈。
- 大面积区域编辑不能每个鼠标点都全量重建；拖动中做轻量预览，抬手后统一重建派生数据。
- 统计数字应来自当前运行时数据，不使用写死示例。
- 面板内部交互不触发地图 pan、zoom 或 selection。
