# 第 274 项：Wiki 功能手册与可复现截图施工图

## 一、问题证据

2026-08-04 只读盘点显示，`docs/wiki/` 只有 12 个 Markdown 页面、合计 193 行，全部页面的 Markdown 图片引用为 0。现有 `audit:wiki` 只检查六个必需页、一级标题、内部链接和 API 命名空间方法数，因此即使正文只有名词摘要、没有操作说明和截图也会通过。

第 226 项原施工图已经要求 Wiki 面向人类细致覆盖自然与人文领域、全部编辑器 / 面板 / 图层、对象详情和典型工作流，并增加导航、截图、操作步骤、概念解释和常见问题。本项修复的是该验收缺口，不新增产品能力。

## 二、信息架构

Wiki 按普通用户完成任务的顺序组织：

1. 首页与快速开始：认识主界面、生成第一张地图、查看对象、保存第一份存档。
2. 生成与显示：地图参数、地图名称、专题视图、主题、标签样式、图层与单位。
3. 自然世界：高度与地貌、水体与海岸、河流湖泊洋流、气候、生物群系、适居度与人口。
4. 人文世界：国家、政体、省份、城市、文化、宗教、路线、经济、外交与军事。
5. 表达对象：地区、资源与标记、标签、备注、测量和名称库。
6. 安全与交换：选择 / 定位、编辑模式、预检、确认、撤销 / 重做、重生成锁、存档、导入导出与旧图兼容。
7. 自动化与理解：浏览器 API、无头只读、无头安全写入、当前标签页桥、Grid / Pack 与区域分析。

每个功能章节至少回答“在哪里打开、解决什么问题、关键控件是什么、操作后会发生什么、如何撤销或保护对象、可以导出或自动化什么、容易误解什么”。精确 schema 和逐方法清单继续由机器目录维护，Wiki 不复制大表。

## 三、截图清单

截图使用固定 `mountains-and-seas` 10k 地图、`1440×960 @ DPR 1` 浏览器视口、隔离系统 Chrome 和清空后的 LocalStorage / SessionStorage。全局与领域场景保留完整视口；为避免把任务范围外的既有旧品牌短标题带入长期手册，导出浮层场景允许从同一完整视口做不缩放、不改字、不遮罩的固定矩形裁剪，并必须断言浮层完整落在裁剪范围内。最低场景为：

1. 主界面与第一张地图。
2. 生成参数、地图名称和文件名设置。
3. 专题、图层、样式或单位控制。
4. 高度编辑。
5. 气候 / 生态 / 人口。
6. 国家 / 省份 / 城市。
7. 文化 / 宗教 / 人口。
8. 路线 / 经济 / 外交 / 军事。
9. 地区 / 标记 / 标签 / 备注 / 测量。
10. 保存、导出与云端入口。

允许把信息过密的组合拆成更多场景，不允许为压缩数量而产生无法阅读的拼图。图片必须来自正式生产构建和真实 UI；纯地图总览可复用现有 README 展示图，但管理操作必须使用包含实际面板的页面截图。

## 四、确定性与隐私门禁

- 只使用公开正式 API、稳定 aria-label、控件 id 和 `data-panel-id` 构造状态，不读取用户 Chrome 会话。
- 截图前关闭动画、toast、hover 和瞬时闪烁；不显示生成时间、动态日期文件名、checksum 或临时日志。
- 不打开云端令牌、OAuth code、provider identifier 或 AI bridge 配对令牌输入区，不加载 `private-cases/` 或真实旧存档。
- 每个场景断言目标视图、图层与面板可见，截图前等待字体、renderer 和动态层稳定。
- 捕获后检查 PNG 签名、尺寸、非空文件、SHA-256、console / page / active health / WebGL error，并在 `finally` 清理服务、浏览器和专属 profile。
- 连续两次 clean capture 的场景清单、尺寸和 SHA-256 必须一致；如文字栅格化导致摘要不稳定，必须先定位并消除动态来源，不能把校验降成只看文件存在。

## 五、同步与审计

`tools/webgl-generator-wiki-sync.mjs` 需要同时检查：

- 必需页面与稳定内部链接；
- 图片相对路径只指向 Wiki 资产目录；
- 每个图片引用具有非空描述性 alt，紧邻正文图注；
- 截图 manifest 与磁盘 PNG、Markdown 引用三方双向差集为零；
- PNG 文件签名、尺寸和非空性；
- 当前 UI 功能分母与 Wiki 领域路由保持一致；
- `--publish` 递归同步 Markdown、manifest 和图片资产，而不是只复制顶层 `*.md`。

## 六、验收与排除

执行 `audit:wiki`、`audit:ai-docs`、截图 clean run ×2、生产构建和 `git diff --check`，再由独立审查者核对事实、功能覆盖、图片可读性与发布路径，最后用系统 Chrome 人工检查至少桌面主视图和关键面板截图。

本项不修改产品行为、地图数据、schema、API、默认图层或 `source/`；不远端发布 Wiki，不改变仓库可见性，不提交或推送。
