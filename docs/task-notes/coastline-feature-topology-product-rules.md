# 海岸雕刻与 Feature 拓扑编辑产品规则冻结稿

本文档对应权威任务第 75 项。当前状态为 **已完成**。本文记录用户确认并已实施的操作矩阵、共同约束、高度跨海平面规则和数据兼容边界；最终任务状态与最小验收仍以 [`../current-plan.md`](../current-plan.md#权威任务清单) 为准。

## 数据语义

- 持久化 feature `type` 只使用 `ocean / lake / island`。
- `continent / island / isle / lake_island` 是根据拓扑重新计算的派生 `group`，不提供直接修改入口。
- 陆地与水域由高度阈值决定：`h >= 20` 为陆地，`h < 20` 为水域。
- `strait` 是“开海峡 / 闭海峡”操作，不是持久化 feature type 或 group。

## 允许操作矩阵

| 操作 | 输入与预检 | 成功结果 |
|---|---|---|
| 海岸雕刻 `land -> ocean` | 目标陆地紧邻开放海域，且转换前后陆地与水体连通分量数都不改变 | 目标转为开放海域的一部分；若会切开陆地或改变水体连通结构，必须改用“开海峡” |
| 填岸 `ocean -> land` | 目标开放海域紧邻单一陆地分量，且不能借此合并两个陆地分量 | 目标并入该陆地；若需要连接两侧陆地，必须改用“闭海峡” |
| 开海峡 | 选择连续陆地走廊，走廊两侧都连接开放海域；转换后必须形成有效通航水道 | 走廊转为水域并立即完成 feature、岸线和相关派生同步 |
| 闭海峡 | 选择连续水道，水道两侧连接陆地 | 水道转为陆地；允许由此合并陆地分量，封闭后与开放海域失去连接的内陆水体自动归为湖泊 |
| 湖海开渠 `lake -> ocean` | 只能显式选择连续渠道，把湖泊连接到开放海域 | 渠道与湖泊并入开放海域；不提供直接修改 lake type 的捷径 |
| 整湖填平 | 必须选中一个完整湖泊并显式确认；沿用既有湖泊面板“填平并删除选中湖泊”的完整对象事务，不新增泛化水陆模式 | 整个湖泊转为陆地；不接受只以“整湖填平”名义选择湖泊子集 |
| 岛屿 / 大陆 split、merge | 只能由上述海岸或海峡操作的真实连通结果触发 | 重新识别 feature 并自动计算 group；不提供直接 split、merge 或 group 转换入口 |

## 开放海域、宽度与邻接

- “开放海域”只按拓扑判定：从目标水体沿共享边水体邻接能够到达地图边界。
- 开放海域判定不依赖旧 `type`、旧 `group` 或面积，旧分类不能覆盖真实连通证据。
- 海峡最小宽度为 `1` 个完整 grid cell；不能只翻转部分 grid cell，也不能用顶点接触或对角接触冒充通道。
- 所有连通检查只认共享边邻接。
- 每个被转换的 grid cell 对应的全部 pack cells 必须同步，不能留下 grid / pack 水陆或 feature 分叉。

## 保护对象与路线门禁

- 禁止翻转包含以下任一主体或关键点的 cell：city / burg、首都、省会、港口主体、河流源点或干流、路线端点、路线 waypoint。
- 操作影响港湾邻域时必须重新计算 `haven / harbor`。
- 如果重算后港口失效，或既有路线会被中断，整次操作拒绝并回滚。
- 不得为了让拓扑操作通过而静默删除港口、路线、路线端点或 waypoint。

## Feature ID、分裂与合并

- 未受影响 feature 保持原 ID 和活动引用，不因局部编辑全表重排。
- feature 分裂时，包含旧中心的分量保留旧 ID；其它新分量使用全局末尾追加的新 ID。
- feature 合并时，存在开放海域分量则由开放海域优先存续；否则由较大分量存续，面积相同时由较小 ID 存续。
- 退役 feature 保留 tombstone，ID 不压缩、不复用。tombstone 保留旧 ID、备注和兼容追溯所需的旧引用信息；活动引用按存续 / 新增映射同步。

## 同步与派生状态

- 专用操作在同一事务内同步 grid / pack 高度与 feature 归属、feature 记录、岸线、`haven / harbor`、水文引用、邻接、picking、标签、统计和导出语义。
- 其它受影响下游系统按既有领域契约标记 stale，不在本项内顺带扩大重生成范围。
- 岛屿、大陆、内陆湖和开放海域的 group / type 结果必须来自本次连通结构，不能沿用已经失真的旧派生值。

## 高度跨海平面规则

- 第 75 项会影响高度数据和跨海平面后的 feature 派生，但不改变现有普通高度编辑器的操作方式、交互或数值语义。
- 专用 `land -> water` 操作把目标高度写到 `19` 或以下；专用 `water -> land` 操作把目标高度写到 `20` 或以上。撤销必须精确恢复操作前的逐 cell 高度。
- 普通高度编辑没有跨越 `19 / 20` 时，只刷新高度表面，不触发本项专用拓扑流程。
- 普通高度编辑跨越 `19 / 20` 时仍按现有方式提交，同时把 Feature 和相关下游标记 stale；它不会自动套用开 / 闭海峡预检，也不会被改造成受约束海岸工具。
- 高度基础派生重建检测到跨海平面变化时，先复用第 75 项的 Feature / 岸线重建，再继续河流、国家、省份等后续重建。
- 第 75 项专用工具不等待另一次基础重建：高度、Feature、岸线和本项要求的同步必须在同一事务内立即完成。

## 事务、回滚与旧图兼容

- 只读预检、受约束预览和正式应用使用同一规则；预检失败不得修改地图或历史。
- 正式应用是一条命令、一个事务和一条历史记录。任一保护检查、拓扑校验、同步或最终不变量失败时，整次操作回滚。
- 撤销 / 重做必须恢复高度、feature、岸线、引用、派生 stale 和相关 UI 目标，不能重新分配首次成功时已经确定的 ID。
- 兼容旧图缺字段，以及 grid / pack 或其它相关数据存在共享引用或独立镜像的情况；同步时保持原有共享 / 独立形态。

## 明确禁止

- 禁止把整片开放海洋填成陆地。
- 禁止通过海岸雕刻让整座岛屿或整块大陆沉没。
- 禁止直接修改 `continent / island / isle / lake_island` group。
- 禁止在没有共享边连通证据时直接执行 `lake <-> ocean` 转换。
- 禁止消灭全部陆地或最后一个开放海域。
- 禁止提供无约束的水陆翻转画笔。

## 本项不覆盖

- 直接湖泊与湖泊合并、手工切分湖泊、多国水体等能力不在第 75 项范围内，也不作为本项新增完成条件。
- 这些事项只是本项不覆盖，不代表未来永久禁止；如需实现，应由后续权威计划另行冻结产品规则。

## 最小验收边界

- 本项沿用权威清单已经批准的最小验收：只读预检、受约束画布预览、单事务应用、非法拓扑不改图，以及撤销 / 重做、完整地图往返、专项回归、生产构建、`git diff --check` 和代表性开 / 闭海峡同一 Chrome 验收。
- 本冻结稿中的实现细化用于保证上述矩阵一致，不把未确认的其它水体操作扩成新的完成条件。
