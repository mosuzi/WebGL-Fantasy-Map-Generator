# 标签显示优先级与位置锁定

本文记录权威任务第 80 项的逐标签布局覆盖、碰撞顺序、世界锚点和存档契约。标签类型与排印字段继续复用 [`label-type-style-system.md`](label-type-style-system.md) 的五类 registry；本项不增加路线曲线文字、区域曲线标签或沿路径排版。

## 数据模型

- `map.labels.layout` 使用版本 1，覆盖键固定为 `state:<id> / province:<id> / city:<id> / custom:<id>`。
- 单个覆盖只允许 `priority` 和 `position`。优先级是 `0～100` 的整数；`position` 是有限的 `x / y` 世界坐标，存在即表示位置已锁定。
- 首都与普通城市继续共用稳定 `city:<id>` 身份，由第 69 项类型 registry 根据城市 `capital` 状态解析不同默认优先级和样式。
- 默认优先级为首都 90、国家 80、手工标签 70、省份 60、普通城市 50。没有用户覆盖时，renderer 继续使用既有派生分值、类型层序、碰撞和 LOD，不改变旧图自动行为。
- 旧 v1、旧 v2、JSON、gzip 和浏览器缓存缺少布局字段时回填空覆盖；未知键和坏值在当前文档严格校验中拒绝，宽容旧数据归一化时丢弃。

## 优先级、碰撞与 LOD

- 只要存在至少一个手工优先级，所有标签按“显示优先级降序 → 既有派生分值降序 → 稳定目标键”排序，再依次占用统一碰撞盒；相同输入重复布局顺序不变。
- 手工优先级同时有限调整该标签的最小缩放阈值，高优先级可更早进入候选，低优先级更晚进入；城市数量上限、国家高倍缩放淡出、图层可见性和屏幕范围继续生效。
- 优先级只决定候选与冲突胜出顺序，不绕过碰撞强制显示。选中的手工标签沿用既有可见例外，也不会造成迭代移动或无限避让。
- 清除最后一个手工优先级后立即恢复旧自动顺序和自动 LOD。

## 位置锁定

- “锁定当前位置”优先读取 renderer 当前标签锚点，并把它保存为世界坐标；隐藏标签没有实时节点时使用对象当前自动锚点作为回退。
- 锁定后，平移、缩放、主题切换、标签样式修改、刷新和完整地图往返继续从同一世界锚点投影。锁定不会绕过碰撞或 LOD。
- 解锁只删除位置覆盖，国家、省份、首都和普通城市恢复当前自动计算；手工标签恢复自身 `x / y`。
- 已锁定的手工标签拒绝画布拖动和编辑命令移动，必须先解锁。删除手工标签会同时删除布局覆盖，撤销删除则一并恢复，避免 ID 再用继承残留覆盖。

## UI 与 PNG

- 标签管理的“显示布局”动作提供优先级输入、恢复自动优先级、锁定当前位置和解锁位置；列表及详情明确显示自动 / 手工优先级和锁定状态。
- renderer DOM 节点记录解析后的优先级模式和锁定状态，实时画面始终使用解析后的世界锚点。
- PNG 继续读取同一 renderer 中 `.visible` 的国家、省份、城市和手工标签节点，因此类别、碰撞结果、位置、主题与排印样式和实时画面一致，不维护第二套布局。

## 回归边界

- `npm run regress:label-layout` 覆盖五类默认值、旧图自动分流、优先级排序与 LOD、重复排序稳定性、世界锚点锁定、单历史撤销 / 重做、锁定手工标签拒绝移动、删除覆盖清理、JSON / gzip / v1 / v2 往返、UI、renderer 和 PNG 接线。
- `npm run regress:label-styles` 继续覆盖主题与排印变化，地图迁移专项继续覆盖旧格式。
- 浏览器中的五类标签、缩放避让、主题 / 样式、刷新、保存恢复和 PNG 对照按用户最新工作流留到第 76～81 项代码全部完成后统一验证。
