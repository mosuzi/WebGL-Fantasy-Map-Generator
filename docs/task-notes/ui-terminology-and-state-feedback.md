# 界面术语、交互状态与恢复反馈

本文记录权威任务第 59 项的用户界面术语、共享交互状态和恢复动作契约。当前批准范围与状态统一查看 [`../current-plan.md`](../current-plan.md#权威任务清单)。

## 对象术语表

| 术语 | 界面含义 | 使用位置 | 不再使用的混合称呼 |
|---|---|---|---|
| 资源点 | 由资源生成链维护、参与经济摘要的资源类地图对象 | 图层、标记管理筛选、资源重生成 | 资源标记 |
| 通用标记 | 用户放置或非资源生成的说明性地图标记 | 图层、放置入口、标记管理筛选 | 标记（单独作为对象名时） |
| 资源点与通用标记 | 两类标记对象的管理总入口 | 控制面板、管理面板标题、列表操作 | 资源与标记管理 |
| 水体与地貌 | 水陆地貌统计领域总入口 | 控制面板、统计面板标题 | 水体统计 |
| 地貌单元 | 内部 `feature` 在普通界面的业务称呼，包含陆地、水域和湖泊单元 | 水体与地貌列表、空态、详情 | feature |
| 湖泊 | 可独立定位、编辑和删除的内陆水体对象 | 湖泊管理 | 水体 / feature 的混用 |
| 测量 | 创建和编辑临时测量路径的地图工具 | 地图工具栏、测量读数 | 测量对象（用作创建动作时） |
| 测量对象 | 已保存、可管理、定位和导出的测量记录 | 管理入口、对象面板、图层与导出 | 对象、测量（用作记录名时） |

内部 schema、API 和调试输出仍可保留 `feature / marker / measurement` 字段名，本表只约束普通用户界面。

## 共享交互状态

| 状态 | 视觉语义 | 退出方式 |
|---|---|---|
| 已选中 | 蓝色行选中态，表格行同步 `aria-selected` | 选择其它对象；批量选择使用复选框清除 |
| 编辑中 | 琥珀色动作与二级编辑面板，标题显示“编辑中” | 再次点击动作、点击统一关闭按钮、点击外部或 Esc |
| 预览中 | 紫色状态横幅或预览容器，明确说明尚未提交 | 点击“退出预览”或各预览自身的取消动作 |

选中只改变当前上下文，编辑会准备可提交输入，预览不得写入历史；三者不能只依赖颜色，均有文字或可访问状态。

## 空态、异常态与恢复动作

- 无筛选结果：对象表格显示空态和“清空筛选”；所有带筛选的对象表格都必须接入该动作。
- 暂无数据：支持创建的面板提供“新建 / 放置 / 开始测量”；只读统计面板只说明当前没有可展示的数据，不伪造创建能力。
- 孤儿备注：明确说明原对象缺失、仍可导出，并提供“删除这条孤儿备注”。
- 待派生：高度面板显示待派生横幅，提供“重算基础派生”和“重算下游派生”。
- 操作失败：文件操作状态标记为错误，保留诊断详情并显示“清除错误并重试”；清除只重置反馈，不修改地图。

## 验收覆盖

- `pnpm run regress:ui-terminology-state`：检查术语、共享状态属性、恢复动作和全部筛选表格空态。
- `pnpm run regress:ui-terminology-state-browser`：检查地貌、标记、测量、选中、编辑、预览、筛选空态与导入失败恢复路径。
- 既有 `regress:control-ia`、`regress:action-ia`、`regress:selection-scroll-center`、`regress:height-brush` 和 `regress:map-import-diagnostics` 继续守护原行为。
