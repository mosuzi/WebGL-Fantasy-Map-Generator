# 第 204 项缺口实施与规则审阅说明

> 状态：用户已于 2026-07-28 整体批准。本文是权威任务第 207～210 项的施工图和人类审阅入口；唯一当前队列仍以 `docs/current-plan.md` 为准。

## 一、这批要完成什么

第 204 项已经证明控制台“有方法可调用”不等于 AI 能安全执行一个玩家意图。本批把审计中尚未闭环的能力按依赖顺序补齐：

1. 为 `24` 个已有写命令增加只读领域 inspector；
2. 把 `5` 个必须串联多个 API 的意图收敛成原子规则事务；
3. 为 `6` 个规则空白确定玩家规则并实现；
4. 把 `10` 个战略目标发布为可逐步执行的 AI 规划器配方。

这不是新增一套远程控制系统，也不会开放 `execute(action, arbitraryPayload)`。公开入口继续按领域命名，底层复用同一 revision、inspection token、EditHistory、地图快照事务和 API 描述体系。

## 三、统一规则事务契约

每个领域动作采用同一语义：

- inspector 是纯读取，不改变地图、历史、revision、selection、相机或渲染状态；
- 成功预检返回规范化输入、受影响对象、是否需要确认、`expectedRevision` 和绑定动作与输入的 `inspectionToken`；
- 参数错误或运行时错误使用失败包络；游戏规则不允许使用 `ok: true / allowed: false / code`；
- 执行前同时复核地图 identity、revision、动作、规范输入和 token；
- 成功恰好写入一条历史并使 revision `+1`，no-op 和拒绝不递增；
- 任一中途异常恢复整图、历史、revision 和运行时忙碌态；
- 旧调用没有 token 时继续按原行为执行；新增 AI 规则入口则强制 token。

## 四、自主冻结的六项游戏规则

用户已授权依据现有模型自行决定。以下默认规则优先保持确定性、可撤销和旧图兼容。

### 4.1 省份合并

- 仅允许同一有效国家内、通过陆地 Cell 相邻的两个或多个省份合并。
- 默认保留显式 `targetProvinceId` 的身份；其余省份墓碑化，全部 Cell、城镇和省会归入保留省。
- 新省会优先使用显式 `capitalCityId`，否则保留目标省会；目标省会无效时选择合并范围内人口最高的城镇。
- 合并后省份必须连通、非空，国家省份列表、城镇省份镜像和统计同步更新。

### 4.2 省份拆分

- 输入为源省份和一个连通、非空且不覆盖全部源省的 Pack Cell 集。
- 新旧两侧都必须陆地连通；每侧至少有一座城镇，避免产生无法管理的无中心省份。
- 新省会优先使用显式 `newCapitalCityId`，否则选择新区人口最高的城镇；原省会必须留在原侧，否则从原侧重新选择。
- 新省使用稳定递增 ID 和现有省份命名策略；旧图不新增必填字段。

### 4.3 宣战

- 两个有效、不同且当前不处于 `Enemy` 的国家才可宣战；宗主与其附庸不得互相宣战。
- 单事务把双边关系设为 `Enemy`，写入外交纪事，并调用现有战争一致性逻辑建立或刷新军事活动上下文。
- 宣战本身不自动移动军团、不转移领土、不结算人口。

### 4.4 议和

- 仅允许当前双向为 `Enemy` 的国家议和。
- 默认关系恢复为 `Neutral`；可明确指定当前外交模型支持的非战争关系。
- 可选领土、省份或宗藩条款必须调用同一事务内的已冻结规则原语；任一条款失败则整份议和回滚。
- 首版赔款只作为结构化和平条款和纪事记录，不直接修改经济库存或国库；真实经济结算需要单独授权扩展经济模型。
- 战争派生、战区和活动上下文统一关闭或清理，纪事记录结果摘要。

### 4.5 宗藩变更

- 使用现有 `Suzerain / Vassal` 逆关系，不新增第二套宗藩存储。
- 一个国家同一时刻最多有一个直接宗主；禁止自指和沿宗藩链形成循环。
- 建立或转移时，宗主看附庸为 `Vassal`，附庸看宗主为 `Suzerain`；解除后双方恢复显式指定的普通关系，默认 `Neutral`。
- 处于直接战争的国家对不能同时建立宗藩；其它外交关系不自动级联改写。

### 4.6 真实战斗结算

- 复用现有军团战斗事件、双方军团定位、兵力和 `BATTLE_RESULT_RULES`，不另建平行战斗模型。
- inspector 必须确认双方军团存在、分属不同国家、国家处于战争、双方兵力为正且空间上处于同一战区或允许的接触范围。
- 结算使用显式结果或确定性种子；同时处理双方伤亡、态势、撤退 / 重整、战斗纪事和相关战区。
- 伤亡不能使兵力为负；领土占领不是战斗结算的隐含副作用，需由后续领土事务显式提交。
- 首版只做玩家或 AI 显式触发的单次确定性结算，不恢复实时模拟、自动时间推进或无限战役循环；联盟参战由配方逐步编排，单次事务只结算明确的双边参战军团。
