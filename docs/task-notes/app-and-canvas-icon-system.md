# 应用图标 A 与画布图标系统施工图

## 来源与目标

用户从多版应用图标中选择 A 方案，并要求进一步整理所有画布内图标：当前相似的城镇等级需要明显区分，资源点等其它语义图标也要有辨识度、彼此好区分且风格统一。第 265 项进一步明确大型城市必须直接采用 A 方案圆盘内的环城城池语言，其它城镇基础剪影与之统一；应用图标只保留补全后的中央圆形地图，外部方框和朱红方印均删除。本专题只服务权威任务第 263～265 项，不建立额外待办。

## 调查结论

### 应用图标链

正式链由用户原图母版 `app/webgl-generator/public/app-icon-master.jpg`、自包含母版的 `app-icon.svg`、六份派生 PNG、`index.html` 和 `site.webmanifest` 组成。生成脚本覆盖 `32 / 64 / 180 / 192 / 256 / 512px`，入口和文件名保持；静态回归冻结母版摘要并解码 SVG 内嵌图像逐字节比对。

A 方案以用户提供的 `1280×1280` JPEG 为唯一视觉真值：海岸比例、双峰、分叉河流、环城虚线路线、圆形城池、树林、旧纸纹理、墨绿边框与朱红方印均不得重画或简化。正式资源只允许等比缩放和格式封装；manifest 使用 `purpose: any`，避免系统 maskable 裁切完整方形构图。

第 265 项保留上述 JPEG 作为原始来源，不覆盖或重编码；用户明确撤销“外框与朱印必须保留”的旧构图要求。正式资源改从新增透明圆形派生母版生成：删除外部墨绿方框和朱红方印，补全圆盘外缘、纸面与附近地图内容。首轮机械拼接稿在右下出现色阶接缝并被独立审查阻断，因此最终资源采用以原图为唯一参考的完整圆盘高保真派生稿；原始 JPEG 继续冻结身份与构图来源，但不再宣称派生稿未遮挡区域与原图逐像素一致。

### 画布图标分母

正式重设计分母为 `80` 个稳定图形键：

- 城镇 `9 + 3`：`capital / provincial / port / city / town / village / hamlet / fort / camp` 九个基础剪影，加首都、省会、港口三个附加徽记。自动人口等级只有 `city / town / village / hamlet`。
- Marker `58`：自然 `4`、资源 `26`、水文 `1`、设施 `3`、商旅 `2`、危险 `7`、异象 `5`、文化 `8`、活动 `2`。
- 军事 `10`：`fleet-large / fleet-small / archers / archers-heavy / cavalry / cavalry-heavy / infantry / infantry-heavy / mountain / artillery`。

当前 `58` 个 Marker 只复用 `16` 个内部 symbol，且全部套同一 pin 外框；`life` 被 `13` 种类型共用，`danger` 被 `8` 种类型共用，是资源与地标难以区分的直接原因。军事十种图已有语义差异，但高细节 PNG 被压缩到 `20px` 观察尺寸，与城镇和 Marker 的扁平制图语言不一致。

战线箭头、洋流箭头和三类远景圆点只检查统一描边、红蓝 / 水系语义与 LOD 过渡。选择圆环、测量点、诊断 cell、编辑手柄、标签、HUD、图例、比例尺、边界与普通线层不进入图标重画。

## 视觉语法

### 城镇

- 村落：单体小屋，外框最窄。
- 村庄：两栋错落民居，横向展开。
- 城镇：民居围绕明确的中心建筑或街道，形成中等密度轮廓。
- 城市：城墙、城门与塔楼群形成连续天际线，不能只靠增加一栋房表达。
- 港镇、寨堡、营帐等手工剪影保留独立结构；文化风格只改变同等级建筑语言和配色。
- 首都、省会、港口继续使用可组合角部徽记，不参与人口等级与基础尺寸计算。

### Marker 与资源点

采用三层语言：底牌保持统一地图点位锚定，外框和类别色表达九个家族，内部轮廓表达具体类型。`58 / 58` 注册类型必须有显式图形键；同一类别内不能再靠通用叶子、警告三角、星星或镐头覆盖多个对象。受控 SVG 不包含文字、emoji、外部图片或任意 HTML。

### 军事

十个资产键和旧字符别名保持不变；在现有军团标签中统一观察尺寸、轮廓粗细、留白和明暗。步兵 / 弓兵 / 骑兵 / 器械 / 舰队 / 山地兵使用不同一级轮廓，重装与大小舰队使用稳定的二级标识，不改变军团生成和判定。

## 单一来源与旧数据

新增画布图标注册表并从中派生 renderer 和 Marker 管理面板选项。自动 Marker 以 `type` 解析新默认；旧图中 `manual !== true` 的老 symbol 只作历史字段，不阻止视觉升级。手工 Marker 保留旧 `16` 个 symbol 和安全 fallback，九个城市手工剪影、十个军事键及其旧字符别名继续可读。

本批不迁移或重写存档，不改变对象 ID、人口、角色、资源经济、生成概率、picking、碰撞、图层开关、公开 API 或 GeoJSON。DOM 与 PNG 继续消费同一 SVG / 图像来源，调整尺寸时同步碰撞盒和标签净空。

## 验收矩阵

- 静态分母：`9 + 3 + 58 + 10 = 80`，注册表、生成器、renderer 与面板双向差集为 `0`。
- 图形完整性：全部注册类型可渲染；资源点、同类别 Marker 和城市四级基础轮廓没有意外重复指纹；无文字、emoji、字体或外部网络资源。
- 兼容：旧自动 / 手工 Marker、城市手工视觉、军事旧别名、JSON、gzip 与浏览器缓存保持；地图 checksum、历史和对象语义不因纯渲染升级改变。
- 视觉图鉴：九个城镇剪影、三角色及组合、六种文化风格、58 个 Marker、十种军事图标、远景圆点、战线和洋流方向符号。
- 真实行为：阈值、选中、城市—资源重叠弱化、军事—城市标签避让、图层隐藏、picking、DOM / PNG 同源均保持。
- 浏览器：系统 Chrome 覆盖 `1440 / 390 / 320px` 和一张真实 `10k` 地图；application console、page、health 与 WebGL error 为 `0`。

## 排除

不修改 `source/`，不新增当前不存在的画布对象图标，不重做文字、标签、线层、面板信息架构或导出选项，不改地图数据和生成语义，不提交或推送。

## 第 265 项返工约束

- 应用图标原始 JPEG 继续冻结摘要；圆形派生母版另行冻结尺寸、格式与摘要，四角必须透明，圆盘外不得残留墨绿方框或朱印红块。
- 城市一级轮廓固定为椭圆环城墙、正面城门、中央尖顶高塔和墙内屋舍；其它八个基础键复用同一线宽、墙体、屋顶、轻俯视与留白语言，但保留单屋、村庄、城镇、都城、省会、港口、寨堡和营帐的语义差异。
- 优先保持既有 `34×26` 观察盒、锚点、碰撞盒与标签净空。人口阈值、P90、角色徽记、文化调色、手工视觉、旧图格式与地图数据不得随纯视觉返工改变。
- 验收除原有注册表、图鉴和真实地图矩阵外，新增圆形透明度、红色残留、右下补全接缝、城市城墙 / 城门 / 高塔 / 屋舍结构和 favicon 缓存后的实际资源字节检查。

## 完成结果

- A 方案原始 JPEG 与用户附件均为 `103496 bytes`，SHA-256 同为 `50c20b1e8d908b0a45e91988e5421a0792d9f4570db7a504de91205851ab771d`，第 265 项未覆盖它。当前 SVG 改为内嵌 `1024×1024` RGBA 透明圆形派生母版，摘要为 `26a13c843177d3c094b8e3b7b4cc2f9b8364e20e0e07b2d4e14e99925e1ededb`；六档 PNG 由该母版确定性缩放生成，外部方框和朱印均为零残留。
- 画布注册表固定 `9 + 3 + 58 + 10 = 80` 个稳定键；Marker、四级自动城镇、军事结构指纹为 `58 / 4 / 10`，资源点 `26`，九类底牌均有不同一级轮廓。
- 首轮复核阻断的自动 Marker 面板旧 symbol、角色组合、六文化和军事正式样式覆盖均已限修，原审查者终验为 `ACCEPT`。
- 系统 Chrome 图鉴在 `1440 / 390 / 320px` 均为 `80` 个稳定卡加 `7` 个附加展示卡，无裁切或横向溢出。真实 `10004` grid cells 地图模型 / DOM 同为城镇 `839`、Marker `44`、军事 `114`；Marker 拾取、PNG 同源和 checksum / revision 不变通过，console、page、health 与 WebGL error 为 `0`。
- 第 265 项重画九个基础城镇剪影并保持原键、`34×26` 观察盒、角色组合与兼容链；九个几何指纹为 `9 / 9`，大型城市的双闭合环墙、正门、中央尖顶高塔和两组墙内屋舍均有直接 path 门禁。首轮独立审查阻断圆盘接缝、缓存回归和元数据伪指纹后，三项均已限修，原审查者与终轮观察使均为 `ACCEPT`。
