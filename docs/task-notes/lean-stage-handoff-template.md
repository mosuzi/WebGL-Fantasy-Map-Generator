# 精简阶段交接模板

本模板用于长任务 checkpoint、委派 brief 和新会话恢复。只填写当前阶段必需信息；完整日志、trace、截图、矩阵和大 diff 留在本地 artifact，不粘贴进交接。

## 任务包

| 字段 | 内容 |
| --- | --- |
| 权威编号与目标 | `<编号；一句话目标>` |
| 当前阶段 | `<单一可交付切片>` |
| 冻结点 | `<分支 / commit / 未提交状态>` |
| 允许文件 | `<精确文件或目录>` |
| 禁止文件 | `<产品、source、Wiki、共享核心等>` |
| 必须保持 | `<身份、兼容、锁、回滚、性能等不变量>` |
| 最小验收 | `<本阶段必须真实通过的门>` |
| 首个廉价门 | `<最快暴露错误的命令>` |
| 停止条件 | `<首败、重复失败、范围变化、需产品裁定>` |

## 阶段结果

- 状态：`ACCEPT / BLOCK / IN PROGRESS`
- 完成：最多五条。
- 产品改动：文件数、增删行数；没有则写 `0`。
- 工具 / 文档改动：文件数、增删行数；没有则写 `0`。
- 已过门禁：命令与关键数值。
- 首败或阻断：分类、精确证据、不得声称的结论。
- artifact：只列路径与用途。
- 延后记录：仅列不影响当前阶段的发现。
- 下一步：一个阶段、一个首个廉价门。

## 委派附加字段

- 角色：`调查 / 集成复核 / 最终验收`。
- 只读或唯一写者：明确写出。
- 上下文：默认 `fork_turns: "none"`，只传本任务包和必要 artifact 路径。
- 返回：调查结论或 `ACCEPT / BLOCK`；不得复制完整日志，不得派生子智能体。
