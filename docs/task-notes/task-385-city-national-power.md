# 第 385 项：城市发展参与国力

## 1. 实施前调查

基线 `9831659 / 0.5.99`。正式国力在 `generator/economy.js:refreshPoliticalEconomicPower` 计算，外交、军事和国家 / 政体面板消费 `powerScore`。现有国力含人口、领土、城镇数量、经济、资源和资源点；城市产出经交易税间接影响国库，但城镇贡献只看数量。

`analysis.comparePower` 是区域代理分析，与正式国家国力不同，本项不改变其契约。既有国家军团由国力参与生成，因此本项不反向把军队规模计入国力，避免反馈循环。

## 2. 完整功能方案

保留国力其余组成，把原城镇数量项升级为“有效城镇发展量”。国家、省份均按实际归属聚合有效 burg，每城只算一次；忽略已删除城市，缺字段按零，非法 / 负数按零。省份归属缺失时从所在 pack cell 回退，显式 0 保持中立。

每座城镇贡献 `q = 1 + 人口项 + 产出项 + 财富项 + 设施项 + 交通项`：

| 项 | 公式 / 分值 | 用意 |
| --- | --- | --- |
| 人口 | `min(1.5, 0.15 × ln(1 + 当前内部人口))` | 总人口仍计原人口项，此处小权重反映城市集聚规模，不使用潜在人口 |
| 产出 | `min(2, 0.20 × ln(1 + 当前 product))` | 已实现生产能力，收益递减 |
| 财富 | `min(1, 0.10 × ln(1 + 当前城市 treasury))` | 地方积累，与国家实际税收分开，小权重封顶 |
| 设施 | 首都 `0.25`、贸易中心 `0.25`、要塞 `0.30`、城墙 `0.15`、港口 `0.20`、神庙 `0.10` | 行政、集散、防御、航运和公共服务条件，直接相加，不再乘一次经济加成 |
| 交通 | 已有主干路 `0.25`、小路 `0.10`、合法港口已有海路 `0.20` | 按实际经过该城镇 cell 的路线；同类多条只算一次，未连通不凭属性造连接 |

国家城镇分数 `20 × sqrt(所属城镇 q 总和 / max(1, 世界国家平均实际城镇数))`；省份采用 `16` 权重及省份平均数。基础数量来自同一有效城市清单，避免旧统计失配。质量上升不会随平均质量同涨被抵消；数量相同、人口 / 产出 / 设施更好的国家获得更高城镇贡献。没有城市时贡献为零，单一国家也能体现升级。

设施系数为产品规则，不是历史统计或战斗模拟。经济产出先在经济重算中生成，国力随后读取实际结果；潜在人口、兵额、尚未生成的道路均不当作现有实力。无需新存档字段，继续写 `settlementPower` 和 `powerScore`；国家 / 省份详情增加“城镇贡献”展示。

### 生效与保护

- 改属性、手工人口不立即重算国力；沿用正式经济 / 国力刷新入口，外交继续消费最后一次已计算的国力。
- 不改变税收和军队公式，不在城市上再次套人口或经济设施倍率。国家锁 / 省份锁保护的评分字段原样保留。
- 正式经济命令及其计算结果提交、独立 politics / pack 镜像、撤销重做、旧档保存回读继续使用现有字段路径，无额外迁移。
- 只遍历城镇和现有路线格一次，禁止按国家反复扫描全部路线，不改 `source/`。
