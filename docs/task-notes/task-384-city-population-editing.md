# 第 384 项：城市人口编辑与即时统计方案

本文件是实施前建立的完整功能与验收方案；活动状态只看 [当前计划](../current-plan.md)。依赖第 383 项完成交付，不合并编号。

## 1. 现状

- CityPanel 已有隐藏在操作栏中的人口编辑器，但直接显示内部人口单位。显示函数以 `内部值 × 1000 × populationScale` 换算为“人”，当前输入容易被误解。
- `createSetCityPopulationCommand` 写 city / burg 并刷新城市大小，只重算 `politics.states.urban`，未覆盖省份、文化、宗教和非同一数组的 pack 镜像。
- 原统计逐城四舍五入到两位内部单位，细小人口变化可能被吞掉；撤销通过重新汇总，而非保存全部被写统计字段，旧数据不一定精确恢复。

## 2. 功能梳理

1. 选中城市时在详情附近直接展示人口输入和“应用人口”，输入单位明确为“人”，步长 `1`，支持 `0`，上限 `1,000,000,000` 人。保留操作栏入口作为同一编辑器的定位入口，避免两套状态。
2. 用当前显示倍率做双向换算；不改公开 `edit.city.setPopulation` 的内部单位约定。保留足够内部精度，使倍率 `0.1 / 1 / 10` 及非整倍率下输入 / 显示往返不丢一个人。
3. 空白、NaN、Infinity、负数、超上限、删除城市、缺失合法 burg 拒绝，不生成历史。相同值 no-op，不把空输入静默当 `0`；应用有明确成功 / 失败反馈，忙碌时禁用，切换城市清理旧反馈与输入。
4. 应用后 city.population 与 burg.population 同步，立即重算所选城市所属国家、省份、文化、宗教的 `urban`，覆盖 politics / society 与 pack 的独立镜像数组；以当前有效城市为权威城镇载体，忽略删除对象。
5. 乡村人口 `rural`、grid / pack cell pop 不变，行政区总人口仍为 `rural + urban`，不改人口空间分布。刷新城市总人口、最大人口、大小 / 标签排序，以及已打开国家、省份、人口统计面板。中立 ID `0`、无省份城市不崩溃，不越界创造行政区。
6. 手工人口独立于潜在人口，不隐式设置锁或属性。第 383 项“按条件重算人口”共用同一统计路径；以后显式重算允许覆盖手工值，属性切换不会覆盖。
7. 人口变化不直接改经济 product / treasury、军事兵额或道路。界面说明这些值需相关重算，不承诺模拟自动发生。
8. 单一历史：保存实际写入字段的 before / after（含原缺字段），失败原子回滚，撤销 / 重做精确恢复人口、大小、受影响统计与镜像；不靠撤销时重新估算旧档。旧档正常保存 / 回读，公开 API 与 UI 一致。

## 4. 逐项验收

- `384-F1` 按“人”输入，倍率换算正确，0 与上限可用，非法输入精确拒绝，不变值 no-op。
- `384-F2` city / burg 同步；国家 / 省份 / 文化 / 宗教的城市人口与总人口即时正确，独立镜像更新，乡村值不变。
- `384-F3` 未所属 / 中立 / 删除对象 / 旧档缺字段处理正确，无悬空统计写入。
- `384-F4` 原子失败、单历史、精确 undo / redo，不累积舍入误差；保存回读和 API 一致。
- `384-F5` 城市规模 / 自动图标和排序即时更新，手工视觉覆盖保持；设施、地形、路线、经济与军队不变。
- `384-F6` UI 同时检查城市、省份、国家和人口统计面板；倍率 `0.1 / 1 / 10`、键盘、切换城市、窄布局和忙碌状态。
- `384-F7` 小图后大图真实入口，目标 error 为 0，LongTask 遵守仓库规则，不用生成新图替代用户当前图操作。
- `384-F8` 一个只读智能体逐项对照此方案给出最终结论，接受后归档、递增版本、中文提交与推送主线。
