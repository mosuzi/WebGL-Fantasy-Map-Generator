## 用户原则冻结

- 错误目标对象直接删除，不得拿来阻塞主动重生成。
- 锁定对象对生成阶段不可见；生成完成后按稳定身份原样并回，不再走生成限制验证。
- 上游数据之间多数是软关联：缺失、陈旧或局部不一致时优先清空、降级、局部推导或后续重建。
- 基础物理和可提交结构仍是硬门，例如城镇落海、陆路穿海、河流海中凭空流动、非邻接路径、非有限坐标、不可读容器、重复身份和事务无法回滚。
- 普通生成与重生成必须共用同一关系分类；不得只在入口吞错而保留下游过重依赖。
