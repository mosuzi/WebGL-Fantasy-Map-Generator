# 第 328 项：大河政治边界分阶段施工冻结

## 权威目标

新图政治生成及用户明确触发的国家 / 省份重生成，把 canonical 河网作为可审计软阻隔。强而连续的大河可以优先形成省界，并在两岸均有合法中心和连通腹地时形成国界；弱河、短支流和单侧无中心情形不得制造碎片。河流不因行政结果被改写，旧图载入、普通渲染和手工边界不自动重划。

## 证据与统一模型

- 现有 pack 国家扩张只用目标 cell 的 `riverId / flux` 形成单点成本；整图分省只有高程成本，按国家局部重分省则是无权 BFS。国家与省份后续还有边界毛刺吸收，单独调大旧 `riverCost` 会被后处理抹平。
- canonical 河流已经提供 `cells / gridCells / parent / basin / flux / width / length / type`；pack cell 提供 `r / fl`。河流等级由 parent 关系确定性派生，不新增持久化河网字段，不按 river ID、像素宽度或数组顺序决定强弱。
- 新增共享纯模块建立每条河与每个河流 cell 的 `0..1` 阻隔分数。分数综合对数流量、宽度、连续长度、父子等级和有效连续率；强河阈值、弱河阈值及各分量进入结构化诊断。无河或资料不全时成本为零并回退既有语义。
- 过河成本作用于从岸地进入河流 cell、从河流 cell 离开到岸地或跨不同河段的相邻转移；沿同一条河纵向移动不重复计费。正式道路连续边与河港只降低成本，不把强河变成零成本硬通道。
- 国家、省份和按国家局部重分省必须复用同一转移函数。锁定 cell / 国家 / 省份优先；中心、首都、省会和城镇仍为保护锚点。边界整理只允许在不会跨越更强河障、不会改锁对象且不会破坏中心连通时吸收毛刺。

## 阶段边界

### A：纯核心与生成器接入

- 新增共享河障模型、道路 / 港口走廊折减、边界采用诊断和纯数据夹具。
- 接入 `politics.js` 的新图 pack 国家、省份扩张与对应边界整理；grid 降级路径复用同一河流评分的 grid 投影。
- 非目标：不改 Worker 协议、runtime command、renderer、存档 schema 或浏览器夹具。
- 最小门：强 / 弱同几何、短支流、多汇流、道路、港口、单侧中心、锁定、无河；强河合格段边界采用率至少 `70%`，弱河不强制分裂，确定性 checksum 固定。

### B：重生成、局部重分省与诊断

- 国家、全图省份及按国家局部重分省复用共享模型；Worker 与 main fallback 输出相同诊断。
- 诊断记录候选数、强 / 弱河数、边界段、沿河边界长度、跨河行政邻接、道路 / 港口走廊和采用 / 回退原因，只进入结果 details、政治 metadata 与开发日志。
- 保留既有事务、锁、撤销 / 重做、取消、迟到结果与失败回滚；河流、道路与 picking 数据只读。
- 最小门：既有国家 / 省份锁专项、局部重分省、Worker 十一类和故障注入全部通过，河网 / 路线引用与字节不变。

### C：真实入口

- 固定 `10k / 50k / 100k` 新图、国家重生成、省份全图 / 单国重生成，锁边界段、两岸中心、连通、未分配、飞地 / 长条退化和确定性 checksum。
- 浏览器覆盖撤销 / 重做、取消、Worker fallback / fault rollback；河流 / 道路 / picking / GPU 同源，普通文案不出现算法术语。
- 先小数据真实入口，再代表性 100k；每个浏览器门首败即停，只允许一次窄诊断和一次目标复验。完整验收后才进入一次独立集成复核和一次最终观察使。

## 非目标与停止条件

- 不改 `source/`、河流生成、河道几何、流域、河流控制点、手工政治编辑或旧存档载入语义。
- 不为提高沿河比例牺牲行政中心、锁、连通性或制造碎片；若强河目标与合法政治结构冲突，记录回退而不是拒绝整次生成。
- 若同一夹具连续两次失败或代表性浏览器门在一次窄诊断和一次复验后仍失败，冻结并重新裁定，不继续扩写单体工具。
