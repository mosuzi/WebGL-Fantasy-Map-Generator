# 项目应用图标专项

本文冻结权威任务第 257 项的设计与接入边界，并记录第 258 项补齐的派生尺寸。

## 设计目标

- 图标以“地图”而非字母缩写作为第一识别对象，避免再次引入 FMG 语义。
- 主色沿用正式界面的墨绿色与旧纸米色，右下角用朱红小方块呼应加载页印章；图形不包含文字、字体和原作资产。
- 轮廓须在 `16px` favicon 下成立，细节只用于 `64px` 以上尺寸，不依赖渐变和滤镜维持主体识别。
- 正方形安全区兼顾浏览器标签页、桌面快捷方式和移动设备圆角裁切。

## 接入范围

- `app-icon.svg` 作为可维护主稿和现代浏览器 favicon。
- 生成 `32 / 64 / 180 / 192 / 256 / 512px` PNG，其中 `64px` 补充高分辨率 favicon，`180px` 用于 Apple Touch Icon，`192 / 256 / 512px` 写入 Web App Manifest。
- 正式入口声明 favicon、manifest、Apple Touch Icon 和与背景一致的主题色；Vite 通过 `public/` 原样发布资源。

## 验收

- 静态门禁核对 SVG 结构、PNG 尺寸、manifest 路径和入口声明。
- 生产构建后逐个确认资源存在且内容类型正确。
- 真实 Chrome 验证标签页请求、manifest、桌面 / 窄视口页面健康状态，并以单独图标预览检查小尺寸可读性。
