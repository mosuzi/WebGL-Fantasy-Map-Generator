# 第 371 项：国界颜色柔化回溯与实验室对照

## 问题与目标

第 370 项把初次载入时曾短暂出现的国家颜色过渡误实现为九道偏移轨道。用户把宽度和强度拉满后，画面仍缺少朦胧感，并在锐角、凹角和边界转折处出现三角色块与突变。问题不是参数上限，而是先沿原始折线法向外扩、再分别平滑多条轨道的几何路线会保留并放大法向不连续。

本项不继续修改正式 renderer。先在隔离旧提交中复现历史效果，再把可比较的算法放入现有共享边界拓扑实验室，让视觉选择发生在低成本、确定性的固定夹具上。

## 候选与判据

1. **第 370 项九轨羽化**：作为已否决基线，必须在夹具中保留其锐角三角和轨道突变，避免后续只凭描述比较。
2. **历史单带过渡**：按旧提交的两侧偏移、路径平滑、跨带颜色插值和统一低 alpha 精确复刻；用来确认用户记忆对应的观感，不默认视为最终方案。
3. **连续朦胧候选**：先把共享中心线变成连续曲线并重新计算法向，再构建颜色过渡和软 alpha；另评估屏幕空间模糊是否更接近“雾化”且不产生几何尖刺。

硬诊断包括非有限坐标、四边形翻面、相邻截面法向反转、过长尖刺、共享端点裂缝和三方交汇孔洞。视觉评审至少同时提供默认尺度和近距离放大，不能只给像素差比例或同色粗线。

## 阶段 A：历史回溯结论

- 隔离 worktree 固定在 `60584a5256d4e85768923ae327f578f79fe723fa / v0.5.67`（第 358 项），路径为 `Z:\tmp\codex\2026-08-29\task-371-state-border-blend-lab\old-60584a5`；当前任务分支没有切离最新 `main`。
- 旧画面来自 `buildPlaceholderSurfaceBundle` 的 fallback：`smoothCellBorders && !useCellVisualMesh` 时调用 `pushPoliticalVisualBands`。它只在 GPU resident surface 尚未接管的加载阶段出现，随后稳定路径替换该 surface，因此形成首次可见但不可由开关恢复的第三态。
- 旧算法不是多轨羽化：先沿每点 `sideVectors` 向两侧各偏移半宽，再分别做一次 `factor = 0.18` 的 Chaikin；单个四边形带的两侧顶点分别使用相邻国家颜色，GPU 在带宽内连续插值，最后统一把 alpha 写成 `0.25`。
- 第 370 项改为九个偏移样本、八层四边形带，每条轨道独立平滑。匿名锐角夹具的同一翻面风险因此从历史单带的 `24` 个三角面放大为 `192` 个，且仍保留 `4.53%` 截面宽度突变；这与用户截图里的尖片和突变一致。
