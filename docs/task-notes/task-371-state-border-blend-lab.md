# 第 371 项：国界颜色柔化回溯与实验室对照

## 问题与目标

第 370 项把初次载入时曾短暂出现的国家颜色过渡误实现为九道偏移轨道。用户把宽度和强度拉满后，画面仍缺少朦胧感，并在锐角、凹角和边界转折处出现三角色块与突变。问题不是参数上限，而是先沿原始折线法向外扩、再分别平滑多条轨道的几何路线会保留并放大法向不连续。

本项不继续修改正式 renderer。先在隔离旧提交中复现历史效果，再把可比较的算法放入现有共享边界拓扑实验室，让视觉选择发生在低成本、确定性的固定夹具上。

## 候选与判据

1. **第 370 项九轨羽化**：作为已否决基线，必须在夹具中保留其锐角三角和轨道突变，避免后续只凭描述比较。
2. **需求前颜色带**：按 `1af5381 / v0.5.4` 的两侧偏移、路径平滑、跨带颜色插值和统一 `alpha = 0.25` 精确复刻；用来确认用户记忆对应的观感，不默认视为最终方案。
3. **连续朦胧候选**：先把共享中心线变成连续曲线并重新计算法向，再构建颜色过渡和软 alpha；另评估屏幕空间模糊是否更接近“雾化”且不产生几何尖刺。

硬诊断包括非有限坐标、四边形翻面、相邻截面法向反转、过长尖刺、共享端点裂缝和三方交汇孔洞。视觉评审至少同时提供默认尺度和近距离放大，不能只给像素差比例或同色粗线。

## 阶段 A：历史回溯结论

- 首轮选择 `60584a5256d4e85768923ae327f578f79fe723fa / v0.5.67` 是错误时间锚点；用户提出疆界柔化样式前的实际父提交为 `1af53817b51fc4bdf01bfaa9d35fd6404ddd4395 / v0.5.4`，隔离 worktree 为 `Z:\tmp\codex\2026-08-24\map-unseal-performance\baseline-worktree`。更早的主线 `4ed66e4`（第 128 项边界平滑调研前）也包含同一政治颜色带，但不能直接读取后来的代表存档。
- 旧画面来自 `buildPlaceholderSurfaceBundle` 在国家视图调用 `pushPoliticalVisualBands`；`STATE_VISUAL_STYLE.bandWidthWorld = 7`。真实 `v0.5.4` 页面加载同一 `krichars (3).webfmg` 后，放大近景可见宽、低对比、连续的国家色过渡，观感接近屏幕空间朦胧；此前“只在首次 fallback 出现、随后被接管后消失”的结论没有被真实证据支持，现已撤回。
- 旧算法不是多轨羽化：先沿每点 `sideVectors` 向两侧各偏移半宽，再分别做一次 `factor = 0.18` 的 Chaikin；单个四边形带的两侧顶点分别使用相邻国家颜色，GPU 在带宽内连续插值，最后统一把 alpha 写成 `0.25`。
- 第 370 项改为九个偏移样本、八层四边形带，每条轨道独立平滑。首轮匿名夹具自身在三方节点下方有第二个非法交叉，导致原 `192 / 24` 计数不能作为有效比较，相关结论作废。
