## 候选范围与最小验收

### Q-12：修正高度普通笔刷的抬手提交与取消回滚

**现状证据**

- `bindHeightEditing()` 的普通高度 stroke 在 `pointerup` 调用 `rollbackCanvasToolStroke(state, "height")`，在 `pointercancel` 调用 `finishHeightStroke()`，与省份等已校准笔刷及通用交互语义相反。
- 现有画布工具回归只固定了省份结束路由，没有覆盖高度普通笔刷的这两条事件路径。

**封闭范围**

- 只修正普通高度圆形笔刷的 `pointerup / pointercancel` 路由及对应动态回归。
- 保留现有高度计算、跨海平面派生、选区、线工具、模板、工作台和历史命令；不借机改高度编辑算法或界面。

**最小验收**

- 有效 stroke 在 `pointerup` 后保留高度变化并只写一条历史，`pointercancel` 完整恢复预览且不写历史。
- 撤销 / 重做精确恢复高度和本次既有派生结果；专项回归、相关高度回归、生产构建和差异检查通过。

### Q-13：清除 Feature 拓扑回归中的过期 API 总数副本

**现状证据**

- `tools/webgl-generator-feature-topology-ui-api-regression.mjs` 仍断言公开 API 为 `196 / 98`，当前稳定基线已经是 `204 / 106`，脚本会在 Feature 动态断言前失败。
- 全局精确总数已经由 API inventory / stability 门禁负责；领域回归再次冻结总数会随其它领域新增 API 反复漂移。

**封闭范围**

- 让 Feature 领域回归只验证本领域方法、确认门禁、UI 接线和动态行为；全局总数继续由唯一的 API inventory / stability 契约负责。
- 不修改公开 API、Feature 运行时行为或已完成第 75 项的产品规则。

**最小验收**

- Feature 回归能够进入并完成全部动态断言，不再保存第二份易漂移的全局精确总数。
- Feature 专项、API inventory / stability / edit coverage、生产构建和差异检查通过。

### Q-14：治理气候下游重算的主线程长任务

**现状证据**

- 第 72 项固定 10k 浏览器样本中，`economy -> markers` 阶段约耗时 `1216ms`，产生本项来源的 `input-handler-stall / main-thread-long-task` warning。
- 第 72 项已消除错误和成功路径的重复整图深克隆，因此本项应专注剩余同步计算，不重做已完成的业务正确性。

**封闭范围**

- 只治理气候变化触发的受约束下游链，可采用分阶段让出主线程、增量快照或等价的有界方案。
- 保持相同输入下的经济、marker、统计、stale、撤销 / 重做和失败回滚结果；不改变经济模型、marker 生成规则或气候编辑产品语义。

**最小验收**

- 固定 10k 样本中，不再出现由该操作产生的单段 `>=250ms` 输入处理阻塞或主线程长任务；跨帧总进度有明确 loading / 阶段反馈。
- 优化前后业务结果一致，操作失败仍完整回滚；气候专项、经济 / marker 相关回归、生产构建和差异检查通过。

### Q-15：商品与市场展示属性轻量编辑

**现状证据**

- 经济面板已经完成商品、市场、交易总览、市场归属和经济链重算，但历史阶段 3 的展示属性编辑尚未接入。
- 当前列表只读，尚不能编辑商品可见状态、颜色、图标、标签，也不能编辑市场名称和颜色。

**封闭范围**

- 商品只编辑可见状态、颜色、图标和标签；市场只编辑名称和颜色。
- 编辑统一进入 `EditHistory` 并随完整地图 JSON 保存；旧图缺字段时使用确定性默认值。
- 不编辑商品配方、产量、库存、价格、单笔交易或市场中心，不触发市场归属和经济链重算。

**最小验收**

- 面板与稳定 API 共用同一命令，单次保存只写一条历史，撤销 / 重做一致。
- 展示属性立即作用于对应列表和既有可视表达，不改变经济数值 checksum；新旧完整地图往返保持结果。
- 专项回归、地图迁移 / API 门禁、生产构建和差异检查通过。

### Q-16：贸易数据结构化组合查询与关联定位

**现状证据**

- 交易 tab 已支持自由文本筛选、排序、详情、单条定位和国家名称匹配。
- 历史阶段 4 仍保留按国家、地区、市场、商品、卖方、买方组合查询并定位关联对象的候选；当前没有结构化筛选条件或组合条件摘要。

**封闭范围**

- 在经济面板增加可组合的结构化交易筛选，并复用现有虚拟限量、排序、详情和 CSV / JSON 导出路径。
- 定位只面向当前选中交易及其国家、行政区域、市场或城市等既有对象。
- 不恢复全量或 top N 贸易连线，不新增常驻地图图层、动画、单笔交易编辑或经济重算。

**最小验收**

- 至少覆盖国家、行政区域、市场、商品、卖方和买方条件，组合筛选、清空、结果计数和导出使用同一结果集。
- 大交易样本打开和组合筛选不产生本项来源的主线程长任务；关联定位保持现有 selection / object details 契约。
- 专项回归、经济面板相关回归、生产构建和差异检查通过。

### Q-17：区域间人口守恒转移第一阶段

**现状证据**

- 第 78 项产品规则明确只实现单一区域非守恒增减，不实现区域间迁移；这解决了第一刀，但没有覆盖保持全图总人口不变的调配场景。

**产品规则门禁**

- 开发前先冻结允许的来源 / 目标范围类型、是否只允许同类型区域、城乡人口如何迁移、零人口落点、重叠区域处理、上限和确认规则。
- 若这些选择尚未获用户批准，不得以实现方便为由自行决定。

**封闭范围**

- 只实现两个有效区域之间的一次守恒转移，共用第 78 项已有的人口载体、统计刷新、经济需求摘要、stale 和事务基础设施。
- 不实现人口刷子、自动迁徙、时间模拟、适居度驱动迁移、文化 / 宗教改宗或城市创建 / 删除 / 移动。

**最小验收**

- 预检明确来源可转移人口、目标容量和实际转移量；成功后全图总人口在既有精度内守恒。
- 一次转移只写一条历史，失败、撤销、重做完整恢复双方人口、统计、经济摘要和 stale；旧地图无需新增必填字段。
- 专项回归、既有人口调整回归、生产构建和差异检查通过。

## 保留但暂不建议转正

- 富文本备注、主题纹理 / 任意字体、生产链图形化编辑：已有基础能力可用，新增价值尚不足以优先于上述实证问题。
- 底层蓝噪声采样或生成网格重做：旧审计仍有方向性担忧，但当前没有新的固定样本失败指标或视觉证据，不以陈旧描述直接立项。
- 局部有效区 mask、进一步单位覆盖和泛化性能专项：没有当前稳定失败证据，继续观察；Q-14 因已有 `1216ms` 与健康 warning 证据，是本轮唯一建议进入的性能专项。
