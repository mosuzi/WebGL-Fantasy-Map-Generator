# UI 系统综合审计门禁

本文记录权威任务第 60 项的稳定验收口径。生成结果写入 `docs/generated/reports/ui-system-audit-results.json` 和 `.md`，不作为手写文档提交；可复现入口为：

```powershell
pnpm run build:app
pnpm run regress:ui-system-audit-contract
pnpm run audit:ui-system
pnpm run regress:panel-overlay-browser
pnpm run regress:shortcuts-browser
```

## 审计矩阵

- 桌面组合：一个主面板与可选对象详情必须无重叠共存；窄视口按后打开者胜出；刷新只恢复最后主面板。
- 固定浮层：导出、高度图工作台和树状总览使用统一安全区、活动层级、Esc 关闭和焦点返回。
- 键盘路径：快捷键可打开主面板，Tab 可到达页签，方向键可切页，Esc 可关闭并返回入口；可见图标按钮必须有可访问名称，禁止正 `tabindex` 和同作用域快捷键冲突。
- 缩放与字体：以 `720×720` 物理视口在 `125%` 页面缩放下等效的 `576×576` CSS 视口，加根节点 `20px` 字体进行自动化压力测试；面板关闭入口和滚动底部必须可达，快捷键提示保持页面底部水平居中且不遮挡交互控件。
- 低频面板：高度、军事、经济和名称库的组件 chunk 在首次打开前不得加载，首次打开后必须能观察到独立 chunk；首次挂载上限 `1500ms`，严重长任务门禁为 `500ms`。
- 连续打开：上述四个面板连续打开 / 关闭三轮，单次重复打开上限 `900ms`；主动回收前后 JS heap 增长上限 `96MB`。

## 本轮结果

- 生产构建完成 `1139 modules`，只保留既有大 chunk 警告。
- 四个低频面板均在首次打开时才加载独立 chunk；首次挂载分别为高度 `287ms`、军事 `402ms`、经济 `264ms`、名称库 `254ms`，最长任务分别为 `161ms / 301ms / 164ms / 163ms`。
- 四个面板连续三轮打开后的 JS heap 增长 `14.98MB`；重复打开均低于 `900ms`。
- `1280×720` 下主面板与对象详情左右停靠且无重叠；`720×720` 下最后打开者可达。固定浮层安全区、最后主面板恢复、键盘焦点进入 / 返回、Esc、Tab、图标按钮名称、快捷键冲突和底部提示全部通过。
- `576×576` CSS 等效缩放样本中，高度面板最终约束为 `left=208 / top=8 / right=568 / bottom=566.7`，关闭按钮与内容底部可达；提示条保持 `bottom=22`、水平偏差 `0`、交互遮挡 `0`。

## 审计中修正的问题

- 移除窄视口下遗留的双行 `.app-shell` 布局。当前页面只有地图主区域，旧规则会让地图只占约 `38vh`，导致底部提示出现在页面中部。
- `PanelManager` 通过 `ResizeObserver` 观察面板尺寸。异步 Vue 组件挂载或内容增高后会重新约束位置，避免按占位高度定位后越出视口。
- 浮层浏览器回归改用测试内创建的独立备注作为稳定对象详情样本，不再依赖固定 seed 必须生成路线；同时显式进入“简介”页再打开导出浮层。
- 快捷键浏览器回归在高度主面板关闭后重新打开控制面板，再验证管理入口，适配“一个主面板”规则。
