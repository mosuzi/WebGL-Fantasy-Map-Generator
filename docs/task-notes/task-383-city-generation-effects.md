# 第 383 项：城市属性后续生成作用方案

本文件是冻结设计与验收依据；活动状态只看 [当前计划](../current-plan.md)。本方案于产品修改前建立。

## 1. 现状与问题

- `generator/settlements.js` 已让首都影响初始人口、主干路端点，港口影响海路；设施主要是根据人口产生的标记。主干路当前只连接首都，贸易中心未获得主干候选资格。
- `generator/economy.js:marketScore` 已给首都、港口、贸易中心加权，但 `assignBurgMarkets` 将 `plaza` 覆盖为“恰好是市场中心”，会抹掉用户属性。产出和国库主要取决于当前人口。
- `generator/military.js` 已消费首都与港口；要塞、城墙没有明确的驻军作用。
- 没有保留现有城市身份的“按条件重算人口”入口。重新生成城镇遵循从空重建，不能拿旧城市属性去污染新对象。

## 2. 功能契约

### 2.1 生效时机

1. 点属性按钮只更新属性及必要身份 / 显示，绝不联动重算人口、经济、道路或军事。
2. 显式“按条件重算人口”只重算所选现存城市人口；“重新生成经济 / 路线 / 军事”各自消费最新属性。新生成城市完成设施分配后应用相同人口潜力规则一次。
3. 全量重新生成城镇仍从空建立新城市；未锁旧城市连同属性消失，锁定城市按原规则原样保留。不以此需求改变锁优先级或目标域隔离。
4. 潜在人口是当前地理和属性下的确定性生成值，不是实际人口上限。手工人口可高于潜力；属性反复开关与重复重算不得复利累乘。

### 2.2 六属性作用表

以下为产品规则系数，并非历史统计模型。各非首都增量相加，避免无界复合。

| 属性 | 人口潜力 | 经济重算 | 路线重算 | 军事重算 |
| --- | --- | --- | --- | --- |
| 首都 | 基础人口乘 `1.5`，保留行政吸引力 | 产出系数增加 `0.10`；保留原最高市场候选优先级 | 保留原主干路资格和行政优先级 | 保留原 `1.25` 都城征募系数 |
| 贸易中心 | 非首都增量 `+0.25` | 产出系数 `+0.30`；保留市场候选 `+700`；不强制成为市场中心 | 成为主干路候选；人口权重 `+1.00`、固定枢纽分 `+20` | 不直接增加兵额 |
| 要塞 | 非首都增量 `+0.05` | 无直接经济加成 | 成为主干路候选；人口权重 `+0.35`、枢纽分 `+10` | 陆军城市征募 / 驻军集中权重 `+0.30` |
| 城墙 | 非首都增量 `+0.10` | 产出系数 `+0.05`，表示安全交易条件 | 不单凭城墙新增主干资格 | 陆军城市权重 `+0.15` |
| 港口 | 非首都增量 `+0.20` | 产出系数 `+0.20`；保留市场候选 `+1200` | 保留水体条件和海路；增加主干路候选，人口权重 `+0.35` | 保留合法港口的海军资格，不给城墙 / 要塞海军增益 |
| 神庙 | 非首都增量 `+0.10` | 产出系数 `+0.05`，表示集会与朝觐活动 | 候选排序人口权重 `+0.10`，不单凭神庙新增主干资格 | 不直接增加兵额 |

人口公式：`max(0.01, suitability / 5 × stableVariation × capitalFactor × (1 + 设施人口增量))`，保留三位内部小数；`stableVariation` 在 `0.85～1.15`，只由地图 seed、城市 / burg ID 和 cell 决定。不能从当前人口乘起。旧档缺适居度时采用固定安全基值，缺属性视为关闭。

经济公式：重算时从原始人口 / 配方重新生成生产量及交易贡献，再用 `1 + 经济增量` 计算城市 product 和 treasury；同一输入再次重算不累乘。不新增货币或产出字段，国家经济按原聚合路径使用新结果。城市贸易设施与 `market.centerBurgId` 为不同概念，经济分配不再设置 / 清除 plaza。

道路：每个陆块保留既有首都集合，按共享评分选择贸易中心 / 要塞 / 港口作为额外主干端点；额外预算 `min(24, max(2, ceil(sqrt(陆块城市数))))`。连通组不足两点不造路；沿用地理寻路、网络稀疏化、ID 和锁合并。权重影响候选选择机会，不保证每座城市必有大路，也不跨海强连。

军事：在既有国家兵额上限与政策内提高要塞 / 城墙城市的陆军来源权重，并让要塞成为驻守状态的依据；不伪造即时防御战斗系统或绕过全国兵额约束。

### 2.3 用户入口与兼容

- 属性中文悬停说明展示主要作用及“相关数据重算时生效”。选中城市详情展示潜在人口与当前人口的区别。
- 人口操作区增加“按条件重算人口”，复用现有城市人口命令与撤销；后续第 384 项补齐该公共路径的行政统计。
- 旧存档只读已有 capital / plaza / citadel / walls / port / temple；不需要新增持久字段。city / burg 兼容优先级沿用第 382 项。
- 属性设置、经济 / 道路 / 军事重算均保留单历史、故障回滚、保存回读和显式锁保护。
