## 韩国在原始存档里的记录

直接解开玩家上次导出的同一份 `stage-2-1-2026-11-19-23-49-13.webfmg`，在执行任何迁移前检查其内容。存档 SHA-256 为 `6AC85DD54D5B22AF9E9B165B3184EFBB3EA20E7C25AA128601A28BBDC4029A63`。100,000 个网格和 43,419 个地块中均无一格归韩国。韩国的面积、城镇数和省份数均为零，国家编号 4009 却仍处于有效状态，首都指针仍指向邯郸。

邯郸所在的编号 439 的网格和编号 4 的地块都属于布撒帝国。城镇与 burg 两份记录均把邯郸登记为布撒的普通城镇。布撒的首都是霜玄。旧版国家列表按国家是否有效筛选，照此显示了韩国。原档能证实保存时的状态，没有跨次编辑的操作历史可用来还原韩国具体在哪一次操作中失去了领土。

旧版画笔在没有可用本土时清空首都，随后仍让这个国家进入列表和自动标签集合。实时预览又先改动 pack 归属，松笔才为撤销拍快照，导致撤销能还原网格却漏还原对应地块。此外，旧版转移城镇时只更新了城镇记录中的省份。

## 十万格副本的实际操作

导入上述副本并打开国家编辑。选择与布撒帝国接壤的微国，将其 94 格中的 93 格通过正式归属编辑交给布撒，留下首都月星所在的 29389 号网格。定位到 2.8 倍，用半径为 1 的国家画笔在画布上实际点击最后一格。逐次记录两层地块归属、国家列表行、地图国名、城镇和首都图标，再执行撤销、重做。

## 存档和性能

文档与地图 schema 从 v3 迁至 v4。旧国家的编号、国名、纹章和自有资料保留在原记录，两层地块归属均证实无地后才标记为已撤销。该玩家原档的其余 25 国的编号、国名、颜色及首都逐一比对一致，两套完整归属数组和城镇的身份、所属、人口、文化、宗教、纹章也一致。

迁移专项覆盖固定的 v1、v2 夹具，以及由 `0.5.158` 编码器生成的 v3 零领土国家夹具。验证 JSON、浏览器存储包装、原始与压缩 WEBFMG3、再次保存回读，以及任一侧仍有陆地时保留国家。旧存档本体仅在本机读取。

针对本次操作，拾取索引只重建点对象，沿用已有路线与河段。独立对照中，结果与完整重建相同，12 个路线桶和 16 个河段桶复用了各自的数组。最终浏览器涂抹、撤销、重做窗口记录到 85、147、139、126ms 四次主线程长任务，页面错误为零。

复验入口为 `tools/webgl-generator-last-state-cell-browser.mjs`。构建正式应用后，将 `FMG_REAL_ARCHIVE` 指向原始存档副本，再运行该脚本。它把重做后的验证存档写入进程的临时目录。
