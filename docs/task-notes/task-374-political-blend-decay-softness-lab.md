# 第 374 项：屏幕空间朦胧衰减柔和度实验

## 用户目标

在正式接入前，先在共享边界实验室观察“衰减柔和度”是否能让国家色从国界中心向外更平缓地消失，并与范围、强度、路径柔顺度明确区分。目标是把两侧已有国家色在边界处直接抹开，不增加装饰色、光晕色或独立颜色增益。

## 冻结方案

- 新参数 `decaySoftness` 为 `0～1`，界面显示 `0～100%`，默认 `65%`。
- 只在屏幕空间朦胧候选中消费：低值使用宽核心、窄软边，颜色更集中；高值缩窄核心、扩大高斯软边，保持总体范围大致稳定并形成更缓的透明度衰减。
- 国界带内按强度混合原国家色抹开面，`1.0` 表示完整使用抹开面，不再以固定 `0.88` 透明度叠在清晰底面上；清晰国界线先绘制、再被同一原色抹开面覆盖，因此会与色面一起抹开。
- 每个像素先确定原始所属国家，再收集包含该国且落入作用域的相邻边；普通边段自然只剩一个邻国，多国交汇则以距离衰减平方形成连续权重并归一化。外来颜色总比例只由最近边距离决定、最大为 `0.5`，不会按相邻边数量累计。三方节点不建立独立放大的圆形蒙版，其有效半径等于普通边段半宽。
- 既有“柔顺度”改名为“路径柔顺度”，继续只控制前三种几何候选的中心线 Chaikin 轮数；屏幕空间候选严格使用原始国家色边界，不消费该参数。
- 九轨固定 profile、`v0.5.4` 历史单带和连续中心线候选不得消费新参数。

## 验收边界

- `0% / 100%` 屏幕空间画布像素不同，且软边像素分布单调可解释；强度 `1.0` 时清晰国界线不得重新覆盖在抹开层之上；三方节点不得出现多路径强度叠加或硬选最近边导致的颜色切换缝；路径柔顺度 `0 / 3` 的屏幕候选必须逐像素不变，另外三张候选仍可按各自几何算法消费该参数。
- 四个行政夹具和既有拓扑回归不退化，浏览器控件、输出值、切换和错误面通过。
- 用户确认前只保留实验室分支和本地服务，不进入正式应用。

## 当前实验结果

- `24px` 范围下，`0%` 的 mask / 颜色 blur 为 `0.75 / 1.92px`，`100%` 为 `10.08 / 13.92px`；核心同步收窄，使有效半宽与三方节点有效半径始终同为 `20.4px`。
- 第一刀仅调整 mask 时端点差异偏弱；同时调整国家色扩散半径后仍因固定 `0.88` 覆盖与末尾清晰国界线而不够明显。最终改为在蒙版内直接使用模糊后的原国家色，并把清晰国界线置于替换层下方；满值画面不再产生居中的锐利切线。
- 用户满值截图继续暴露三国交汇处的过度混合：全色面高斯模糊会让三个国家同时进入节点采样，独立交汇圆又比普通边段多扩出作用域。上一阶段曾改为像素级“最近国界、仅相邻两国”混合，并让交汇半径严格等于普通边段；它消除了累计强度，但随后被新的交汇切换缝反例取代。
- 用户随后指出全满路径柔顺度时抹开带过于明显且与锯齿原边界分离。根因是像素所属国家仍来自原始色面，但距离场错误地锚定在 Chaikin 平滑路径上，形成原始填色边与偏移模糊带两条边界。屏幕候选现固定使用 `path.points` 原始共享边，缓存不再按 smoothness 分叉；路径柔顺度只保留给前三种几何候选。
- 用户再以满值近景指出三国节点左侧存在明显颜色突变。根因是上一版每像素硬选最近边，粉色区域在“粉黄 / 粉青”两种配对的 Voronoi 分界上必然跳变。当前保留原始边界锚定，但改为对同一所属国的全部相邻边计算连续距离权重；权重归一后分摊固定的外来颜色总量，消除硬切换且不恢复按边数累计的三色过曝。
- 上一版整面模糊的浏览器 `0% / 100%` 端点比较曾证明九轨、历史单带和连续中心线截图指纹不变，只有屏幕空间候选变化；该证据只用于确认参数隔离，不再作为当前交汇算法的最终视觉结论。
- 当前“归一化邻边 + 原始边界锚定”方案的等距两边权重为 `0.5 / 0.5`，最近边两侧 `7.99 / 8.01` 微扰镜像连续且单权重变化小于 `0.01`；四边同点权重和为 `1`，总外来颜色仍为 `0.5`。CDP 满值近景中，上一版节点左下的粉青硬分区已变为连续过渡，warning / error 为 `0`；最终截图保存在 `Z:/tmp/codex/2026-08-29/task-374-decay-softness/normalized-junction-max-card.png`，专项仍为 `20` 夹具、推荐管线 `14 / 14`。
- 用户已确认该视觉方向并授权提交、推送和合入。实验室仍保留本方案，正式应用改动保持为 `0`；完成版本 `0.5.86`。
