# 第 415 项：古地图主题计算配色

## 根因与实现

旧“古地图”只给画布加浅色滤镜，分类色面、独立人口和降雨图层仍使用蓝绿紫红原色；HTML / SVG 标签、标记、军事标识和图例不经过画布滤镜。旧地图的自定义国家色和标签色因此更容易露出艳色。现在古地图关闭画布滤镜，在正式 WebGL 顶点着色、独立数值图层及覆盖层绘制时把显示色投影到黄、赭、棕、纸色范围；水域和海底高度也使用暖色深浅。地图对象原色、保存结构与其他主题配色不变。

共享计算配色同时供 GPU 着色器、标签、标记、军事标识、图例及 PNG 合成使用。保留明度差和既有边界线，国家、省份仍可分辨；主题切回后不重写对象数据。旧式后台准备的主题切换校验改用目标显示意图，避免切换期间将新主题准备结果误判为当前主题失配。缩小尺寸的 PNG 导出直接从现有画布取样，避免为了缩图临时放大 WebGL 画布并重复绘制；放大导出路径保持原有处理。
