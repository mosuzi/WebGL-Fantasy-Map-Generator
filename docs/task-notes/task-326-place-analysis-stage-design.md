# 第 326 项地点解析与测量阶段冻结稿

## 封闭目标

第 326 项只新增国家、省份、城镇三类地点的只读解析、世界距离和方位查询。浏览器与无头 API 共用同一纯数据核心；不得修改地图、选择、相机、图层、历史、显示偏好、存档或 `source/`。

## 阶段边界

### 阶段 A：纯数据核心

- 完整名称匹配去除首尾空白但区分大小写；国家同时接受 `name / fullName`，不做模糊猜测。
- 同名按“国家 > 省份 > 城镇”，同类按数值 ID 升序；结果返回首选与全部候选，精确引用固定为 `{kind, id}`。
- 城镇以正式 `x / y` 为锚点；国家依次使用首都、中心 cell；省份依次使用唯一省会、`pole`、中心 cell。非法、删除或无有效锚点均返回结构化错误。
- 距离复用正式显示单位换算；方位以地图正北为 `0°`、顺时针增加，Y 减小为北，八方位使用半开边界，低于统一 epsilon 时返回“重合”。

### 阶段 B：API、schema 与文档

- 在浏览器与无头 `analysis` 命名空间接入 `resolvePlace`、`measureDistance`、`getDirection`，进入发现、schema、能力矩阵与 AI 文档。
- 浏览器可选返回当前画布设备像素口径的 `screenDistancePx`，必须同时声明坐标空间；正式地理距离始终来自世界坐标。
- 无头单位优先显式参数，其次存档显示单位，最后使用默认单位并标记近似来源；结果回显地图 revision / source checksum 的既有环境口径。

### 阶段 C：真实入口验收

- 固定 10k / 100k、细分图和保存往返核对浏览器 / 无头同源；三档相机只允许屏幕距离变化。
- 锁定解析歧义、锚点来源、单位、八方位边界、无副作用、API 发现、schema、构建与 application / page / health / WebGL 错误面。

## 交付约束

- 主线程为唯一写者；本权威编号只使用一次独立调查、一次集成复核和一次最终验收。
- 每阶段先跑静态门与最窄专项，建立 checkpoint 后再升级；浏览器首败按项目精简规则停止并只允许一次窄诊断与一次目标复验。
- 不扩展到边界最短距离、路线里程、航路、模糊地名、更多对象类型或地图写入。
