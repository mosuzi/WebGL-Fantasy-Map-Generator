# 第 375 项：桌面鼠标 / 触摸板地图导航实验

## 用户目标

让只使用触摸板的 macOS 用户无需模拟鼠标中键 / 右键即可自然平移与缩放地图，同时不破坏 Windows、Linux、macOS 上既有鼠标习惯。有能力时为大屏平板提供中性浏览态手势，但本项不面向手机，也不一次性重写所有编辑工具。

## 冻结交互矩阵

| 输入 | 中性浏览态 | 编辑态 | 本项边界 |
| --- | --- | --- | --- |
| 鼠标主键 | 点击选择；越过阈值后平移；空格 + 主键立即平移 | 仍归当前工具，本项不抢占 | 不改变对象编辑语义 |
| 鼠标中键 / 右键 | 立即平移 | 继续允许导航 | 保持既有行为 |
| 鼠标滚轮 | 指针锚定缩放 | 保持既有编辑锁边界 | 行 / 页单位与典型大步长自动识别 |
| 触摸板双指滚动 | 像素单位横向、细小或小数增量自动双轴平移 | 本项不扩写工具仲裁 | 不靠操作系统、User-Agent 或用户设置猜设备 |
| 触摸板捏合 | `ctrlKey` wheel 指针锚定缩放 | 本项不扩写工具仲裁 | 阻止浏览器页面缩放仅限地图 canvas |
| 触屏单指 | 点击选择；越过阈值后平移 | 继续归当前工具 | 只支持中性浏览态 |
| 触屏双指 | 质心平移 + 距离缩放 | 留给后续独立任务 | 不实现三指 / 四指和边缘系统手势 |

## 自动兼容与数据边界

- 不提供“鼠标 / 触摸板”设置，不在控制面板、本地偏好、地图文档、导入导出、公开地图 API、revision 或撤销 / 重做中保存输入模式；旧本地字段在归一化写回时移除。
- 单一路径自动分类：`ctrlKey` wheel 一律作为 pinch 缩放；行 / 页单位、像素单位 `48px` 以上的典型整数大步长作为鼠标缩放；像素单位横向分量、`48px` 以下细小增量或小数增量作为触摸板平移。同一短 burst 锁定意图，避免惯性阶段在平移 / 缩放之间跳变。
- 浏览器 `WheelEvent` 本身不暴露“鼠标还是触摸板”，该规则只依据事件单位和增量形态，不读取操作系统或 User-Agent；极少数高分辨率鼠标 / 首帧即大幅触摸板输入仍需真实设备手感确认。
- `touch-action: none` 只应用于地图 canvas，控制面板和页面其它区域仍保留浏览器原生滚动与缩放。

## 实现阶段

1. `375-A`：建立 wheel 单位归一化和无需配置的 burst 自动分类，专项先固定纯函数边界。
2. `375-B`：把单 active pointer 改为统一导航控制器，固定主键阈值、空格拖动、多指质心 / 距离、捕获丢失和取消清理。
3. `375-C`：把控制器接到 renderer，并把 `touch-action` 限定到 canvas；不增加控制面板卡片，只做必要的编辑锁兼容。
4. `375-D`：运行导航专项、既有 canvas tool / pointercancel 门、类型 / 构建门，并在本地真实浏览器验证自动鼠标 / 触摸板分类和模拟触屏手势。

## 最小验收

- 鼠标中 / 右键平移和滚轮定位缩放保持；主键点击仍选择，跨过阈值后只平移不误选；空格 + 主键直接平移。
- 像素单位细小 / 小数或带横向分量的普通 wheel 同时消费 `deltaX / deltaY` 平移，`ctrlKey` wheel 定位缩放；行 / 页单位及典型大步长保持鼠标缩放。
- 中性浏览态双触点不会覆盖彼此，能同时形成质心平移与连续 pinch 缩放；任一 `pointercancel / lostpointercapture` 后不残留交互态。
- 控制面板不存在输入模式配置，运行时不读取或持久化输入模式；导航不产生地图 history、revision、主题或地图文档差异。
- 真实浏览器目标窗口 warning / error 为 `0`。完成后只提交 / 推送实验分支，`main` 保持不变。

## 非目标

- 手机响应式界面、屏幕旋转、虚拟键盘适配。
- 三十类编辑工具的触屏语义、Apple Pencil / Windows Pen 专项、压力与倾角。
- 三指 / 四指桌面切换、Mission Control、系统返回 / 前进及屏幕边缘手势。
- 地图渲染颜色 / 几何、生成器、存档 schema、主题或公开 API 改动。

## 当前实验结果

- 新 `viewport-input-controller` 以多指 `Map` 取代单一 active pointer。鼠标 / 笔主键先作为选择候选，鼠标 `5px`、触屏 `8px` 后转平移；中 / 右键和空格主键立即平移。`pointercancel`、`lostpointercapture`、窗口失焦和销毁统一清理活动指针并结束视口交互。
- 用户确认兼容逻辑不应成为配置后，输入模式枚举、控制面板卡、localStorage 字段、UI bridge、runtime 恢复和 renderer setter 全部移除。旧 `navigationInputMode` 仅作为遗留键在偏好归一化时删除，不再改变行为。
- wheel 现始终自动分类：`ctrlKey` 永远作为指针锚定缩放；非像素单位与典型整数大步长缩放；像素单位横向、细小或小数增量平移。短 burst 锁定同一意图，下一 burst 再按新事件特征分类。
- 本地真实页面中，`12px` 纵向 wheel 使“白麓帝国”标签只平移 `-12px`、宽高不变；相隔新 burst 后，`100px` 典型滚轮步长使“白麓帝国 / 石门帝国”标签中心距离由 `125.2200px` 变为 `113.3162px`，比例 `0.90494`。控制面板 DOM 无地图导航 / 输入方式控件，页面本轮 `100` 条日志中 warning / error 为 `0`。
- 浏览器控制层未能把两种 Control 修饰键拼入 wheel，因而没有用该模拟手段宣称真实 pinch 已通过；纯控制器专项已固定 `ctrlKey wheel` 的缩放和光标世界锚点不变，最终仍需用户在真实触摸板上确认手感。
- `regress:viewport-input`、`regress:canvas-tools`（30 个模式）、`regress:control-ia`、`regress:global-shell`、`typecheck:core` 和 `1409 modules` production build 通过。既有直接操控总账被未修改的 `RoutePanel.vue` 未分类全局监听先行阻断，按首败即停规则未跨范围修复。
- 首版实验为 `v0.5.87`；移除配置并改为始终自动兼容的第二次任务提交为 `v0.5.88`。用户试用后授权合入，归档与快进交付版本为 `v0.5.89`，`main` 不再手工补版本。
