# 第 375 项：桌面鼠标 / 触摸板地图导航实验

## 用户目标

让只使用触摸板的 macOS 用户无需模拟鼠标中键 / 右键即可自然平移与缩放地图，同时不破坏 Windows、Linux、macOS 上既有鼠标习惯。有能力时为大屏平板提供中性浏览态手势，但本项不面向手机，也不一次性重写所有编辑工具。

## 冻结交互矩阵

| 输入 | 中性浏览态 | 编辑态 | 本项边界 |
| --- | --- | --- | --- |
| 鼠标主键 | 点击选择；越过阈值后平移；空格 + 主键立即平移 | 仍归当前工具，本项不抢占 | 不改变对象编辑语义 |
| 鼠标中键 / 右键 | 立即平移 | 继续允许导航 | 保持既有行为 |
| 鼠标滚轮 | 指针锚定缩放 | 保持既有编辑锁边界 | 自动 / 鼠标模式不退化 |
| 触摸板双指滚动 | 触摸板模式双轴平移；自动模式只识别高置信度输入 | 本项不扩写工具仲裁 | 不靠操作系统或 User-Agent 猜设备 |
| 触摸板捏合 | `ctrlKey` wheel 指针锚定缩放 | 本项不扩写工具仲裁 | 阻止浏览器页面缩放仅限地图 canvas |
| 触屏单指 | 点击选择；越过阈值后平移 | 继续归当前工具 | 只支持中性浏览态 |
| 触屏双指 | 质心平移 + 距离缩放 | 留给后续独立任务 | 不实现三指 / 四指和边缘系统手势 |

## 配置与数据边界

- “自动 / 鼠标 / 触摸板”是当前浏览器 / 设备的全局控制偏好，与主题、地图样式和地图内容无关。
- 偏好只进入既有控制面板本地存储，不进入地图文档、导入导出、公开地图 API、revision 或撤销 / 重做。
- 自动模式采用保守分类：`ctrlKey` wheel 一律作为 pinch 缩放；行 / 页单位或歧义较大的单轴滚动保持既有缩放；双轴、细粒度像素滚动的短 burst 才作为平移。同一 burst 锁定意图，避免手势中途在平移 / 缩放之间跳变。
- `touch-action: none` 只应用于地图 canvas，控制面板和页面其它区域仍保留浏览器原生滚动与缩放。

## 实现阶段

1. `375-A`：建立输入模式归一化、wheel 单位归一化、burst 分类与配置持久化，专项先固定纯函数边界。
2. `375-B`：把单 active pointer 改为统一导航控制器，固定主键阈值、空格拖动、多指质心 / 距离、捕获丢失和取消清理。
3. `375-C`：在“视图”页增加“地图导航”卡并接到 renderer；只做必要的编辑锁兼容，不扩展编辑工具能力。
4. `375-D`：运行导航专项、既有 canvas tool / pointercancel 门、类型 / 构建门，并在本地真实浏览器验证设置持久化、鼠标兼容和模拟触摸板 / 触屏手势。

## 最小验收

- 鼠标中 / 右键平移和滚轮定位缩放保持；主键点击仍选择，跨过阈值后只平移不误选；空格 + 主键直接平移。
- 触摸板模式下普通 wheel 同时消费 `deltaX / deltaY` 平移，`ctrlKey` wheel 定位缩放；自动模式对歧义输入维持鼠标兼容。
- 中性浏览态双触点不会覆盖彼此，能同时形成质心平移与连续 pinch 缩放；任一 `pointercancel / lostpointercapture` 后不残留交互态。
- 切换输入模式不产生地图 history、revision、主题或地图文档差异；刷新后浏览器偏好保持。
- 真实浏览器目标窗口 warning / error 为 `0`。完成后只提交 / 推送实验分支，`main` 保持不变。

## 非目标

- 手机响应式界面、屏幕旋转、虚拟键盘适配。
- 三十类编辑工具的触屏语义、Apple Pencil / Windows Pen 专项、压力与倾角。
- 三指 / 四指桌面切换、Mission Control、系统返回 / 前进及屏幕边缘手势。
- 地图渲染颜色 / 几何、生成器、存档 schema、主题或公开 API 改动。

## 当前实验结果

- 新 `viewport-input-controller` 以多指 `Map` 取代单一 active pointer。鼠标 / 笔主键先作为选择候选，鼠标 `5px`、触屏 `8px` 后转平移；中 / 右键和空格主键立即平移。`pointercancel`、`lostpointercapture`、窗口失焦和销毁统一清理活动指针并结束视口交互。
- wheel 分类保守：`ctrlKey` 永远作为指针锚定缩放；“鼠标”固定滚轮缩放；“触摸板”固定普通双轴 wheel 平移；“自动”只把像素单位且带明确横向分量的事件判为平移，其余保持旧缩放。短 burst 锁定同一意图，模式切换清空 burst。
- 控制面板“视图 → 地图导航”提供“自动（兼容鼠标）/ 鼠标 / 触摸板”，标明“当前浏览器 · 不写入地图”。刷新后 DOM 选择值与 renderer canvas 模式均保持 `trackpad`，canvas 计算样式 `touch-action: none`，作用域未扩到页面或控制面板。
- 本地真实页面在触摸板模式接受一次 `90 / 120` 双轴滚动后，稳定标签位置精确变化 `-90 / -120px`；主键跨阈值拖动后精确变化 `60 / 30px`，随后单击仍选中城市“灵鹿”并打开对象详情。自动模式纵向滚轮使两国家标签距离由 `246.2521px` 变为 `222.8953px`，比例 `0.90515`，证明保持缩放而非平移；该目标窗口新增 warning / error 为 `0`。
- 浏览器控制层未能把两种 Control 修饰键拼入 wheel，因而没有用该模拟手段宣称真实 pinch 已通过；纯控制器专项已固定 `ctrlKey wheel` 的缩放和光标世界锚点不变，最终仍需用户在真实触摸板上确认手感。
- `regress:viewport-input`、`regress:canvas-tools`（30 个模式）、`regress:control-ia`、`regress:global-shell`、`typecheck:core` 和 `1409 modules` production build 通过。既有直接操控总账被未修改的 `RoutePanel.vue` 未分类全局监听先行阻断，按首败即停规则未跨范围修复。
- 版本工具从 `origin/main v0.5.86` 自动准备并验证实验版本 `v0.5.87`；该版本只属于独立任务分支，不表示已获准合入主线。
