# 第 422 项：图标按钮与列表操作列

## 问题与范围

国家列表的锁定和定位按钮只有 28px，操作列却固定占 `88 + 64 = 152px`。面板通用按钮规则还把 28px 圆按钮撑成约 28×32px，形成截图中的椭圆。对象表在 24 个面板有 27 张实例；本项只改这套共用表、图标按钮及其它仅图标的编辑入口，不改地图数据与存档。

## 改动

- 锁与定位列各为 40px，表头用对应图标和可访问名称；每个行内按钮保留 32×32px 透明命中区。两列右侧固定关系不变，合计释放 72px 给正文列。
- 对象操作、批量锁、导入导出、城市属性、高度工具及详情定位共用的图标按钮去掉常态边框和底框；导入导出组去掉重复外框。选中用图标强调色和底部短线，锁定仍区分 Lock / Unlock，禁用透明度与键盘焦点轮廓保留。带文字的危险动作仍使用完整按钮。
- 标题栏、二级编辑面板、树状总览、高度图工作台、搜索弹窗的关闭图标及全局工具栏收起图标直接呈现；工具栏收起图标用浅色笔画与暗色描边适应不同底图。风带档位和收起后的唯一展开凸片保留其必要外形。
- 面板主题中的普通按钮高度规则不再覆盖图标控件，避免再次拉伸成椭圆；排版长期契约记录 40px 操作列与 32px 图标命中区。

## 验证与失败归因

- `build:app`、表格几何、`regress:global-shell`、`regress:regeneration-lock-ui`、`regress:control-ia`、`regress:action-ia`、`regress:action-ia-browser` 与 Impeccable 布局扫描通过。浏览器动作专项首跑在旧断言“默认重生成国家”处失败；现行控制面板默认项实际是“地理要素”，更新夹具断言后一次目标复验通过，城市与路线按钮均可用，浏览器错误为 0。
- 全量 `check:ui-layout` 对桌面、窄屏及实际 125% / 150% / 200% 共 709 个状态检查，问题 0；国家和城市列表的锁 / 定位列实测各 40px，紧邻右侧边缘，32×32px 按钮无常态边框与底色。锁定、撤销 / 重做、定位不改变列表选中集合，横向滚动时表头和两列持续对齐。静态 `webgl-generator-interaction-keyboard-visual-regression` 与复杂工作区审计仍在未修改的 `StatePanel.vue` 字段旧计数 `12/10` 处提前停止，不计为通过。
- 独立复核指出去框后的全局工具栏收起图标在暗底图对比不足；已改为亮色图标加暗色描边。真实浏览器复核其 34×34px 命中、透明背景、亮色图标与描边，标题栏关闭为 32×32px，页面 / 控制台错误为 0。
- 正式预览面板打开时观测到 1 条 `76ms` LongTask；相位定位在国家面板首次打开后的布局更新。随后的锁定点击与撤销窗口无 LongTask，`>200ms` 为 0。此前两次隔离对照首次国家 / 城市切换约 `72 / 61ms`，均处于旧面板开启链路，未归因给图标点击；图标布局收紧后目标复验仍记录该 `76ms`，按规则保留精确残余。
