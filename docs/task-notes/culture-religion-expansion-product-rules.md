# 文化与宗教中心及扩张编辑规则

本文冻结权威任务第 76 项的产品规则。实现与验收不得越过以下边界。

## 联动与事务

- 文化重新扩张默认不重算宗教；预检和执行可以显式选择在同一事务中联动宗教，默认关闭。
- 不联动时保留宗教覆盖，并把宗教及必要下游系统标记为待派生。
- `save` 只保存中心与参数，归属数组逐值不变；`reexpand` 对对应领域全部活动对象执行确定性受约束重扩张。
- 重扩张必须明确确认，并只形成一条可撤销历史；预检始终只读。

## 中心规则

- 中心只能迁往目标自身当前拥有的合法陆地 pack cell，同领域活动对象的中心不得重叠；执行时再次校验。
- 重扩张后中心不再属于自身时，从自身覆盖 cell 中按人口、适居度降序和 pack cell ID 升序确定性回退。
- 完全没有覆盖时，`center / gridCenter` 都设为 `-1`；Folk 宗教不得回退到自己并不拥有的文化中心。

## 参数与扩张边界

- 文化类型只允许 `Generic / Hunting / Highland / River / Lake / Naval / Nomadic`。
- 文化及非 Folk 宗教扩张系数为 `0.1～10`，步长 `0.1`；旧图缺失或非有限值默认 `1`，越界值截断到合法范围。
- Folk 宗教固定为 `expansion = culture`、`expansionism = 0`。
- 其他宗教允许 `culture / state / global`：`culture` 严格限制在绑定文化内；`state` 严格限制在中心当前国家内但可跨文化；`global` 可跨文化和国家并保留跨界代价。
- 移动宗教中心不隐式修改其绑定文化。

## 稳定字段与派生

- 重扩张保留对象 ID、名称、颜色、父级、origins、名称库绑定及其他非派生字段，不随机生成、改名或重建继承关系。
- 继承树只修复 `children / depth / lineage` 等派生字段；失效父级回根 `0`。
- grid / pack 归属、双对象 store、中心、覆盖统计及城市、国家、省份等引用必须同步；名称库绑定保持原值。
