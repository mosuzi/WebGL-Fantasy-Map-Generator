# 第 423 项：画布当前对象与编辑列表联动

## 现象与归因

27 张对象表分布于 24 个面板。画布普通选中通过 `SelectionStore` 更新渲染器及已打开面板的当前对象 ID；表格滚动使用该 ID，但带多选的行色、`aria-selected` 只读批量选择集合，带重生成锁的表格还只读独立锁会话。因此画布高亮的国家可成为编辑目标，却没有可见当前行。政体面板的国家子表是另一个遗漏：国家选择路由只更新国家编辑面板。文化、宗教的树视图直接用当前 ID，其列表视觉与树视图不一致。

本项把当前对象标记与批量选择分开：共享表格以当前 ID 显示左侧强调和 `aria-current`，批量选择仍使用 `aria-selected`；Ctrl 取消批量选择不会清空编辑目标，普通地图选取不会悄悄改变重生成锁的选择集合。持续地图高亮也保持独立，只表示显式高亮集合。

## 浏览器夹具失败与目标复验

1. `browser-1` 首次失败：国家和政体面板连续打开后，国家面板等待可见超时 180 秒。原因是浮动管理面板互斥，后开政体面板会隐藏国家面板；夹具误把它们当成可同时显示。修正：按实际交互依次打开，每一阶段只检查当前可见面板，并增加阶段日志；目标复验检查国家真实画布点击、政体面板接收画布国家选择、城市及文化当前行。
2. `browser-2` 运行至 10k 国家阶段后迟迟没有新阶段日志，超过一分钟手动停止；上次只在阶段入口记日志，尚不能判定卡在面板可见还是当前行等待。原因分析：等待粒度过粗，直接复跑会浪费 180 秒且无法定位。实质调整：为面板打开、API 选择、当前行、批量点击逐步记时和 DOM 摘要，并把阶段等待收窄到 15 秒；目标复验先明确具体等待点，再修产品或夹具。
3. `browser-3` 诊断发现国家面板打开且当前行已有 `aria-current=true`，DOM 键为 `n:1`；夹具仍以裸数字 `1` 查询，误报等待超时。原因是共享表格的对象 ID 键带类型前缀。修正所有数字 ID 定位器使用 `n:<id>`；目标复验进入真实画布国家选择和政体、城市、文化阶段。
4. `browser-4` 已通过国家当前行及 Ctrl 批量取消，随后找不到画布落点。原因是夹具把拾取返回值当作 `stateObject`，而现行国家画布拾取用 `gridCell` 再查 `grid.cells.state`（参考现有国家创建浏览器夹具）。修正为现行拾取身份路径，继续排除城市图标；目标复验命中实际国家画布选择。
5. `browser-5` 在国家当前行后超过一分钟未进入下一阶段，手动停止；尚不能区分表格行点击等待与逐格落点搜索。原因分析：该阶段含未记时点击和可遍历全部格点的拾取检查。实质调整：逐个点击加阶段标记和 15 秒超时，画布候选按固定步长取样并限制拾取次数；目标复验定位等待点，同时防止夹具自身占用主线程。
6. `browser-6` 已完成国家行普通点击、Ctrl 取消和有限候选搜索，随后画布点击未在等待窗口内产生目标国家。原因是夹具只验证了落点的国家归属格，却没有验证当前视图的实际 `picked.object`；高度视图可拾取其它对象或无国家对象。修正：先切到国家视图，并以拾取返回的实际 `object.kind/id` 筛选落点；点击后立即记录真实选择，等待收为 8 秒。目标复验真实画布选择国家且列表跟随。
7. `browser-7` 在 10k / 100k 通过国家画布点击、Ctrl 取消、政体、城市、文化目标行与性能门。独立复核随后发现首次打开国家面板、外交视图早退及政体筛选目标丢失，已修补并扩充夹具，需重做集成浏览器验收。
8. `browser-8` 国家阶段已通过，政体阶段入口的夹具却仍期待上一步画布国家 `canvasPick.id`；加入外交分支验证后，当前选择已切到 `stateA`。这是顺序调整后的旧期望。改为按实际当前选择 `stateA` 断言，目标复验政体过滤和三类真实画布点击。
9. `browser-9` 国家、政体、城市、文化入口均跑通，100k 最后命中 `>200ms` LongTask 硬门。当前夹具把落点搜索、视图切换和产品交互混入一个观察窗，只存持续时间，无法归因。实质调整：记录 LongTask `startTime` 与浏览器阶段时间戳，输出超限条目的所属阶段；提供仅 100k 目标复验。若是夹具同步拾取，移到观察窗外或减少候选；若是产品面板选择，优化产品链路后再复验。
10. `browser-10-large` 定位到唯一 `234ms` LongTask 发生于文化面板阶段；该阶段同时包含首开面板、API 选择、切换文化视图、夹具落点搜索与画布点击，尚不能归因。国家 / 政体阶段最长 `153ms`。实质调整：在文化阶段每一步前后加浏览器时间戳，只跑 100k 目标复验，确认超限任务所属操作后再处理。
11. `browser-11-large` 再现 `227ms` LongTask，准确落在文化画布点击到选择完成之间；夹具落点搜索与视图切换均不在该时间段。原因收窄为真实选择回调或其绘制 / 面板更新。实质调整：仅在文化点击前包裹 `SelectionStore` 回调、renderer 选择 / 绘制 / 拾取及文化面板更新，逐项记录同步耗时；目标复验定位产品瓶颈后实施一次窄优化。
12. `browser-12-large` 的 `214ms` LongTask 中，`SelectionStore` 回调 `195.4ms`、`renderer.setSelection/draw` 各 `192.5ms`，文化面板更新仅 `0.3ms`；真实瓶颈在选择重绘。现有 `selection-layer.js` 对文化所属格逐三角在 CPU 转屏幕再转裁剪坐标，并经 JS 展开数组复制。实质调整：先记录 `selectionBuildMs`、整帧 `drawMs` 和生成顶点数，确认几何构建占比；随后只优化确认的热点并保持像素结果。
13. `browser-13-large` 确认文化选择生成 `228999` 顶点，`selectionBuildMs=211.4ms`，整帧 `drawMs=211.6ms`，LongTask `240ms`；热点就是选择网格构建。实质调整：同一格中心只变换一次、相邻顶点沿环复用裁剪坐标，直接写原有三角顶点序列；合并普通 / 陆地遮罩数组时直接写入目标 `Float32Array`，去掉百万级 JS 展开副本。目标复验顶点数量与颜色、选择画面和 100k LongTask 硬门。
14. `browser-14-large` 对同一 100k 文化画布点击目标复验通过：选择网格构建 `27.1ms`，选择回调 `36.6ms`，最长 LongTask `103ms`，页面错误 `0`。优化前后固定几何对照的 `38400` 个顶点坐标完全一致、颜色差异 `0`；随后执行完整小图 / 大图复验。
15. `browser-15-full` 覆盖 10k / 100k 国家、政体国家子表、城市、文化的真实画布点击，以及首次打开、外交主题、Ctrl 取消、筛选和虚拟行；两图均通过。100k 文化选择生成 `228999` 顶点，构建 `26.1ms`、选择回调 `34.8ms`；最长 LongTask 为 `81 / 0ms`，目标页面 / 健康 / WebGL 错误均为 `0`。
16. 独立终验发现 `browser-15-full` 未覆盖“国家面板关闭时缓存上一张地图，再在新地图选中仅新图存在的国家并首开”场景。旧 setter 会用缓存的旧图拒绝新 ID；这不是全量夹具失败，而是覆盖缺口。实质调整：setter 只暂存规范 ID，`open / update` 再按现行地图校验；夹具在首次打开前注入仅含另一国家的旧图缓存。`browser-16-small` 目标复验通过，首开当前行确为新图目标，最长 LongTask `79ms`、错误 `0`；随后做完整 10k / 100k 复验。
17. `browser-17-full` 把旧图缓存首开反例并入完整 10k / 100k 场景，再核对国家、政体、城市、文化的真实画布与列表联动；两图均通过。100k 文化高亮构建 `25.5ms`、回调 `35.2ms`，最长 LongTask `107 / 0ms`，页面 / 健康 / WebGL 错误 `0`。同一错误的复验未达到 20 次上限。

`selection-panel-policy` 专项首跑失败：静态断言仍匹配旧的 `{object}` 调用，现行列表选择在调用前会生成 `nextObject`。已把断言改成现行 `{object: nextObject}` 且继续要求 `sourcePanelId`，目标复验通过。

城市对象详情浏览器专项首跑在进入列表联动断言前失败：仍查询早已移除的 `.object-details-actions-city` 两列网格；现行对象详情按第 399 项改为 `.object-details-actions` 弹性换行，定位按钮又按第 422 项改为纯图标。修正夹具去掉旧网格列数 / 行数假设，改查正式容器、按钮可访问名称、整颗换行与零裁切 / 重叠，再复验城市当前行。

## 验收

共享表格的 `27` 个实例分布在 `24` 个面板，均传入当前对象 ID。普通画布可拾取的国家、城市、省份、文化、宗教、河流、湖泊、地区、路线、标记、军事，以及有条件可拾取的外交关系、交易线，均经对象键、面板路由及当前行绑定核对；没有普通画布拾取的统计和设置列表继续使用各自本地选择。国家选择同步已打开的国家与政体面板，首次打开和筛选不会把目标改为另一国。当前对象以左侧强调及 `aria-current` 标记；`aria-selected` 仍只代表批量选择，重生成锁与持续地图高亮不被画布普通点击改写。

正式浏览器 `10,004 / 100,000` 格的国家、城市、文化和政体国家子表联动、旧图缓存后首开、重复 / Ctrl 点击、外交主题、筛选及虚拟列表通过，最长 LongTask `107 / 0ms`，超 `200ms` 与目标浏览器错误均为 `0`。文化高亮网格的 `38400` 顶点对照坐标与颜色精确一致；100k 实际选择构建 `211.4 → 25.5ms`，选择回调 `35.2ms`。`build:app`（1439 modules）、`typecheck:core`、选择路由 / 高亮 / 复合高亮 / Ctrl / 锁会话 / 滚动居中专项和 `check:ui-layout`（709 状态、问题 0）通过。旧城市对象详情浏览器夹具的布局与图标断言已按现行界面校准并通过；独立静态集成复核和终验均 `ACCEPT`。第 402 项仍冻结。
