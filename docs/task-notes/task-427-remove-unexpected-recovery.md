# 第 427 项：移除“意外恢复”

## 范围

用户撤销第 389 项的“意外恢复”能力。简介页折叠区、自动保留开关、手动恢复点操作、启动时无条件安装的服务与每 30 秒定时写入一并移除；与之专属的来源诊断和过时测试同时清理。手动浏览器保存、地图文件导入、旧档迁移、事务失败回滚及调试模式错误重试继续使用。既有 `webgl-generator-recovery-v1` IndexedDB 记录和旧偏好均未主动清除。

## 首败与目标复验

- `regress:map-import-diagnostics` 首败：静态断言仍要求旧的 `recovery` 来源。该来源已随专用服务删除；把断言改为只允许现行 UI / 浏览器存档来源，并明确拒绝旧来源分支。目标专项复验通过。
- 布局门第 1 次在源码指纹阶段 `ENOENT`：删除的组件尚未暂存，`git ls-files --cached` 仍把它列入指纹。实质调整为先显式暂存该删除，再复验。
- 布局门第 2 次在构建指纹阶段发现 `ui-layout-build.json` 为 `null`：上次构建发生在删除文件尚未暂存时。实质调整为暂存删除后重新构建，再复验；704 状态、问题 0。
