# README 地图展示截图与默认可读性

本文对应权威任务第 266 项，冻结默认地图信息密度、默认标签视觉和 README 截图生成链的施工边界。任务状态与验收以 [`../current-plan.md`](../current-plan.md#权威任务清单) 为准。

## 问题与目标

当前 fresh session 的画布几乎打开全部专题图层；完整世界视图会同时出现省份名称、洋流、资源、军事、地区与测量等内容。默认中文字体栈又遗漏 Windows 已安装字体使用的 `Noto Sans SC` / `Noto Serif SC` 名称，国家、省份和城市标签在全图截图中显得拥挤。README 目前没有长期入库的产品画布截图，也没有可重复执行的生成命令。

第 266 项同时解决两个相邻问题：让新用户第一次打开地图时先看到清晰的核心地图；让维护者用一个命令在隔离环境中生成固定构图的 README 展示图。两者共享标签和图层契约，但展示预设比产品默认更克制，不能反向把 README 特例误当作所有用户的默认地图。

## 冻结的产品默认

- fresh session 默认开启：海岸、湖岸、河流、道路、城市、常规标签、国家名称、人口、比例尺和国界。
- fresh session 默认关闭：贸易流、洋流、省份名称、省界、Marker、资源点、军事、战线、全部地区子层、测量、地图徽记和网格。
- `localStorage` 中已有的逐图层偏好继续优先于默认值；本项不清理、不迁移、不重写用户设置。
- `population` 因当前没有首层恢复开关，继续作为产品默认开启；只在 README 展示预设中关闭。
- 全局城市标签上限从开发期的近似无限值收敛到 `128`；README 展示同样固定为 `128`。已有用户偏好继续覆盖全局默认。
- 默认字体栈补入 `Noto Sans SC` 与 `Noto Serif SC` 的真实 family 名称；标签风格修改只作用于默认 registry 与默认主题。旧图或用户显式保存的样式继续按既有优先级覆盖。

## 冻结的 README 场景

- 画布：`1440×960`，设备像素比 `1`。
- 生成：`10000` 目标 cells、`continents` 高度模板、`12` 个国家、`30%` 省份比例。
- 种子：固定为 `mountains-and-seas` 且显式设置 `randomSeed: false`，不使用当前页面默认种子或每次随机种子。
- 画面：relief 使用 `height` 视图并只保留地貌、岸线、河流与比例尺；atlas 使用 `states` 视图并保留国家着色、国界、国家名称、首都 / 城市、河流、道路、岸线与比例尺。两者都关闭人口、省份、Marker / 资源、军事 / 战线、地区、测量、地图徽记和网格，并清除 selection 与临时高亮。
- 主题：同一 canonical 地图分别导出无政治标签的 relief 自然地貌和 atlas 国家视角，不为第二张重新生成地图。
- 输出：`docs/assets/readme/showcase-relief-overview.png` 与 `docs/assets/readme/showcase-atlas-overview.png`，由中英文 README 直接引用。

## 自动化与安全边界

生成工具必须自行启动临时静态服务和隔离的系统 Chrome，创建独立临时 profile，由 Playwright 持久上下文管理该脚本拥有的浏览器，并建立独立 CDP session 设置确定性视口。它不得探测或复用用户浏览器的调试端口，也不得刷新或关闭现有会话。流程结束或中途失败时都要关闭浏览器与服务并删除临时 profile。

图片必须来自应用正式 `data.exportPNG` 合成路径，不使用页面截图，也不把工具栏、面板、提示或浏览器 UI 混入画面。生成前后核对地图 checksum 与 revision；同时收集 console、page、health 和 WebGL 错误。工具只依赖仓库已有依赖和本机系统 Chrome，不下载字体、浏览器或网络资源。

- 标签样式、默认标签、碰撞 / 城市净空、图层信息架构、PNG 选项和生产构建通过。
