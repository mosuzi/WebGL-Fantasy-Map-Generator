# 保存到夸克网盘可行性调研

本文记录权威任务第 70 项的调研问题、官方证据边界、安全门禁和交付格式。活动状态与执行顺序仍以 [`../current-plan.md`](../current-plan.md#权威任务清单) 为准。

## 2026-07-16 初查

- [夸克网盘官网](https://pan.quark.cn/)公开网页上传 / 下载、Windows / macOS / 移动 / TV 客户端、浏览器插件和桌面备份能力。
- [夸克扫描王开放平台](https://scan.quark.cn/business)公开 API、MCP、CLI 等接入形式，但页面列出的能力是 OCR、扫描、文档处理等 AI 能力，不能据此推定存在夸克网盘文件存储 API。
- 本次官方域名检索尚未找到面向普通第三方 Web 应用的夸克网盘上传 OpenAPI、OAuth 授权、CORS 或文件管理文档。这个结论只表示“初查未发现”，正式调研仍需核验开发者后台、服务协议、官方公告和合作咨询渠道。

## 必答问题

1. 是否存在个人开发者或企业可申请的官方文件上传 API；申请条件、审核、费用和调用配额是什么。
2. 是否有 OAuth / 授权码 / PKCE 等无需接触用户密码、Cookie 或长期 token 的授权方式。
3. 浏览器能否直接调用；若不能，后端代理需要保存什么凭据，服务端部署与隐私责任是什么。
4. 是否支持目录选择 / 创建、同名冲突、覆盖、重命名、删除、分片、断点续传、进度、取消、校验和错误重试。
5. 文件大小、类型、频率、空间和会员限制是什么；完整地图 JSON、压缩 JSON、PNG 与 GeoJSON 是否都允许。
6. 服务协议是否允许第三方地图应用代用户上传；品牌、用户告知、隐私政策和数据删除有什么要求。
7. 官方 API 不可用时，能否可靠地把文件导出到夸克客户端监控 / 备份目录；网页下载后手工上传应如何明确标注为降级方案。

## 需要比较的路线

| 路线 | 前置条件 | 调研重点 |
|---|---|---|
| 浏览器直传 | 官方 OAuth / OpenAPI 与 CORS | 是否能做到无项目后端、最小权限、目录选择和上传进度 |
| 项目后端代理 | 官方服务端 API / 合作凭据 | 凭据托管、用户授权映射、运营成本、隐私与限流 |
| 客户端同步目录 | 用户安装官方桌面客户端 | 浏览器文件选择 / 保存限制、目录授权、同步状态不可观测边界 |
| 本地下载后上传 | 无官方开发接口 | 保留现有导出，提供清晰操作说明，不冒充一键云保存 |

## 安全停机条件

- 不调用逆向发现的网页私有接口。
- 不读取、导入或持久化 Cookie，不要求用户粘贴 token，不自动化扫码登录。
- 不把任何授权信息写入地图 JSON、普通 LocalStorage、日志、截图或调研报告。
- 官方许可、认证流程或数据删除边界无法确认时，不制作上传 PoC。
- 需要商务合作或后端服务时，只报告前置条件和成本，不在本调研任务内自行开通或部署。

## 交付与验收

调研报告必须：

- 只引用官方页面、官方开发文档、服务协议、隐私政策、官方公告或可记录的官方合作答复，并注明核验日期。
- 给出“可直接实现 / 需要后端或正式合作 / 当前不建议集成”三选一结论。
- 画清认证与文件数据流，列出前端、后端、夸克和用户各自持有的数据与责任。
- 覆盖至少完整地图 JSON，并说明 PNG、GeoJSON、压缩 JSON 能否复用。
- 列出安全、隐私、可用性、配额、浏览器兼容、失败恢复与供应商锁定风险。
- 给出推荐路线、降级路线、预估改动文件 / 模块和若获批准后的最小验收草案。

只有官方上传能力与许可得到确认时，才允许上传一份不含真实地图或个人信息的测试 JSON，并在验证后按官方接口删除；否则以客户端同步目录或本地下载流程验证降级可达性。调研完成不等于集成获批，正式实现必须另立权威任务。
