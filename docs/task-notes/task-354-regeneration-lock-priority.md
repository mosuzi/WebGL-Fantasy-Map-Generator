# 第 354 项：全部重新生成入口落实锁定最高优先级

> 2026-08-25：本项产品、专项与浏览器夹具已单独移植到 `codex/map-core-engine-architecture-plan`，保留 MapCoreEngine 的 owner、revision、提交前验证和 GPU 快切约束；重构分支集成版本为 `0.5.63`，仍不合入 `main`。

## 重构分支集成复验

- AST 静态门、TypeScript、正式构建、四组 MapCoreEngine 领域协议和复合 Worker 均通过；复合 Worker 同时覆盖 100k、绑定过期、取消、故障回滚和 GPU 常驻岸线预热。旧夹具补齐 `renderPreparationId / renderGeneration` 与 `gpuShoreSurface` 正式契约，保存反馈夹具的 Playwright 解析也移回资源 owner `try`，没有放宽 owner、revision、binding 或失败清理校验。
- 十一类正式重生成 × 十五类锁仍为 `165` 组：`164` 组执行并保留锁定快照、`1` 组全锁 no-op、失败 `0`。省会与洋流世界构造样本专项通过。
- 真实 Chromium 门因本机 Chrome headless 启动器在页面创建前退出，夹具保留 Chrome 默认值并新增 `FMG_BROWSER_CHANNEL` 测试覆盖参数，本次用系统 Edge Chromium 隔离复验。直接领域 LongTask `0`、应用 / 页面 / WebGL 错误 `0`；复合 world / climate / seafloor 分别为 `15 / 7 / 14` 类锁与 `11 / 2 / 12` 个阶段，全锁 `15285` 个对象成功 no-op，`after:rivers` 故障只注入一次并完整回滚，最大 LongTask `169ms`，应用 / 页面 / WebGL 错误 `0`。

## 结论

正常、可读取的锁定内容不再阻塞任何主动重新生成。十一类正式 `generate.regenerate` 与高度派生、气候下游、洋流世界和海底等复合重建都把显式锁及其必要支撑闭包作为不可覆盖约束，只在剩余空间生成；目标领域全部锁定时成功 no-op。对象缺失、镜像损坏、越界或结构本身不可解析仍按数据损坏精确拒绝，避免把真正坏档伪装成可满足的业务冲突。

## 巡检分母

- 静态入口盘点覆盖 `14` 个面板、`15` 类锁、`22` 个重新生成入口，登记与实现差异为 `0`。
- 十一类正式入口与十五类锁的交叉矩阵共 `165` 组：`164` 组成功执行并保持锁快照，唯一“标记全部锁定”场景成功 no-op，失败 `0`。
- 复合入口另覆盖高度派生、气候下游、洋流世界、海底重建，以及全锁 no-op、取消、过期、故障回滚和撤销 / 重做。

## 实现要点

1. 新增统一锁优先闭包：锁定国家带入省份、城镇、外交和军事；锁定 Feature 带入相关城镇、路线与标记；经济市场 / 交易带入端点城市和国家；锁定城市补齐首都 / 省会锚点；锁定 Warzone 补齐外交对；锁定河流补齐湖泊、源头与出口 Feature。
2. 国家重生成不再因为可读取的锁定外交关系主动拒绝；外交保留可读取的战争派生数据，军事完全跳过锁定国家。无效端点、非互惠关系和损坏结构仍精确报错。
3. 政治扩张、城镇落位、省会重选和 Feature 拓扑都先排除受保护所有者。锁定国家 / 省份即使没有首都 / 省会也保持原状，不再为了满足新生成器偏好而改锁或拒绝。
4. 显式社会对象按完整快照恢复，依赖锁只保结构支撑；快照比较改用稳定键，避免对象属性顺序产生假冲突。
5. 正式 Worker 与主线程复合入口都在生成前捕获约束，补丁提交后恢复显式社会对象快照，并在最终提交前断言锁定内容未变。故障、取消和过期路径保持原子回滚。
6. 补齐高度派生、气候下游和洋流世界的 picking 写集；洋流世界故障注入透传到正式入口，确保复合事务的成功与回滚均由真实路径验证。

## 真实浏览器验收

- 直接领域：锁定外交对下的国家重生成成功且外交对原样保持；军事锁定为成功 no-op；应用错误与页面错误均为 `0`。
- 高度 / 国家：高度链共 `6` 类锁、`5` 个派生阶段；基础全锁 `535` 个对象成功 no-op；国家链覆盖 `4` 类锁，锁定外交下仍成功重生成；应用错误、页面错误和 WebGL 错误均为 `0`。
- 复合链：洋流世界覆盖 `15` 类锁、`11` 个阶段；气候链覆盖 `7` 类锁、`6` 个阶段；海底链覆盖 `13` 类锁、`12` 个阶段；`15285` 个对象全锁场景返回 `domain-fully-locked`；`after:rivers` 故障成功回滚。应用错误、页面错误、WebGL 错误与 `regeneration_lock_conflict` 均为 `0`。

浏览器性能记录把操作等待信号与应用错误分开统计。气候专项并行首轮受资源竞争影响出现 `200.68ms`，按门禁做一次隔离复验后最大阻塞为 `140.54ms`；没有用重复全门掩盖首败。全锁大验证产生的单次主线程长任务只登记为该验证入口的性能信号，不属于锁冲突或提交失败。
