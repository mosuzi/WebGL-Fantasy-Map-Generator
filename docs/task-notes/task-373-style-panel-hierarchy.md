# 第 373 项：样式页国界效果与地图标签层级

## 问题

“国界晕染”虽已有独立卡片，但标签样式控件紧随其后直接铺开。用户难以从层级判断前者是全局国家视图效果，后者是随当前地图保存并进入历史的标签文字样式。

## 冻结方案

- 顶级“样式”页保持不变，内部增加互斥的“国界效果 / 地图标签”二级入口。
- 国界页只展示启用、宽度、强度及“仅国家视图”的范围说明。
- 标签页把类型、预览、字体、字重、字号、颜色、描边、阴影与重置动作收进同一类别卡，并说明其为当前地图、按标签类型调整。
- 二级切换只控制 UI 显隐，不触发国界或标签事件，不持久化为地图数据。

## 验收

- 两类控件互斥显示，语义标题与作用域可被 DOM 和视觉直接识别。
- 切换前后国界偏好与标签样式快照不变，返回后保留本次二级选择。
- 桌面与窄面板无横向溢出；既有两类专项、production build 和真实浏览器目标窗口通过。

## 完成结果

- 二级类别默认显示“地图标签”，切到“国界效果”时标签卡互斥隐藏；离开顶级“样式”页后返回仍保留本次二级选择。
- 两张卡分别显示“全局显示偏好 · 仅国家视图”和“当前地图样式 · 按标签类型”，并用不同侧边色强化层级。
- 真实浏览器抽样国界启用 / 宽度 / 强度与标签类型 / 字体 / 字号，类别切换前后完全一致；目标窗口无新增 warning / error。
- `640×800` 视口下页面、二级导航和两张活动卡均无横向溢出；国界晕染、标签样式专项与 `1408 modules` production build 通过，完成版本 `0.5.85`。
