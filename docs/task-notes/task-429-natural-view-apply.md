# 第 429 项：失焦提交与显示设置自然生效

## 玩家动作与变动闭包

玩家在不能换行的单字段中编辑名称、数字或颜色，按回车或离开输入框即提交有效值；同值不新增历史，输入法选字不提交，Esc 和明确关闭放弃草稿，错误时保留草稿以便重试。外点关闭先让输入框失焦并完成提交。改色、外观选择与显示视图/图层设置在选取时自动作用于画面，无第二个“应用”步骤。

规范地图编辑继续经原命令及单次历史，覆盖地图事实、镜像、GPU、标签、列表、撤销和保存；纯显示偏好不写地图编辑历史，进入现有偏好保存链。显示任务按具体设置键排序，同键保留最后一次，不同键依次应用。后台主题刷新失败时撤回尚未呈现的主题编辑命令，恢复主题注册表、地图资料、历史及控件，保留原草稿供重试。

## 入口清点与边界

| 类别 | 入口 | 现行提交时机 |
|---|---|---|
| 单行文本 | `UiTextEditField` 的 15 个面板宿主、动作坞快速重命名 | 回车或有效失焦；Esc/关闭取消 |
| 数字 | `UiNumberField` 的 3 个宿主、城市人口 | 回车或有效失焦；城市人口仍走原事务 |
| 预设名称 | PNG 预设名称 | 回车或失焦保存，刷新后可回读 |
| 颜色 | 国家、省份、文化、宗教、地区、用户主题共 6 个共享颜色宿主 | HEX 回车/失焦，HSL 变更结束、预设色点击即应用；点击预设不先提交未完成 HEX 草稿 |
| 外观 | 城市剪影、标记图标/配色、地区纹理 | 选中即应用 |
| 视图与图层 | 12 种视图、22 个单图层按钮和 2 个图层组 | 点击即切换；相同设置后发覆盖先发，不同设置顺序兑现 |
| 显示选项 | 海洋高度、边界平滑、地图边缘渐隐、国家边缘效果、最大城市标签数、用户主题 | 变更即排入显示链；后台画面准备结束后自动呈现 |

用户追加裁定：自然应用也覆盖重生成与整图替换，只有真正危险的动作才保留额外保护。按实际恢复能力清点如下：

| 数据链路 | 玩家动作与保护 | 依据 |
|---|---|---|
| 11 类管理页领域重新生成及各专用面板重算 | 选定目标后点一次“重新生成/重算”即执行，不再弹确认 | 这是明确的重建动作，事务完成后可用单次历史撤销；仅改变目标下拉框不触发地图重建 |
| 洋流与世界整链重算 | 点一次“重算气候与世界”即执行，运行中可取消 | 原生二次确认已移除；事务为单次历史，可撤销/重做 |
| 预览后的海底重设 | 先看预览，点一次“应用重设”即执行 | 原生二次确认已移除；预览不会写图，正式重设为单次历史，可撤销 |
| 高度全局工具、模板与灰度图导入 | 预览后由明确动作应用 | 预览用于判断地形或完整换图结果，不把改变选择器当作确认 |
| 生成新地图、按模板创建、导入完整地图或云图 | 明确的“生成/创建/导入”动作；保留完整换图的 API 显式授权和云端覆盖提示 | 完整换图会清空编辑历史，云端覆盖还会改写外部旧版本，属于危险动作 |

第 402 项的非画布全面改造仍冻结。本项不改持久格式或旧档迁移链。

## 关键修复

- 浮层外点先提交输入，再关闭；Esc 和关闭图标显式跳过失焦提交。输入法、同值、空值、错误草稿与失败重试保持各宿主语义。
- 地区样式只重建主线缓冲中的地区纹理段，保留海岸、政区和军事线层；解决纯改色触发全量线层重建的 `229ms` 峰值。
- 用户主题编辑保留地图命令历史，显示刷新按意图队列顺序兑现，同 ID 改色也刷新；待显示命令形成独立账本，任务成功时结清其前的命令，失败时仅逆序补偿仍待显示的命令。玩家仅切换显示主题时，地图登记主题可不同于 renderer，不能用两者是否相等推断历史回滚边界。
- 共享颜色预设的 pointerdown 阶段阻止 HEX 草稿因焦点转移抢先提交；键盘 Tab 仍正常提交 HEX。
- 可撤销的海底与洋流世界重算去掉原生二次确认；海底成功文案从预览数据读取实际受影响格数，避免提交成功后访问已离开作用域的变量。
- 主题改色复用海岸修正面的现有三角形与 cell 范围，只重算顶点颜色，按约 `6ms` 预算分片让出主线程；正式主题、路线、标签经 GPU 常驻路径更新。平滑海岸的 10k 四类顶点共 `17,151` 个，与完整重建逐值相等；颜色缓存限制为最多 `12` 份，避免连续调色无界增长。

- 10k 视觉编辑夹具：六处颜色、三类外观即时应用；地区图层开启后，颜色与纹理 GPU 顶点指纹变化，撤销/重做逐态精确恢复。用户主题同 ID 改色影响约 `45.7` 万画布像素；撤销残差在原状态海岸同态波动内，重做恢复。故障注入覆盖主题执行、撤销和重做，以及地图登记 B、只显示 A 后编辑 A 的失败补偿；同一事件轮连续两次改色、后一显示任务失败时，两条未呈现编辑一起回退，先前成功的建主题命令保持。资料、历史、renderer 回退与同值重试通过。主题改色可见完成 `134～137ms`，其中 GPU 更新 `55.3～60.2ms`；原复合测试中 Worker 准备为 `1.6～7.3s`。优化后正常操作最长 LongTask `112ms`、`>200ms=0`、页面/WebGL 错误 `0`。
- 约 100k（实际 `99,846` grid 格）高度视图与边界平滑复合图，正式颜色弹层改主题色后 `139ms` 可见，GPU 更新 `70.1ms`，改变正式画布 `1,224,000` 像素；目标窗口 LongTask `>200ms=0`，WebGL / 页面错误 `0`。
- 数据动作正式入口：3k 管理页“重新生成资源点”点一次产生一条历史，无浏览器确认；随后生成页点“换种子 → 生成地图”装入新图并清空原编辑历史。10k 高度面板“预览新海底 → 应用重设海底”实际改写 `5949` 个 grid 格、`1053` 个 pack 格，单条历史、无额外弹框，预览图层清除并自动显示海底；2k 洋流面板“重算气候与世界”一次点击执行、无额外弹框，API 历史往返精确。上述浏览器目标窗口应用错误 `0`，3k 视图/生成组合最长 LongTask `128ms`。
