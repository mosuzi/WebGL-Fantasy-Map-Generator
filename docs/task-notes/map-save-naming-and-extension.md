# 地图名称、云端命名模板与原生存档扩展名

## 背景

当前生成参数没有独立地图名称，文件名只能依赖 seed、checksum 或调用时刻。云端新建直接采用压缩导出的固定文件名，用户无法形成稳定、可读的命名规则；原生压缩存档后缀 `.webgl-map.json.gz` 也过长。

本项只整理地图身份和存档外壳，不改变地图内容、生成算法或压缩数据。

## 冻结规则

- 地图名称保存在 `options.mapName` 与 `map.metadata.name`，默认值为“未命名地图”。旧图缺少名称时使用原 seed 回填，名称不参与地图 checksum。
- 生成 Tab 中的名称随生成参数同步；导入后恢复到输入框。用户修改输入后，下一次生成与保存使用新名称。
- 云端新建模板默认 `{name}-{date}-{time}.{ext}`，支持 `{name}`、`{date}`、`{time}`、`{seed}`、`{checksum}`、`{ext}`。
- 日期固定为本地 `YYYY-MM-DD`，时间固定为本地 `HH-mm-ss`；所有 token 使用同一个时间快照。
- 模板可直接写普通文件名；未知 token 明确拒绝。空模板恢复默认值，非法文件名字符统一替换，最终文件名限制长度并强制以当前原生扩展名结尾。
- 模板是当前浏览器的共享保存偏好，不进入地图 schema；地图名称输入右侧的设置图标按需展开格式输入、token 帮助和实时预览，入口始终可用但默认收起，也不要求配置云盘。本地“保存”、高级压缩导出与云端新建共用该模板，云端面板只展示当前新建文件名和入口提示。
- 云端新建使用模板结果。覆盖继续沿用选中文件的远端身份和原文件名，不因模板或地图名称变化而重命名。

## 扩展名决定

`.wff` 已被其它小众格式使用，三字符扩展名也无法保证唯一。正式扩展名采用 `.webfmg`，含义为 WebGL Fantasy Map Generator 存档。

`.webfmg` 仍是 gzip 压缩的地图 JSON，MIME 保持 `application/gzip`。旧 `.webgl-map.json.gz`、`.json.gz`、`.gz` 和未压缩 `.json` 继续可导入；云端列表继续识别旧扩展名。新建云端存档、本地“保存”和压缩完整地图导出改用 `.webfmg`。

## 数据流

1. `ControlPanel.vue` 提供地图名称输入，`panel.js` 读写 `mapName`。
2. `options.js` 归一化名称，生成器写入 `map.metadata.name`；`map-file-io.js` 在导出和旧图读取时同步兼容字段。
3. 共享文件名模块负责原生扩展名、旧后缀识别、模板解析、文件名清洗和长度门禁。
4. 本地保存、压缩导出和云端新建复用同一命名结果；其它 PNG、GeoJSON 等导出只复用地图基础名称，不自动附加日期时间。
5. Dropbox / Google Drive provider 只负责安全归一化和传输；覆盖不改变选中文件名。

## 验收矩阵

- 纯函数：名称归一化、旧图回填、固定时间六类 token、直接文件名、空模板、未知 token、非法字符、重复 / 旧扩展名和长度上限。
- 协议：Dropbox / Google Drive 同时列出新旧存档，新建使用 `.webfmg`，旧文件按原 id / path / revision 覆盖。
- 导入导出：API 压缩导出、本地下载、File / Blob、gzip-base64、无头 CLI 新旧扩展名往返。
- 浏览器：生成 Tab 名称输入；云端模板、预览和刷新持久化；本地实际下载后重新导入；`1440 / 390 / 320px` 无溢出。
- 公共门禁：相关语法检查、专项回归、生产构建、`git diff --check`，应用 console / page / health / WebGL error 为零。

## 排除

- 不把浏览器固定单槽 LocalStorage 改成多存档系统。
- 不按文件名查找或覆盖云端对象，不增加远端重命名。
- 不改变 gzip 算法、地图文档版本、公开地图数据结构或 checksum。
- 不访问真实 Dropbox / Google Drive 账号，不修改 `source/`。

## 验收结果

第 268 项已完成。纯函数、云端 mock、旧图迁移、无头读写、API 往返、生产构建与差异检查通过；独立复核在修正地图替换后的云端预览刷新后为 `ACCEPT`。系统 Chrome 三档视口完成实际 `.webfmg` 下载、gunzip、UI 重导入、模板持久化、未知 token 拒绝与换图预览同步；共享模板专项实际捕获主保存和高级压缩导出的两个同名文件并核对内容，横向溢出和 console / page / health / WebGL error 均为零。
