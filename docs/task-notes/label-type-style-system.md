# 标签类型样式系统

本文记录权威任务第 69 项的标签类型、样式字段、控制面板入口、持久化和验收契约，以及第 108 项追加的本机字体选择与缺字回退语义。活动状态与执行顺序仍以 [`../current-plan.md`](../current-plan.md#权威任务清单) 为准。

第 69 项完成后，权威任务第 80 项继续基于同一标签类型 registry 增加显示优先级与位置锁定；第 69 项只负责排印样式，不应提前吞并第 80 项的世界锚点和碰撞优先级语义。

## 已确认的现状

- 控制面板目前只有“简介 / 生成 / 视图 / 图层 / 管理 / 单位”六个 Tab；“视图”负责视觉主题和画布滤镜，不适合继续堆叠标签排印设置。
- renderer 当前只生成国家、城市和手工标签，`LABEL_TARGET_KIND` 也只有 `state / city / custom`；省份对象存在，但没有正式省份名称标签。
- 标签颜色可从视觉主题读取，字体族、字号、字重、字距、阴影和轮廓主要由固定 CSS 决定。
- PNG overlay 会读取标签 DOM 的 computed style，因此样式模型需要同时驱动画布 DOM 与 PNG 合成，不能维护两套独立默认值。

## 首批标签类型

- 国家名。
- 省份名。
- 首都名。
- 普通城市名。
- 手工标签。

国家与省份是区域中心标签，首都与普通城市是点标签，手工标签保留自身可拖动与背景能力。河流、湖泊、山脉、文化、宗教等未来类型不在本项新增，但 registry 必须允许后续扩展而不改写现有存档。

## 样式字段与继承

每个类型首批支持：

- 字体族：从稳定系统 / 内置字体栈选择。
- 字号、字重、斜体和字距。
- 文字颜色与不透明度。
- 描边颜色与描边宽度。
- 阴影 / 光晕颜色、偏移、模糊或等价的有限强度配置。
- 描边宽度以 `0.05px` 调节，阴影横移、纵移和模糊以 `0.1px` 调节；数值精度必须原样进入历史、存档、实时标签和 PNG。

字段采用“内置默认 -> 当前视觉主题 token -> 用户类型覆盖”的优先级。用户未覆盖的字段继续继承主题；切换主题不得抹掉显式覆盖。重置当前类型只删除该类型覆盖，全部重置删除所有标签类型覆盖。

不支持上传本地字体文件、嵌入字体二进制、加载任意远程 URL 或把外部字体塞进地图 JSON，避免文件膨胀、跨域、许可和导出不可复现问题。第 108 项只允许通过用户明确触发的浏览器 Local Font Access API 读取获准访问的字体族名称。

## 本机字体扩展

- “样式”页保留五个稳定内置字体栈，并提供独立“读取本机字体”按钮；页面载入和存档恢复不得静默枚举本机字体。
- 浏览器授权后读取字体族、完整名称与 PostScript 标识，只用于构造本机候选；同族多个字形去重，界面优先显示完整名称，缺失时回退字体族或 PostScript ID。不会读取字体文件内容，也不会把字体二进制写入地图或上传到任何位置。
- 本机字体覆盖保存为 `fontFamilyId: local` 与 `fontFamilyName`。名称必须非空、长度不超过 128 个字符且不含控制字符；旧存档继续使用原有内置字体 id。
- resolved font stack 固定为“存档字体族 + 系统 fallback”。目标机器缺少该字体、浏览器不支持 API、用户拒绝权限或读取失败时，地图仍可打开并使用系统字体。
- 动态候选明确区分本机已发现、存档未检测到和系统回退状态；切回内置字体时清除本机字体名称覆盖。

## 独立“样式”Tab

- “样式”作为控制面板一级 Tab，与“视图”“图层”并列，不放进标签管理面板。
- 首层提供标签类型切换、当前继承来源、有限样例预览、主要字段和重置动作。
- 修改应实时作用于地图，但不改变地图地理 / 生成 checksum；字号或字距变化后必须重新计算标签包围盒与可见性。
- 窄视口下控件仍可滚动到达，不得让字体选择器或颜色编辑浮层遮住 Tab 导航。

## 数据、兼容与导出

- 标签样式属于地图显示配置，随完整地图 JSON 保存；加载旧地图时通过显式 normalize / backfill 得到空覆盖，继续使用当前默认与主题。
- 增加省份标签时，需要同步类型常量、renderer 生成 / 布局、图层可见性、标签隐藏 / 恢复语义、有限状态和 PNG overlay。
- 实时画布与 PNG 必须使用同一个 resolved style；缺少系统字体时使用同一 fallback 栈并在结果中可诊断。
- 用户视觉主题的既有标签颜色继续有效，不能因新增类型样式而破坏主题导入导出或旧主题文档。

## 最小验收

- 五类标签分别设置明显不同的字体、字号、字重、颜色和描边后，实时地图只改变目标类型。
- 切换主题时未覆盖字段改变、已覆盖字段保持；单类重置和全部重置恢复准确。
- 省份名在规定缩放范围出现，缩放、平移、字号变化与窗口 resize 后布局稳定，不覆盖国家名的语义层级。
- 完整地图 JSON 往返、浏览器刷新和至少一份旧地图样例兼容通过；地图地理 / 生成 checksum 不因纯样式修改变化。
- 同一视口 PNG 与实时画布在标签类别、字体 fallback、字号、颜色、描边和透明度上保持一致。
- 模型、Tab、renderer、省份标签、兼容与 PNG 专项回归、生产构建和 `git diff --check` 通过；同一 Chrome 完成五类型、主题、重置、刷新与 PNG 对照。

## 明确不做

- 不在本项新增河流、湖泊、山脉、文化或宗教标签。
- 不提供字体文件上传、远程字体 URL、逐个标签的任意排印覆盖或文字沿路径排版。
- 不把“样式”Tab 扩展成所有 WebGL 图层的完整符号化编辑器。
