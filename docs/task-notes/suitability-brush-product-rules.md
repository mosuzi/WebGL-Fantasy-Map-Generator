# 数值适居度笔刷规则

本文冻结权威任务第 77 项的首期数值语义与数据边界。实现与验收不得扩展到人口迁移或完整生态模拟。

## 首期语义

- 首期只采用“直接设值”，目标适居度为整数 `0～100`，步长 `1`；不实现增减值或比例缩放。
- 同一 stroke 内每个命中 cell 最多应用一次目标值，连续经过不会叠加；重复 stroke 可以重新设值。
- 提供“恢复基础值”清除手工 override，属于直接设值的配套回退，不新增第二种调整语义。

## 基础值与持久化

- 基础值来自现有生物群系、气候、地形、水文和资源适居度计算链；手工 override 存在时最终 `cells.s` 取 override，不再叠加基础值。
- 生物群系或资源链重算会先更新基础值，再重新应用手工 override；清除 override 后立即恢复最新基础值。
- pack 语义层持久化基础值与 override，grid 适居度和人口承载继续作为 pack 映射派生；旧图缺字段时以当前 `cells.s` 回填基础值、以“无 override”回填手工层。

## 陆水与人口承载

- 作用范围支持 `land / water / all`；`land` 只命中 `h >= 20`，`water` 只命中 `h < 20`，`all` 同时允许两类。
- 陆地人口承载继续按最终适居度、cell 面积和平均面积计算；适居度为 0 时承载为 0。
- 水域允许保存适居度供专题与后续环境逻辑读取，但人口承载始终为 0，不生成或迁移城市。

## 事务与派生

- 半径、目标值、作用范围、悬停范围和拖动预览由 UI 与 API 共用同一命令；抬手提交一个 stroke 为一条历史，取消完整回滚。
- 成功后同步 pack / grid 适居度与人口承载、气候摘要、国家、省份、文化、宗教的乡村人口统计，并标记城镇、政治、宗教、标记、地区、军事、经济和外交等下游为 stale。
- 不自动重生成城市、边界、文化、宗教、经济或其它对象；完整地图、浏览器存档和旧图兼容沿用现有 schema v2 容器。
