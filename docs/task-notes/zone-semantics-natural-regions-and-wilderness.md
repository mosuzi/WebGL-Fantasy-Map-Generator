# 地区语义、自然地区与自动无人区施工图

## 用户问题与现状

用户确认现有地区需要同时补齐三类能力：

1. 入侵、传教、叛乱等事件地区必须明确“谁对谁做什么”，不能只显示类型、纹理和 cells。
2. 地区类型增加无人区、沙漠、沼泽等自然类型，并允许创建名称、说明、样式和基础影响均可自定义的地区；基础影响默认无。
3. 地区图层自动识别连成块的无人区，每个不连通分量都是独立对象、独立名称，并可像国家一样显示和重命名。

当前 `zones` 仍以 source 风格事件覆盖区为主。`Warzone` 已保存 `attacker / defender`，但 `Invasion` 计算参与国后只写名称和 cells，`Proselytism` 计算来源 / 目标宗教后同样丢失引用，`Rebels` 只保留所在国家名称。地区创建要求单对象连通且与全部既有地区互斥，不能表达“沙漠上同时发生战争”；WebGL 地区层只绘制纹理，标签系统没有地区目标；地区管理也没有正式的名称、语义和影响编辑器。

## 统一模型

地区仍使用统一的 `zone` 对象和地区管理入口，不新增“无人区国家”。新增字段全部允许缺省，并由兼容入口归一化：

- `category`：`event / natural / custom`。
- `source`：`generated / auto-wilderness / manual / legacy`。
- `type`：稳定类型键；自定义地区另存 `customTypeName`。
- `context`：结构化参与方、来源、状态和简要说明。
- `effects`：`habitability / movementCost / economy / defense` 四项基础修正。
- `nameMode`：`auto / manual`，自动无人区改名后进入手工保护。
- `labelHidden`：只控制地区名称标签，不等同于隐藏地区面。

自然底区之间不得重叠；事件覆盖区可与自然 / 自定义底区重叠。旧的事件地区互斥语义继续保持。自定义地区创建时选择底区或覆盖区，默认作为底区。

`effects` 使用中性默认值：宜居度 `0`、通行成本倍率 `1`、经济产出倍率 `1`、防守修正 `0`。本批建立确定性归一化、cell 级合并查询、UI / API 与导出契约；不开放脚本表达式，不在加载旧图时静默改人口、道路、经济或战斗结果。现有系统只有在显式读取地区影响时才消费这些值。

## 第 220 项：事件地区关系与信息完整性

### 类型角色

- `Warzone / Invasion`：进攻国、目标国。
- `Rebels`：叛军身份、反抗国家；叛军身份依次从显著文化、宗教、所在省份或地区性通名确定，不伪造独立国家。
- `Proselytism`：传播宗教、目标宗教，并派生涉及国家。
- `Crusade`：发起宗教 / 国家、目标宗教 / 国家。
- 疫病与自然灾害事件：来源城市、河流、marker 或地貌单元，以及受影响的国家 / 城市。

`context.participants` 使用 `{role, ref: {kind, id, nameSnapshot}}`。显示时优先按 id 解析当前对象名称，`nameSnapshot` 只在对象已删除或旧图缺镜像时兜底。摘要由结构化引用实时生成，不把名称字符串当作关系真相。

### 旧图回填

- 已有 `attacker / defender` 的战区直接转入 context，同时保留旧字段供军事规则兼容。
- 入侵、传教和叛乱只在 cells、邻接和归属能得到唯一结果时回填，并标记 `inferred: true`。
- 结果不唯一时显示“参与方待补充”，不从英文名称强猜。

### 最小验收

- 固定入侵、传教、叛乱和战区样本均生成完整结构化关系；对象解析、悬停、地区表和详情使用同一摘要。
- 参与方改名后摘要同步；对象删除后使用快照并显示失效状态。
- 旧图缺 context 可读、可导出、可撤销编辑；回填确定且不会改 cells。
- 地区 context 编辑是一条历史事务，失败完整回滚；公开 API、schema、对象查询和 GeoJSON 同步。

## 第 221 项：自然类型、自定义地区与基础影响

### 内置自然类型

第一批内置 `Wilderness / Desert / Swamp / DeepForest / Grassland / Tundra / Highland / Badlands / VolcanicLand`，分别显示为无人区、沙漠、沼泽、密林、草原、苔原 / 冰原、高地 / 山地、荒地、火山地带。它们是可命名的大区对象，不替代逐 cell biome。

### 自定义地区

地区管理创建入口允许设置：类别、内置或自定义类型名、地区名称、说明、半径、颜色、面纹 / 实心显示和四项基础影响。名称、类型、说明、样式与影响均可在创建后以单条可撤销事务修改。

### 最小验收

- 自然底区与事件区可重叠；同一底区类别仍拒绝重叠，错误码明确。
- 内置类型、自定义类型和 effects 在 JSON、gzip / base64、浏览器缓存、对象查询、GeoJSON 和撤销 / 重做中一致。
- `effects` 缺失时严格等于中性值；cell 级查询对底区与覆盖区按固定规则合并且有上下限。
- 旧十二类地区自动归为事件类，未知旧类型归为自定义类，不改名称、cells 和样式。

## 第 222 项：自动无人区、分块命名与标签

### 识别与身份

自动无人区只读取陆地 `state = 0`、无城市且人口低于固定阈值的 pack cells，以 `pack.cells.c` 求连通分量。每个分量生成一个 `type = Wilderness / source = auto-wilderness` 的独立地区；不同分量禁止共享同一自动名称。

重算时按 cell 最大重叠匹配旧对象：分裂时最大碎片继承原 id 和名称，其余碎片获得新 id / 名称；合并时重叠最大的旧对象继承，其他对象退出。`nameMode = manual` 的名称优先保留，但绝不复制给多个不连通分量。

### 图层与标签

地区图层提供自然地区、事件地区、自动无人区和地区名称四个独立可见开关。事件地区继续使用纹理；自然地区使用低透明实心面和边界。地区标签在连通面内部使用稳定锚点、较低默认优先级和现有碰撞 / LOD，选择、定位和改名都落到真实 zone 对象。

### 最小验收

- 固定夹具中连通分量数、cells 覆盖、无城市 / 低人口条件和名称唯一性正确。
- 分裂 / 合并 / 无变化三类重算的 id、名称继承确定；手工名称不会扩散到多个分量。
- 四个可见开关互不篡改地图数据；地区标签可见、可选、可定位且不会压过主要国家 / 城市标签。
- 新图、旧图、国家中立化后的显式地区重算、导出、撤销 / 重做、生产构建与真实 Chrome 通过。

## 统一执行与排除
