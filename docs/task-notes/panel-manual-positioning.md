# 编辑面板手动位置优先

本文记录权威任务第 67 项的交互语义、实现边界和验收矩阵。活动状态与执行顺序仍以 [`../current-plan.md`](../current-plan.md#权威任务清单) 为准。

## 已确认的根因

- `PanelManager.open()` 会在每次打开后调用共存和重排逻辑，而不是只约束越界。
- 当主面板和对象详情可共存时，`dockPanelPair()` 无条件把主面板写到右侧、对象详情写到左侧。
- 当只有主面板且它与地图工具栏相交时，`keepPanelClearOfToolbar()` 也会把主面板直接写到右侧。
- Vue 异步挂载和内容尺寸变化会触发 `ResizeObserver -> reflowPanels()`，所以即使用户刚完成拖动，后续内容重排仍可能再次覆盖坐标。
- 自动重排后的坐标会被 `savePanelState()` 写回 LocalStorage，用户原先保存的左侧或中央位置因此永久丢失。

## 产品规则

面板位置分为“自动”与“手动”两种意图：

1. 从未被用户拖动、也没有可用保存状态的面板，可以使用自动默认位置、左右停靠和工具栏避让。
2. 用户完成一次有效拖动后，当前位置成为该面板的手动偏好；关闭重开、切换面板、刷新、选择变化、内容增高和对象详情开关都不得覆盖。
3. 手动位置只在面板完全或关键标题栏将离开视口时做最小钳制；工具栏遮挡属于用户主动布局结果，不得强制右移。
4. 主面板与对象详情发生碰撞时，优先移动尚未手动定位的一方；两者都为手动位置时不得静默改写任一持久坐标，可以在当前会话做最小可达调整或沿用窄视口“后打开者胜出”。
5. 自动重排和临时越界钳制不能伪装成新的手动偏好；只有真实拖动结束才能更新手动位置意图。

## 数据与兼容边界

- 面板状态只属于浏览器 UI 偏好，不进入地图 JSON 或地图 schema。
- 旧 LocalStorage 记录缺少位置意图字段时必须安全读取；不得清空用户已有坐标、宽度或打开状态。
- 当前“只恢复最后一个主面板”和开发面板不覆盖最后业务面板的规则保持不变。
- 固定导出浮层、高度图工作台、树状总览等继续使用自身安全区，不纳入主面板手动位置状态。

## 最小验收

- 城市、国家、高度三个代表性主面板分别拖到左侧、中央和右侧后，关闭重开、切换其它主面板再返回、刷新页面，位置与保存值误差不超过 `2px`。
- 打开和关闭对象详情、切换 selection、等待 Vue 异步内容挂载及触发面板高度变化后，手动主面板不移动到右侧。
- 主面板保持手动位置时，对象详情仍可打开且关闭按钮可达；自动对象详情优先使用剩余空间，不覆盖主面板持久坐标。
- 窄视口和窗口 resize 只做必要可达钳制；回到可容纳视口后不得把临时钳制结果当成用户新的手动偏好。
- 专项纯代码回归覆盖手动 / 自动状态转换、旧偏好兼容、共存决策和保存边界；`regress:panel-overlay-policy`、`regress:panel-overlay-browser`、`audit:ui-system`、生产构建和 `git diff --check` 通过。
- 同一 Chrome 中完成真实拖动、重开、刷新、对象详情共存和异步内容增高验收。

## 明确不做

- 不新增吸附动画、可视化停靠区、多窗口布局编辑器或面板分组系统。
- 不改变同一时间只保留一个主面板的既有规则。
- 不重做面板宽度、视觉主题、表格布局或业务面板内部功能。
