# 第 370 项：国界晕染样式

## 用户目标

用户要保留的不是国界几何平滑，而是初次载入存档时曾短暂出现的国界涂色过渡：两侧国家颜色沿国界形成半透明、朦胧的混色带，并能在样式中独立开关和调节。

## 冻结契约

- 新样式名为“国界晕染”，仅用于国家视图的国家填色过渡。
- 字段包含 `enabled / widthWorld / strength`；启用基线为 `false / 7 / 0.25`，宽度使用世界单位，强度限定 `0～1`。
- 三字段属于独立全局显示偏好，内置主题下也能直接调整；不得写入主题文档、要求复制用户主题或进入地图编辑历史。
- 旧显示偏好缺字段时默认关闭，不改变当前稳定画面。
- 晕染是填色效果，不改变国界线几何、国界线颜色或宽度，也不受国界线图层显隐控制。
- 色带必须以多级 alpha 轨道向两侧外沿连续衰减到完全透明；禁止整条使用同一 alpha 形成突兀的平行硬边。
- 现有海岸 / 湖岸平滑保留，但 UI 改回准确名称，不再宣称它包含行政边界。
- 地图 canonical 数据、政治归属、checksum、拾取、编辑、历史、导出尺寸和 `source/` 不变。

## 实现方向

现有 `political-layer.js` 已保留旧政治色带算法：国家侧总宽度为 `7` 世界单位，沿边界两侧取各自国家颜色。旧路径只在部分非 GPU fallback surface 中短暂绘制，最终 GPU 常驻 surface 不消费它，因此形成“初次可见、稳定后消失”的历史观感。

本项不恢复非规范第三态，而是抽出确定性的国界晕染 mesh：由国家边界路径和两侧国家颜色构建独立三角带，在总宽度内设置九道对称轨道。中心只取 `strength × 0.42` 的轻度混合，向两侧依次衰减并在外沿到达 alpha `0`；国家 A 一侧叠入国家 B 色，国家 B 一侧叠入国家 A 色。该 mesh 进入正式 line layer，随显示意图准备、安装和绘制，首次载入与运行时样式修改走同一路径。

- 浏览器夹具连续两次失败或同一资源 owner / 像素阻断再次出现时冻结，不重复全量运行。
