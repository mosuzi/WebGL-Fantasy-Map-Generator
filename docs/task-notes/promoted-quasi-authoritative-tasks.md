## 转正边界

- 转正的是当时“建议进入准权威池”的 11 项，不包含“保留但暂不建议转正”的候选。
- 高度图 3D / OBJ、子地图变换、真实 CRS、新导出格式、富文本备注、主题纹理 / 任意字体、经济商品 / 单笔交易编辑、局部有效区 mask、单位进一步覆盖和无稳定超阈值证据的性能专项仍未转正。
- pack 重建、温度量尺、PNG 裁剪、政体面板、市场归属 / 经济重算、路线 / 河流 / 湖泊 / 地区创建、完整地图迁移等已完成事项不得因历史措辞再次入队。
- 动态军事、贸易流地图和纹章深化继续遵守用户既有取消、退役或移除决定。

## 执行规则

- 第 71～81 项排在既有第 64～70 项之后，不因原建议优先级改写当前封闭队列。
- 第 73～78 项的产品规则门禁属于任务范围的一部分；到达该项时先记录决定，若用户尚未批准且不同选择会显著改变结果，按 Goal mode 停止并询问。
- 每项达到 `docs/current-plan.md` 的最小验收后立即转入下一项，不把专题文档中的远期增强顺带实现。
