### 第 382 项：城市管理选中城市属性图标快捷操作

- 用户需求：选中城市时，以 icon 按钮群快捷设置首都、贸易中心、要塞、城墙、港口等现有城市属性。
- 目标：在城市管理选中详情旁增加紧凑图标按钮组，当前属性点亮，具备中文悬停说明、可访问名称与按下状态；切换城市和撤销 / 重做后状态同步。
- 范围：主线程唯一写者；修改城市面板、回调接线、必要局部样式与城市属性命令，复用既有编辑历史、首都事务和港口条件检查；设施补充窄字段事务，保持 city / burg 镜像、保存与撤销兼容。不新增数据字段或重生成行为，不修改 `source/`。

- 最小验收：构建 / 目标静态审计、既有城市编辑专项、真实浏览器逐属性切换及撤销 / 重做、首都转移与无效港口拒绝、窄面板无横向溢出、目标错误为零。旧数据沿用既有字段和读取兼容路径。
