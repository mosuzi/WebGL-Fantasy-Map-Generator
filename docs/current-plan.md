## 权威任务清单

### 第 402 项：非画布界面设计与内容改造（进行中，当前冻结）

**目标与方向。** 按已全局安装的 Impeccable `Operate` 模式，把正式应用所有非画布界面整理成可扫描、可理解、可操作的统一体系。保留第 398 项确立的暖米色纸面、墨色文字和青色强调，以及第 400～401 项的排版、列表身份、选择、锁与定位契约；改造信息层级、文案、状态反馈、响应式布局、键盘与辅助功能体验。用户已要求排查全部非画布样式和内容，不能只交付样板页或部分面板。

**封闭范围。** 正式应用的七个控制页（简介、生成、视图、样式、图层、管理、单位）；管理页全部 24 个入口：

- 地形环境：高度编辑、气候统计、生物群系、水体与地貌、河流、洋流、湖泊。
- 政治社会：国家、政体、省份、城市、人口、文化、宗教、外交。
- 网络经济：经济、军事、路线。
- 标注对象：地区、资源与通用标记、标签、备注、测量。
- 系统工具：名称库。

同时覆盖控制面板以外的对象详情、云端存储、纹章统计、开发模式面板、地图工具栏、全图搜索、保存与恢复点、导入与导出、PNG 预设、城市更新引导、孤儿备注救援、交易路径诊断、启动与加载页，以及地图上的非画布 HTML / SVG 标签、纹章、编辑手柄、图例、比例尺、测量读数、提示、状态通知和快捷键说明。共享基础控件、菜单、表格、操作栏、筛选、页签、分段控件、状态横幅、空态与错误态均在范围内。实施前以当前源码补齐逐入口 / 逐状态清单；属于上述正式应用非画布表面的漏项纳入本项，跨出该边界时先请用户裁定。不以已有 28 面板排版矩阵替代完整内容检查。

**明确改造结果。**

1. 把现有纸面主题提炼为语义色、字级、间距、边框、焦点、状态与地图浮层反色规则；收敛分散的局部硬编码和重复样式。先以真实计算样式核对，再改共享控件，不做无证据的整表重写或替换组件库。
2. 七个控制页与 24 个管理面板按“任务 / 对象 → 当前状态 → 输入或预览 → 操作 → 结果”建立一致层级。高度、经济、军事等密集面板做渐进展开；管理入口、十二种视图、长图层列表保持全部能力且更易扫描。列表、详情、预览和操作栏的位置与状态语义统一。
3. 逐条核对普通界面的标题、字段、占位词、帮助、菜单、按钮、反馈、错误、空态和导入导出说明。`Cloud Provider Config`、`OAuth client identifier`、`fixture`、`mock`、`颜色 token`、普通模式的 `id` 和直接拼接的 `seed` 等技术措辞改为准确的用户用语；技术标识只留在开发模式或诊断。对未配置云端能力如实说明，不虚构已接通的服务。
4. 全图搜索在空查询、大结果集、无匹配、分页与选中对象并存时给出清晰入口和状态；保存 / 恢复、导入 / 导出、重算和危险操作紧邻动作说明影响范围、预览、结果与撤销途径。保留原有业务语义、数据及历史行为。
5. 统一实际可点击区域、键盘焦点、辅助功能名称、颜色与状态辨识；在桌面、窄视口和浏览器放大下处理遮挡、横溢、内容折行及地图浮层对比。启动动画尊重减少动态效果设置。检测器报告须人工核对真实状态，不把有意的卷轴裁切或未打开页签的隐藏内容直接记为缺陷。

**非目标与边界。** 不改 WebGL / canvas 绘制、地图算法、业务能力、对象数据、保存格式、公开 API、地图 PNG 像素或 `source/` 参考项目；不新增地图玩法，不删除现有入口。仅因非画布 HTML / SVG 交互和可读性所需的样式、结构与文案变更属于本项。若发现必须修改数据字段、保存格式、产品语义或视觉身份才能继续，冻结该点请用户裁定，不以“顺手优化”扩大范围。原有中国用户文案、全局与当前地图设置的作用域、锁与撤销语义必须保持准确。
