- **权威任务第 284 项：优化 100k 地图文字交互的合成性能。** `已登记，暂缓；来源：用户要求列入但不立即实施`
  - 现状证据：`99846 grid / 54634 pack / continents / full layers / 1280×820` 下，当前版本四个独立系统 Chrome 进程的缩放 / 平移 frame P95 中位为约 `97.1 / 76.5ms`，直接父提交三轮中位约为 `41.3 / 53.1ms`。交互期完整 overlay 仍为 `0`，最终 commit、dirty 清理、checksum / revision / camera / layers 恢复和错误面均正常；当前不是逐帧 DOM 重排回归，而是约 `2521` 个标签、Marker 与军事内容节点参与反向缩放及统一 `will-change: transform` 后的样式 / 合成压力。
  - 已知独立问题：`12` 个同帧输入稳定产生 `3 draw / 1 viewport preview`，在第 282 项直接父提交同样复现，不归因于文字修复；平移 `draw` 相对 `viewport preview` 多 `0～4` 次，两版本范围重叠但当前偏高，需在正式实现前用事件序号和 Chrome trace 继续拆分。
  - 预定范围：保留第 282 项无错位、固定屏幕字号、政治候选稳定和手势结束单次提交语义；优先限制反向缩放与 `will-change` 到实际可见 / 预热节点，修复同步输入 rAF 合并，避免恢复逐帧扫描全部 DOM或把中文文字迁入 WebGL。
  - 最小验收：固定同一 100k 地图和完整图层，至少五个平衡交错的独立系统 Chrome 进程；交互期完整 overlay 为 `0`，同步输入每 rAF 至多一次 preview / draw，平移 draw 不超过有效 preview，缩放 / 平移 frame P95 相对本项当前基线显著下降。10k 文字稳定性、100k 最终 commit、PNG、标签命中与四类错误通过，地图数据、schema、存档、API、生成和 `source/` 不变。
  - 暂缓边界：本轮只登记权威任务，不修改实现、测试阈值或性能报告；后续须由用户明确要求开始后再实施。

- **权威任务第 298 项：建立现有地图网格拓扑细分与内部结构受控 API。** `已登记；来源：用户直接要求；暂缓实施`
  - **目标**：在不调用整图重生成的前提下，让当前已有地图能够从约 `10k` Grid Cells 细分到约 `100k`，尽量保持原有海陆边界、地形走向、高度场连续性、邻接连通关系及河流 / 城市等对象的空间语义；以该能力作为“现有 10k 地图拓扑保持式扩展到 100k”的基准用例。
  - **范围**：新增受控的内部网格 API，覆盖 `grid.points`、`grid.cells.i / c / v / p / h`（简称 `c/v/h` 等拓扑与基础高度字段）的只读快照、结构摘要、版本 / 引用绑定、写入预检、事务式写入、撤销 / 重做和失败回滚；允许受控构造母 cell → 子 cell 映射，并在细分后重建 pack、feature、气候、河流、路线、城市拾取等派生结构。读写必须通过 schema、范围、长度、索引、邻接对称性、边界闭合和地图版本校验，不得暴露可绕过领域规则的裸引用。
  - **拓扑细分要求**：细分算法必须以当前地图的既有 `points / c / v / h` 和海陆边界为输入；新 cell 只能在母 cell 及其原邻接闭包内建立关系；高度采用母 cell / 邻接约束插值并保留海平面与边界符号；输出需保留母子映射，使国家、城市、河流、道路及选择 / 拾取能够迁移或明确拒绝迁移。现有 `generate.newMap({cellsTarget: ...})` 不得伪装为本任务实现。
  - **最小验收**：固定旧地图夹具由约 `10k` 扩展到约 `100k`；海陆连通分量、海岸 / 湖岸边界、主要地形高度分位数、山脊 / 河网骨架和母 cell 邻接连通性满足冻结阈值；`c / v / h` 的读写 schema、版本绑定、非法拓扑拒绝、事务回滚、撤销 / 重做、旧存档兼容和 API 能力发现全部通过；真实 5410 Chrome 页面能够在用户现有地图上执行一次受控细分并恢复稳定渲染。性能、内存和大地图派生重建需单列门禁。
  - **排除**：本登记阶段不改代码、不开放裸内部对象、不新增远程写入、不改变现有 `generate.newMap` 语义；不在没有独立拓扑夹具、算法审查和回滚证明前直接改写用户当前地图。
  - **实施顺序**：先冻结结构快照与拓扑不变量，再设计只读投影和写入 schema；随后实现细分事务与派生重建，最后进行独立算法审查、旧数据 / 5410 浏览器验收和性能门禁。用户未另行授权前保持暂缓。
