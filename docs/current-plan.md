- **权威任务第 284 项：优化 100k 地图文字交互的合成性能。** `已登记，暂缓；来源：用户要求列入但不立即实施`
  - 现状证据：`99846 grid / 54634 pack / continents / full layers / 1280×820` 下，当前版本四个独立系统 Chrome 进程的缩放 / 平移 frame P95 中位为约 `97.1 / 76.5ms`，直接父提交三轮中位约为 `41.3 / 53.1ms`。交互期完整 overlay 仍为 `0`，最终 commit、dirty 清理、checksum / revision / camera / layers 恢复和错误面均正常；当前不是逐帧 DOM 重排回归，而是约 `2521` 个标签、Marker 与军事内容节点参与反向缩放及统一 `will-change: transform` 后的样式 / 合成压力。
  - 已知独立问题：`12` 个同帧输入稳定产生 `3 draw / 1 viewport preview`，在第 282 项直接父提交同样复现，不归因于文字修复；平移 `draw` 相对 `viewport preview` 多 `0～4` 次，两版本范围重叠但当前偏高，需在正式实现前用事件序号和 Chrome trace 继续拆分。
