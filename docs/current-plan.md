## 权威任务清单

- **权威任务第 322 项：复杂计算 Worker 化。** `待执行；来源：用户要求梳理复杂计算清单并逐步迁出主线程，避免阻塞交互`
   - **P0 重生成事务**：`generate.regenerate` 实际公开的地理要素、路线、河流、城镇、国家、省份、标记、外交、宗教、军事与地区十一类重算，以及这些领域连带的人口 / 经济下游；高度基础 / 下游 / 全量派生重建、气候下游重算和洋流世界重算。现有整图生成 Worker 还需继续拆出结果复制、正式地图装载和派生渲染准备，避免“Worker 已算完但主线程安装结果”仍形成长任务。
   - **P1 核心算法**：网格细分与 Delaunay / Voronoi、pack 重建、Feature / 岸线拓扑、河流洼地消解与流量累计、路线寻路、文化 / 宗教 / 国家 / 省份扩张、人口重布、城镇选址、经济交易、军事和地区生成。
   - **P2 大数据与 CPU 渲染准备**：大型存档 JSON 解析、迁移、校验、序列化与压缩；surface / shore / political / route / river mesh、标签布局和 picking index 的 CPU 构建。WebGL buffer 上传与最终 draw 保留主线程。
   - **架构边界**：主线程只负责确认、map revision / generation token 校验、锁保护、事务提交、历史、DOM / 面板和 GPU 提交。Worker 输入必须是可复制或明确 transfer 的不可变快照，不得转移仍由正式地图持有的 typed arrays；旧浏览器 / Worker 初始化失败需安全降级。
   - **最小验收**：同 seed 与同 salt 的 Worker / 主线程降级结果语义一致；取消、换图、迟到结果、故障注入和锁冲突均不产生半写入；100k 代表流程的交互窗口主线程长任务归零或达到分阶段预算，Loading 阶段、进度、回滚、旧存档与 API 兼容通过。

- **权威任务第 323 项：地图规模统一限制为 1～100k。** `待执行；来源：用户要求地图规模最大支持 100k，越界数字自动降级且不得小于 1`
   - **统一口径**：建立唯一的地图规模归一化规则，所有用于创建或扩大地图的目标值均为整数 `1～100000`；有限数值大于 `100000` 时自动使用 `100000`，小于 `1` 时自动使用 `1`，两个边界值保持不变。非数值输入继续走明确的默认值或输入错误，不得静默变成意外规模。
   - **覆盖入口**：生成 Tab、整图生成选项、公开 API / schema / 配方、URL 或预设恢复，以及 `grid.refine` 的 `targetCells` 必须复用同一规则；当前 UI 的最小值 `1000` 和网格细分的最大值 `200000` 一并收敛。归一化后的值必须回显到控件、地图 options / metadata、预检结果和操作日志，禁止界面值、API 值与实际计算值分叉。
   - **一格与细分边界**：`cellsTarget=1` 必须能够完成生成并至少绘制一个有限、可见的地图单元；依赖多样本的人文或网络阶段在样本不足时应确定性降级为空结果或最小合法结果，不得崩溃。细分仍只允许增长，但请求超过 `100000` 时先按 `100000` 执行；地图已经达到上限时返回明确 no-op，不再分配超过上限的网格。
   - **存档安全**：不允许通过静默删除 cells 把既有超限存档伪装成 100k；实际网格超过 `100000` 的导入应在替换当前地图前明确拒绝并保留原图，`≤100000` 的旧存档保持兼容。不得修改 `source/`。
   - **最小验收**：固定覆盖 `-1 / 0 / 1 / 99999 / 100000 / 100001 / 200000`，确认 UI、生成器、API、schema 与细分预检归一化一致；1-cell 地图完成真实浏览器生成、稳定显示、PNG、保存与恢复；100k 生成 / 细分继续通过，超限存档拒绝与回滚无数据丢失，application / page / active health / WebGL error 为 `0`。

- **权威任务第 324 项：内置真实地理与历史场景地图模板系统。** `待执行；来源：用户要求内置常见世界地图场景，并按用户选择的 cell 数一键创建`
   - **产品入口与概念边界**：生成 Tab 新增“地图模板”选择与一键创建入口，先选模板、再选第 323 项统一约束下的目标 `cellsTarget`。新系统是带真实地理范围、版本和映射规则的场景模板，不得与现有“大陆 / 群岛 / 地中海”等程序化高度模板混为一谈；公开 API 提供等价的模板枚举、详情和创建能力，AI 能发现每个模板的范围、版本、推荐规模及历史年代。
   - **首批固定模板**：
      1. 世界地图。
      2. 中国地图：完整包括藏南、阿克赛钦、台湾、南海诸岛和钓鱼岛，不得因画布裁剪、投影、岛屿面积阈值、几何简化或 cell 重采样丢失。
      3. 欧洲地图。
      4. 北美地图。
      5. 南美地图。
      6. 非洲地图。
      7. 亚洲地图。
      8. 东亚地图：西边界从七河平原所在经度开始，东边界到北海道所在经度结束，北边界从贝加尔湖所在纬度开始，南边界到越南河内所在纬度结束。
      9. 澳洲及巴布亚新几内亚岛、新西兰岛地图，三部分都必须完整进入画布。
      10. 南极洲地图。
      11. 中原地图：北到内蒙古中部，南到浙江与福建交界，西到兰州，东到东海。
      12. 日本本州岛地图。
      13. 朝鲜半岛地图。
      14. 中东地图。
      15. 神圣罗马帝国地图。
      16. 地中海地图：以复刻罗马帝国场景为主要目标。
   - **模板契约与来源**：每个内置模板使用稳定 `id / version` 和可审计 manifest，至少记录中文名、类别、地理范围、投影 / 裁剪规则、推荐 cell 数、canonical 海陆 / 高程 / 水文 / 区域掩膜、必须保留的岛屿与锚点、数据来源、再发布许可、内容摘要和历史快照年代。所有正式资源随应用版本化并按需加载，不依赖创建时访问第三方网络。神圣罗马帝国与罗马帝国场景必须先固定单一明确年代和史料口径，并内置对应年代的政治 / 人文场景预设，不得把不同年代边界拼成无日期模板；普通地理模板默认只复刻地理底图，人文世界继续由生成器派生。
   - **模板到 cell 的确定性映射**：模板 canonical 几何投影到按目标 `cellsTarget` 建立的新网格，派生海陆、高度、Feature、湖泊、河流、区域掩膜及后续人文数据；不得把模板原始 cell 数直接复制给所有规模。相同模板版本、cell 数、seed 和 salt 必须得到相同语义 checksum。映射需保持海岸与湖岸拓扑、陆岛归属、河口和跨日界线连续性，并用受保护锚点避免关键小岛在常用规模下消失；极低 cell 数允许明确标注的示意化降级，但创建不得崩溃或伪称完整精度。
   - **普通地图与兼容性**：模板创建完成后得到可编辑、可重生成、可保存、可导出和可撤销替换的普通地图；metadata 只保留模板 `id / version / source checksum / requestedCells / actualCells` 等来源证据，不建立会覆盖用户后续编辑的持续绑定。旧存档和未选择地图模板的生成链保持原行为，既有 `heightmapTemplate` 字段继续兼容；不得修改 `source/`。
   - **最小验收**：16 个模板在 UI 与 API 中顺序、名称和 manifest 一致，并各自完成默认规模的真实生成、结构审计和固定视口截图；纯数据门禁对全部模板覆盖 `1 / 10000 / 100000` 目标值及第 323 项上下限钳制，浏览器再覆盖世界、中国、东亚、澳洲组合、神圣罗马帝国和罗马帝国场景的 10k / 100k。中国五类指定区域、东亚四边界、澳洲三部分和两类历史年代均有机器断言与人工截图证据；存档往返、PNG / GeoJSON、picking、回滚、旧图兼容、延迟资源加载及 application / page / active health / WebGL error 通过。
