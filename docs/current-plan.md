- **阶段结果**：28 面板共用语义浅色主题、字段 / 弹层状态与尺寸间距；导入聚合、动作分组、危险文字保持、定位图标化和重复历史入口收敛。旧新动作对应见 [实施清单](./task-notes/task-396-panel-refinement.md)；静态构建通过，真实视觉与操作待批末验收。
- **范围**：盘点全部正式编辑 / 管理面板、共用表格与字段、工具条、二级操作浮层及相关选择 / 确认弹层。控制面板和对象详情纳入相关入口与通用外观；云存储仅检查共享壳与弹层一致性。冻结清单、逐面板记录保留 / 合并 / 图标化 / 布局修正及理由。具体入口与阶段见 [追加需求说明](./task-notes/map-search-and-panel-refinement-2026-09-19.md)。
- **动作精简**：定位、锁定、显隐等易识别动作优先图标化，具备中文提示、可访问名称和选中 / 禁用 / 忙碌反馈；有歧义或破坏性的动作保留必要文字及原确认。按同一对象与作用范围组织按钮组，互斥模式与独立动作区别呈现；重复入口可收敛，不同对象 / 不同写集不因名称相似而合并。保留每项能力的可达路径，不把全部高频操作藏入多层菜单。
- **尺寸与间距**：统一控件高度、图标命中区、行内与组间间距；长中文、输入值、单位、错误、空态和忙碌文案均能容纳或完整查看。分组内紧凑、组间清楚，允许合理换行 / 滚动；不得靠压缩字号、裁剪控件、固定窄宽或撑出视口取得整齐。
- **明亮主题**：默认浅色面板和字段、深色文字、明确边框 / 层次；同步表格、选中、悬停、焦点、禁用、警告和错误。统一主题变量并清理相关硬编码暗底，覆盖挂到面板外的菜单、下拉、颜色选择和对话框。界面明亮主题独立于地图配色、背景及导出，不修改地图视觉事实。
- **最小验收**：逐面板动作映射无意外丢失，原回调、作用范围、锁、单历史、取消、失败及撤销重做保持；桌面、690px 窄视口及 200% 浏览器缩放下检查长中文和各状态，不遮挡关键动作，不意外横溢。真实浏览器验证所有面板外观与代表性编辑链、弹层主题、键盘焦点及地图手势隔离；小图 / 100k、交互审计和性能门通过，地图主题与导出不变。
- **非目标与首门**：不换组件库、不重写编辑业务、不新增世界模拟、不做地图主题或暗亮双主题切换器。主线程唯一写者；先建立面板 / 动作清单，再以共用控件与城市 / 道路代表面板验证规范，随后分组推广及最终全清单验收；首个廉价门为动作、可访问名称与样式作用域静态核对。
