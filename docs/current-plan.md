## 权威任务清单

### 第 375 项：桌面鼠标 / 触摸板地图导航实验（独立分支待用户试用）

- 用户目标：改善没有鼠标的 macOS 触摸板用户在地图上的平移与缩放体验，同时保留 Windows / Linux / macOS 的常规鼠标操作；在不面向手机布局的前提下，为大屏触屏设备提供中性浏览态的基础单指 / 双指导航。
- 分支与交付：从 `main / 5f893b9 / v0.5.86` 创建 `codex/task-375-desktop-input-navigation`。本项完成后只提交并保留独立分支供用户试用；未经用户再次明确授权，不合入 `main`。
- 冻结交互：保留中键 / 右键拖动与鼠标滚轮定位缩放；中性地图主键点击仍选择对象，越过移动阈值后改为平移，空格 + 主键立即平移。wheel 始终走无需设置的自动分类：`ctrlKey` 捏合定位缩放，行 / 页单位和典型大步长滚轮缩放，像素单位的横向、细小或小数增量平移；短 burst 锁定意图，避免触摸板惯性阶段突变。
- 触屏边界：中性浏览态允许单指点击 / 阈值平移、双指质心平移 + 距离缩放，并处理 `pointercancel / lostpointercapture`；本项不承诺三十类编辑工具的单指编辑 / 双指导航仲裁，不实现手机响应式布局、三指 / 四指或屏幕边缘系统手势。
- 配置边界：不提供控制面板开关，不保存或恢复输入模式，也不进入用户主题、地图文档、导入导出、公开地图 API 或撤销 / 重做历史；旧本地字段在偏好归一化时移除。`touch-action` 只约束地图 canvas，不影响控制面板和页面滚动。
- 最小验收：专项固定自动鼠标 / 触摸板分类、触屏多指、阈值选择 / 平移、光标锚定缩放与取消清理；既有 canvas tool / pointercancel 门不退化。真实浏览器验证控制项不存在、小幅纵向滚动平移、典型滚轮步长缩放、选择与平移互斥，目标窗口 warning / error 为 `0`，无地图历史新增。
- 非目标：不修改 `source/`、地图 schema、主题、生成器、renderer 颜色 / 几何、手机 UI、编辑工具语义或系统级手势；不通过操作系统 / User-Agent 猜输入设备。
- 执行：主线程唯一写者，使用 `run-lean-staged-delivery`；阶段依次为 `375-A 自动输入分类 → 375-B 统一导航控制器 → 375-C 运行时与 canvas 边界 → 375-D 专项和真实浏览器验收`。每阶段首个廉价门分别为分类纯函数专项、控制器状态机专项、静态接线审计和目标浏览器交互。
- 当前结果：统一控制器专项通过鼠标中 / 右键、主键选择 / 阈值平移、空格主键、自动 wheel / pinch、触屏单指 / 双指和取消清理；输入模式控件、renderer setter 与持久化字段已移除。真实页面小幅纵向 `12px` wheel 只使标签平移 `-12px`、尺寸不变，相隔新 burst 后 `100px` 典型滚轮步长使两标签间距按 `0.90494` 缩放；控制面板无输入配置，目标日志 warning / error 为 `0`。实验版本 `0.5.88`，等待用户在真实触摸板上试用后裁定是否继续调整；不得合入 `main`。
