## 权威任务清单

### 第304项：河流网络算法实验室与生成质量修复

- **状态**：调查完成，304-A、304-B、304-C 已完成，当前进入 304-D；本项必须先在独立实验室中比较算法，证据通过后才可另行批准正式生成器接入。当前不修改 `rivers.js`、河网正式输出、地图数据或用户当前 Chrome 标签页。
- **目标**：定位并修复离散细线、支流未接入干流、支流宽度 / 流量超过接收干流、无效循环和非汇流交叉；保留合法河网分叉、湖泊进出水和河口边界语义。
- **封闭子任务**：304-A 实验室壳体与固定夹具 / 只读审计；304-B 流向 DAG、父子关系与循环候选算法；304-C 汇流锚点与路径连续性候选算法；304-D 流量 / 宽度单调性与碎线视觉策略；304-E 固定种子、真实浏览器视觉对照和正式接入决策门。
- **304-A 最小验收**：固定夹具能分别复现孤立碎线、未接入汇流、支流越级、无效循环、合法汇流、非汇流交叉、湖泊溢流和边界河口；10k / 50k / 100k 固定种子输出确定性诊断，给出河流 ID、cell / 坐标、指标和证据等级；实验室不写入地图、存档、历史或 API，正式应用构建与 `source/` 零改动。
- **304-A 结果**：`prototype/river-network-lab/` 与 `tools/river-network-lab-regression.mjs` 已完成；8 类固定夹具全部命中预期 issue ID，10k / 50k / 100k 的河网快照、诊断列表和 `networkChecksum` 重跑稳定，原始快照不变。正式地图摘要 checksum 在两次生成中仅作上下文记录且出现变化，不作为本子任务的确定性门禁，留给 304-E 继续核查；本阶段没有正式生成器、地图、存档、历史、API、用户 Chrome 或 `source/` 写入。
- **304-B 结果**：实验室新增确定性父子图分析和 DAG 候选；缺失父级、自指和关系环会拒绝候选，合法汇流可得到稳定拓扑序，非汇流交叉不会被误判为父关系错误。固定夹具与 10k / 50k / 100k 重跑的 visited、cycles、missing、self 指标稳定；候选只复制内存快照，不重写 `points`、`cells` 或正式河网。
- **304-C 结果**：实验室新增汇流锚点分析和候选；合法父子末端在固定容差内才允许复制并贴到父河最近折线点，超容差的未贴合支流拒绝候选；无父关系的非汇流交叉继续由几何审计标识，湖泊 / 入海 / 边界出口不参与整体吸附。固定夹具与三档 seed 的关系数、未贴合数、保护出口数和最大距离重跑稳定，原始快照不变。
- **兼容边界**：在正式接入决策前保持 `river.cells`、`points`、`parent`、`basin`、`source`、`mouth`、`flux`、`discharge` 等既有字段和旧存档语义；不把实验室候选结果直接覆盖正式生成结果。
- **明确排除**：不通过删除所有交叉来伪造河网、不把所有环都判成错误、不用单纯加粗掩盖断线、不在用户当前地图上重新生成或刷新验证。
- **专题方案**：详见 [`task-304-river-network-lab.md`](./task-notes/task-304-river-network-lab.md)。
