## 任务条目

- **权威任务第 352 项：启封舆图性能与边界柔化样式。** `已完成；来源：用户要求优化启封舆图，并在查明初载国界蒙眬成因后把该观感作为可控样式并入同项`
  - **根因与性能修复**：用户提供的 `krichars (3).webfmg` 是 gzip v3、`9,642,587B`、解压后 `15,428,683B` 的 24 段存档。旧入口在 Worker 完成解压、v3 解码和迁移后，又把完整地图重新编码成 v3 接纳 handoff，主线程随后再次解码；现对原始 v3 / gzip v3 直接复用已解压的 canonical 分段字节，主线程仍重新执行同一迁移与投影，JSON、旧格式及非 v3 输入保持旧 fallback。三轮同浏览器新上下文的正式 UI 导入中位数由 `19,795.5ms` 降至 `17,509.1ms`，改善 `11.55%`；重复 handoff 编码由 `2,064.6ms` 降至 `0.2ms`，下降超过 `99.99%`，Worker 总耗时由 `12,124.7ms` 降至 `9,879.3ms`。
  - **边界成因与样式实现**：首个正式帧和稳定帧使用同一政治边界线 mesh，线签名均为 `88812:e13fea6a`，中心像素哈希均为 `256x256:d8fe8143`，不是另画的栅格快照。蒙眬观感来自国界 `0.36` 世界宽度 / `0.34` alpha 与省界 `0.24` / `0.22` 的亚像素半透明线在标准 alpha 混合下呈现。样式页新增 `0～100` 的“疆界柔化”：`0` 加宽并提高不透明度，`50` 精确保留旧视觉，`100` 收窄并降低不透明度；它只重建国界 / 省界线层，不刷新 surface，也不使用会波及文字、图标或整图的画布滤镜。
  - **持久化与兼容**：旧图和缺字段输入默认 `50`；正式导出把柔化值写入既有 `map.metadata.display`，导入时恢复到 `map.display`、renderer 与控制偏好。v3 仍为 24 个既有 section，未增加未知顶层 section；压缩保存后回读 `100` 档，地图 checksum 仍为 `28eede3c`，对象数量、历史初态与 WebGL 状态不变。
  - **验收与边界**：边界公式、地图迁移、v3 容器、文件 IO Worker、正式构建与用户样本真实浏览器三轮性能 / 首稳帧 / 三档视觉 / 压缩回读全部通过；三档 line mesh 签名互异，默认 `50` 与基线逐像素一致，当前最大 LongTask `143ms < 200ms`。未修改 `source/`、地图生成 / 编辑、存档容器契约、公开 API、显示快切或第 349～351 项。详细证据见 [`task-notes/task-352-map-unseal-performance.md`](../task-notes/task-352-map-unseal-performance.md)，版本升至 `0.5.5`。

- **权威任务第 353 项：正式保存性能与路线锁定优先重生成。** `已完成；来源：用户反馈正式保存仍慢，且路线重生成错误地以“锁定内容冲突”整批拒绝`
  - **目标与锁定语义**：以用户提供的 `krichars (3).webfmg` 为只读代表存档，复现正式“重新生成路线”的实际拒绝并追到具体锁对象、依赖和校验阶段。锁定对象优先级高于主动路线重生成：锁定路线及其必要端点、路径和派生镜像必须作为不可覆盖约束预先种入，新路线只使用剩余空间；旧派生关系失效时在事务内修复，不得用笼统 `regeneration_lock_conflict` 要求用户解除合法锁。多个锁之间需要竞争同一资源时采用稳定、可解释且不丢锁对象的保留策略；只有输入本身已损坏到无法表达锁对象时才允许安全拒绝，并必须返回精确对象、字段和原因。
  - **保存性能目标**：测量正式压缩保存从地图归一化、Worker 输入、v3 编码、gzip、结果回传到下载就绪的分段墙钟，消除已证重复序列化、复制或无效重算。优化后同一构建、浏览器和存档的正式保存端到端中位数必须明确改善，已证主瓶颈至少下降 `20%`，不得用降低压缩级别、跳过校验、丢字段或改成非正式入口换取成绩。
  - **最小验收**：用户存档的路线重生成在存在合法锁定路线 / 锁定城镇及旧派生关系时成功提交，锁定对象核心身份、端点和路径保持，未锁路线从空结果重建；重复边、交叉依赖和失效港口 / 城镇镜像均有确定性处理，失败与撤销保持事务原子。保存前后内存地图、checksum、对象数量、TypedArray、稠密身份槽和历史不变；新压缩文件经正式 UI 回读恢复同一地图和柔化样式，旧 JSON / gzip / v3 兼容回归通过。专项 Node、正式构建和真实浏览器路线重生成 / 保存性能各跑一次代表性终验，新增 LongTask 不得超过 `200ms`。
  - **非目标与阶段**：不修改 `source/`，不改变地图生成、非路线领域重生成、锁管理 UI、v3 section / schema 契约、显示快切、公开 API 或第 349～352 项既有语义。阶段顺序为 `真实拒绝与保存基线冻结 → 锁定优先路线契约及专项 → 保存主瓶颈优化 → 用户存档统一浏览器终验 → 归档交付`。若必须改变锁对象核心身份、允许丢锁、改变 v3 容器契约、夹具连续两次失败或同一阻断再次出现，则冻结并请求裁定。

- **权威任务第 354 项：全部重新生成入口落实锁定最高优先级。** `已完成；来源：用户要求道路之外的一切重新生成都必须强制执行，不能被合法锁定内容阻塞`
  - **统一契约**：十一类正式重生成和高度、气候下游、洋流世界、海底等复合重建统一把可读取的显式锁及其必要支撑闭包作为不可覆盖约束。锁定国家可带入省份、城镇、外交与军事；锁定 Feature 可带入相关城镇、路线和标记；经济端点、首都 / 省会、Warzone 外交对、河流关联 Feature 等依赖均在生成前闭包。目标领域全部锁定时返回成功 no-op；只有对象缺失、越界、镜像损坏或结构本身不可解析时才精确拒绝。

  - **边界**：未修改 `source/`、存档 schema、数量算法、美术样式、普通编辑 / 删除锁规则或 `main`；任务分支独立推送，等待用户后续决定是否合入。
