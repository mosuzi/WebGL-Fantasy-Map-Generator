## 任务条目

- **权威任务第 403 项：cell 人口柱与降雨圆点图层** `已完成（2026-11-12）；版本 0.5.124`

  - **目标与范围**：在正式“图层”页增加默认关闭的“人口柱”和“降雨量圆点”。逐陆地 cell 读取已有 `grid.cells.pop` 和 `grid.cells.prec`；人口柱以有明暗面的短 2.5D 形体表达人口，降雨量以不超出所属 cell 的圆点表达。两者可独立开关和叠加，不改变既有“人口”点层及人口、降水着色视图。
  - **边界**：不增加地图字段或修改存档格式、生成算法、人口结算、气候数值和 `source/`。旧数据缺少人口或降水字段时跳过相应形体；图层开关沿用显示偏好，不写入地图本体。第 402 项的完整界面终验与冻结状态不受影响。
  - **实现**：按 cell 多边形边缘计算安全内切半径，人口柱高度最多为该半径，圆点半径最多为安全内切半径的 `84%`；最大值按当前地图归一，并保持数值单调。数据按每批 2048 格构建；地图或相关 cell 数值更新时使缓存失效。PNG 导出等待当前图层准备完成，绘入正式 WebGL canvas。
  - **验收**：图层专项通过零值、海格、旧数据缺字段、单调与尺寸约束；`build:app`、`check:ui-layout`（709 状态、问题 0）、控制页、GPU 显示、上下文恢复、类型、PNG 选项及九项导出回归通过。正式本地预览的小图与约 100k 格地图确认独立开关、缩放和叠加；开启双图层后经“图片”入口导出 1920×1080 PNG，图像包含两种形体。图层切换和导出窗口无新增 console / WebGL 错误；页面此前生成地图时的两条旧健康警告不计入图层操作。

- **权威任务第 404 项：国家画笔响应与画布卡顿诊断** `已完成（2026-11-13）；版本 0.5.125`

  - **目标与范围**：解决国家画笔在 100k 格地图点按、连续涂抹和提交时卡数秒；在开发模式显示画布采样、输入延迟、长任务与帧停顿。保持国家、省份、城镇关联、单笔历史、撤销和旧图语义，不变更地图格式与参考项目。
  - **首败与实现**：正式浏览器首测单笔提交 `1177ms`，主要为政治边界缓存 `233ms`、线层 `711ms`；后续定位完整标签重建约 `214ms`、对象拾取约 `200ms`。预览改为空间索引查询与局部 GPU cell 属性更新；政治边界路径和描边交给独立 Worker，分片初始化，完成后只替换政治线段；国家笔画只更新受影响的政治标签，撤销走相同局部路径。画布监测用浏览器 `PerformanceObserver` 的 long task、Long Animation Frame、Event Timing 缓冲条目及帧间隔采样，主线程恢复后补记；开发浮层保留有界的最近记录。浏览器已提供所需 API，无需本地扩展。
  - **验收**：10k / 100k 正式本地 Chrome 每笔含连续移动，提交 `37.7 / 90.1ms`，预览最大 `17.4 / 16.7ms`，Worker 预热最大 `2.8 / 3.2ms`，边界安装 `3.4 / 5.3ms`，撤销墙钟 `41.2 / 71.9ms`；目标画布交互卡顿样本 `0`、WebGL 错误 `0`，调试专栏可见。国家生命周期、拓扑与 UI API、画布监测专项、核心类型检查、应用构建通过；`check:ui-layout` 检查 709 状态、问题 `0`。第 402 项整体冻结状态不变。
