# 2026-11-15 至 2026-11-21 开发记录

## 2026-11-15：修复国家画笔后的异色三角

用户截图中的黄色细三角并非未转移的国家 cell，而是平滑表面用邻居色填充曲边的 GPU correction；画笔和拾取仍按原始 Voronoi cell，故细片可能越过边界且无法通过点击所在 cell 去除。国家、省份、政体和外交归属视图停止绘制此修正片，地形等连续视图保持。双 cell 几何夹具和正式 WebGL 绘制计数确认越界来源及修复，10k / 100k 真实画布拖涂、撤销、旧图数据、国家建删与保存回读、渲染准备和类型检查通过。100k 提交 110.2ms、预览峰值 29.8ms、撤销 76.1ms，目标卡顿及 WebGL 错误为 0；涂抹交界放大截图无孤立异色三角。截图夹具先后因全图拾取和落点邻居已同时涂抹而失败，分析后定位实际涂抹区域外缘并复验通过。版本 `0.5.131`；第 402 项仍冻结。

## 2026-11-15：人口柱调整为圆柱投影

人口柱旧棱柱的完整轮廓最高 `1.36r`、主体宽 `0.68r`；新圆柱投影以椭圆顶面、弧面明暗及圆弧底实现最高 `2.72r`、宽 `0.34r`。独立复核发现首次方案的阴影过宽、顶端抗锯齿裁切和完整轮廓高度不足两倍，逐项修正。10k / 100k 正式页面两档缩放均显示人口柱，PNG 导出通过，降雨圆点开关往返像素相同，WebGL / 页面 / health 错误为 0。10k 首次准备阶段出现一次 `81ms` LongTask；分析后减少半径计算及实例写入开销，目标复验 `65ms`，最终 10k / 100k 峰值 `105 / 120ms`，均未超过 200ms。版本 `0.5.132`；第 402 项仍冻结。
