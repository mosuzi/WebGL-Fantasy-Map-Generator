# 地图数据模型、尺度与派生关系

## 两层 Cell

- Grid cells 是基础生成网格，承载基础高度 `grid.cells.h`、温度、降水及 Grid Voronoi 几何。高度灰度图也以此层为准。
- Pack cells 是陆水、政治、人口、城市、路线和多数对象分析使用的业务网格。`pack.cells.g` 映射到 Grid cell；区域分析统一返回 Pack cell id，同时附 `gridId`。
- 不可把 Grid id 和 Pack id 混用。调用 `cells.*` 时必须显式空间；无头区域分析当前固定输出 `space=pack`。

## 核心字段解释

| 主题 | 主要数据 | 解释 |
|---|---|---|
| 高度 | Grid / Pack `h` | 0～100 的模型高度；20 为海平面，不直接等同米 |
| 降水 | Grid `prec` | 生成模型原始降水单位；显示毫米需结合单位偏好 / 比例 |
| 温度 | Grid `temp` | 模型温度值，分析需同时记录纬度与气候选项 |
| 人口 | Pack `pop` + burg population | 农村与城市分开，国力比较必须显式说明是否两者都计入 |
| 宜居度 | Pack `s` / suitability | 人口承载的一个输入，不是最终人口 |
| 政治 | Pack `state / province` | 0 通常为中立；对象数组可能含中立占位或 tombstone |
| 地区 | zone cells / category / coverage / effects | 自然底区、事件覆盖区和自定义地区可有不同重叠语义 |
| 邻接 | Pack `c` | 共享边邻接，是坡度、连通块和扩张分析基础 |

## 派生关系

高度会影响陆水、坡度、水文、路线成本、宜居度和后续人口；气候会影响降水、温度、生物群系和承载；道路、城市、市场、政治归属又影响人口与国力解释。因此“只改一个数”通常不足以得到可信世界。分析阶段先定位瓶颈，写入阶段按公开规则事务重建必要派生系统。

`metadata.derivedStale.systems` 表示当前已知过期派生系统。输出建议前必须报告它，否则基于旧经济、军事或水文的比较可能失真。

加载兼容归一化可以补齐缓存或可选镜像，但不能重算并覆盖用户保存的人口、地形或疆域。人口保存时至少同时核对 `pack.cells.pop`、Grid 人口镜像和国家 / 省份 / 文化 / 宗教的农村人口聚合；索引 `0` 是未归属桶，也必须在聚合前清零，防止重复加载累加。

## 聚合口径

- 同时报告 count、min、max、mean、P10、P50、P90；崎岖地形不要只看平均高度。
- 人口同时报告 rural、urban、total、城市数和路线覆盖。
- 比较面积不同时，除总量外还需比较每 cell 指标；当前 analysis API 暴露原始总量与样本数，调用者可计算密度。
- 国力 `powerScore` 只是透明代理：总人口、城市人口加权、城市、路线、宜居度。它不是正式军事 / 经济规则裁决。
- `slope` 是当前 cell 与邻接 cell 的最大高度差，`roughness` 是邻接高度差均值；两者用于发现突变，不等同现实角度。
