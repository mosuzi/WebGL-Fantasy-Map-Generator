# Playbook：高山无人区北侧平原追平南侧同政权国力

1. 找到自动无人区 zone、高山屏障和其南北邻接平原；北 / 南区域都与目标国家区域求 intersection，排除跨境 cell。
2. `compareRegions(north,south)` 比较面积、降水、温度、宜居度、坡度、人口、城市和路线；用每 cell 人口补充总量比较。
3. `diagnosePopulation(north)` 输出候选 cell 与限制因子；`comparePower` 给出透明代理差距。另用对象查询核对市场、路线、城市、军事等正式对象，避免把代理分数当规则事实。
4. 依次判断瓶颈：自然承载 → 山口 / 路线通达 → 城市锚点 → 政治安全 / 地区影响 → 人口分布。北侧若自然条件接近但无路线和城市，应先解决网络；若自然条件显著较差，人口直灌会失真。
5. 建议目标写成“北侧 power ratio 接近 0.9～1.1、每 cell 人口与南侧同量级、至少形成可达城市锚点”，而不是要求人口数机械相等。

保持约束：高山无人区仍为无人 / 低人口屏障，政权疆域不变，南侧人口不因非守恒增量被抽空。实际写入需人口、城市、路线相关 inspector 与锁定检查；无头阶段不执行。
