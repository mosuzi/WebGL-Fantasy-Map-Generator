# Playbook：保留晴布赫斯疆域与地形时改善降水、人口

目标不是简单抬高人口，而是在保持王国疆域、西部高山和南部丘陵的约束下找到真实瓶颈。

1. `objects.query` 按名称找到国家并确认唯一 id；`analysis.defineRegion({kind:"state",id})` 固定全境。
2. 用高度阈值和相对方位从 evidence / cells 查询建立西部高山、南部丘陵、核心平原三个子区；把它们作为必须保持的集合记录。当前 region spec 尚不直接支持方位和高度过滤时，先用 `cells.query` 得到 cell ids 再传 `{cells}`。
3. 对全境与核心平原调用 `describeRegion`、`explainPrecipitation`、`diagnosePopulation`；另取西侧外缘和北 / 东邻区作降水对照。
4. 查 `climate.get()` 的风带与纬度。只有当上风侧较湿、屏障 cell 连续、下风核心较干时，才把雨影列为高置信原因；南丘陵可能阻挡水汽，但必须结合主导风向判断。
5. 比较路线、城市锚点、宜居度与城乡人口。若降水尚可而路线 / 城市缺失，优先建议交通和城市体系；若降水与宜居度同时低，才建议评估气候或地形方案。
6. 输出三档方案：只改善交通 / 城市、全局气候参数的小幅方案、保持山脊与丘陵拓扑的局部地形方案。每档列出目标统计、保持 cells、潜在派生重建和现有公开 inspector。

成功口径：疆域 cell 集合不变，西部山地与南部丘陵的相对高度关系保留；核心平原降水 P50、宜居度均值和人口承载候选增加；不得仅靠直接写人口制造与承载不一致。
