# 生成与重生成的数据关系、容错和最小硬门

本文是普通生成、正式重生成、复合重建和直接重算的长期数据契约。实现、测试和错误码不得另行扩大校验范围；确需新增硬门时，必须先修改本文并说明它防止的不可提交结果。

## 1. 核心判断

架空地图中的多数关系是生成偏好或可重建派生关系，不是数据库外键，也不是数学等式。主动重生成的职责是从仍可读取的基础地图上产出一组新的可用对象，而不是先证明旧对象和所有上游镜像都正确。

因此统一顺序固定为：

1. 在事务 working copy 中确认地图基础容器可读取，捕获目标域显式锁对象的最小原像。
2. 清空目标域的未锁旧对象及其陈旧派生索引；旧目标对象不进入候选、评分、数量、限制或最终校验。
3. 只用本域真正必需的基础输入生成空白目标结果；软输入缺失时使用空集合、局部推导或降级策略。
4. 对新生成的未锁对象执行本域基础物理与结构硬门。
5. 按稳定身份把显式锁对象原样并回；锁对象不参加本次生成限制，也不因其内部旧错误被拒绝。
6. 只重建本次目标域拥有的镜像和索引。不能安全回填的软引用置空或保持陈旧标记，不反向改写锁对象。
7. 检查锁对象本体 before-image、稳定身份唯一性、补丁写集、事务 owner / revision / history 和可回滚性后原子提交。

“全部锁定”不是错误：生成空白未锁结果后并回全部锁对象，允许成功 no-op。锁引用找不到对象时，该锁本身是陈旧元数据，应从本次约束中忽略并报告诊断，不阻塞重生成。

## 2. 关系分类

| 分类 | 含义 | 缺失或错误时的动作 | 能否阻止主动重生成 |
| --- | --- | --- | --- |
| 生成必需输入 | 本域无法在缺少它时定义几何或身份空间的基础数据 | 精确拒绝，事务回滚 | 可以 |
| 可选偏好 | 改善数量、命名、评分、连接或风格的上下文 | 空集合、默认值、局部推导或降级 | 不可以 |
| 可重建派生 | 可由目标对象和基础地图重新计算的镜像、统计、索引 | 清空后重建 | 不可以 |
| 可丢弃陈旧引用 | 指向旧目标对象或其它软对象的引用 | 置零、置空、过滤或标记待派生 | 不可以 |
| 锁定后置合并 | 用户要求保留的目标对象本体 | 生成时不可见，完成后按稳定 ID 原样覆盖 | 不可以；对象不存在时忽略陈旧锁 |
| 物理结构硬门 | 新生成对象若违反就无法表示或明显违背地图物理的条件 | 精确错误码、拒绝提交、完整回滚 | 可以 |

硬门只检查本次新生成的未锁对象。显式锁对象可能正是用户准备稍后修复的旧数据，不得因为落海、断链、陈旧父级或镜像缺失而阻止其它对象重生成。

## 3. 全图基础层

以下输入是各领域可共同依赖的基础层，但只有实际使用它的领域才能把它列为必需输入：

| 基础层 | 最小可读条件 | 说明 |
| --- | --- | --- |
| grid cells | `i / h / p / c` 容器可读，cell 身份、有限坐标和邻接可解释 | 高度、水陆、空间与邻接的根；损坏时依赖几何的生成不能继续 |
| pack cells | `i / h / p / c` 容器可读，pack 到 grid 映射在被访问位置有效 | 路线、河流、城镇、政区等正式对象的空间根 |
| 地图边界与海平面 | 有限宽高，海平面判定可用 | 城镇、陆路、河流等基础物理门的依据 |
| 随机种子与选项 | 缺失时可使用稳定默认值 | 是确定性输入，不是旧对象正确性证明 |
| namebases | 缺失、损坏或绑定丢失时使用默认名称源或稳定占位名 | 永远是可选偏好，不得阻止几何或对象生成 |

`politics / pack`、`society / pack`、`economy / pack` 等双份数据不是两个独立权威输入。目标域重建时以可读的一份作为软视图；完成后由目标域一次性重建镜像。镜像不一致本身不是重生成前置错误。

## 4. 领域关系矩阵

| 目标域 | 生成必需输入 | 可选偏好与软上游 | 清空后重建的派生 | 后置合并的锁本体 | 新生成对象硬门 |
| --- | --- | --- | --- | --- | --- |
| Feature / 岸线 | grid 高度、水陆、邻接、坐标 | 旧 Feature 身份、河湖引用、城镇/道路/标记引用 | grid/pack Feature、cell `f`、岸线、haven/harbor | 显式锁 Feature 对象；不保留其支撑闭包 | 新 Feature cell 连通且水陆侧一致；边界坐标有限 |
| 河流 | pack/grid 高度、陆地邻接、降水或稳定默认降水 | 湖泊进出口、旧河名、文化命名、旧河网 | 河流数组、cell `r/fl/conf`、河网统计与 mesh | 显式锁河流对象 | 新河流主体在陆地/湖岸水文路径上，连续邻接、坐标有限；不得在海洋内部凭空成河 |
| 城镇 | pack 陆地 cell、有限位置 | 人口、文化、国家、省份、港口、河流、适居度、名称 | cities、burgs、cell burg 索引、港口统计、标签 | 显式锁 city 对象本体；必要时仅按其自带稳定 burgId 放回 burg 槽 | 新城镇必须落在陆地有效 cell；新 ID/burgId 唯一，坐标有限 |
| 路线 | pack 邻接、水陆、至少可用的路线端点集合 | 国家、省份、港口、河流成本、旧连接、旧路线 | routes、pack route 边索引、route mesh/拾取 | 显式锁 route 对象 | 新陆路不穿海，新海路只走可导航水体，路径 cell 有效且相邻，坐标有限 |
| 国家 | pack 陆地、至少一个可用领土种子；没有城镇时允许以陆地中心降级建国 | 城镇首都、文化、人口、河流边界、名称、旧国家/省份 | state cell 归属、国家数组、边界、统计、标签 | 显式锁 state 对象 | 新国家中心为有效陆地 cell，ID 唯一；空候选时允许空国家结果而非事务错误 |
| 省份 | pack 陆地、可用国家领土；无国家时成功空结果 | 城镇省会、人口、河流边界、旧省份 | province cell 归属、省份数组、国家 province 列表、边界 | 显式锁 province 对象 | 新省份中心位于其新生成父国领土，ID 唯一；无省会候选可置 `burg=0` |
| 文化 | pack 陆地/人口评分；人口缺失可使用陆地权重 | 城镇、国家、名称、旧文化父系 | culture cell 归属、对象、覆盖统计、镜像 | 显式锁 culture 对象 | 新文化中心 cell 有效，ID 唯一；父系缺失可置根文化 |
| 宗教 | pack 陆地/人口评分；缺文化时可生成无文化偏好的宗教或空结果 | 文化、城镇、国家、省份、旧父系 | religion cell 归属、对象、覆盖统计、镜像 | 显式锁 religion 对象 | 新宗教中心 cell 有效，ID 唯一；父系/文化引用缺失可清空 |
| 标记 / 资源点 | pack 有限 cell 与地形 | 河流、生物群系、气候、政区、经济 | marker 数组、pack 镜像、资源统计、拾取 | 显式锁 marker 对象；手工标记按产品规则属于非目标对象 | 新标记 cell 有效、坐标有限、ID 唯一；分类约束只检查新对象 |
| 经济 | 至少可读取 pack cells；无城市/市场时允许空经济结果 | 城镇、国家、省份、资源点、路线、商品偏好 | goods/markets/deals、cell market、对象经济字段、统计 | 显式锁 market / trade-flow 对象分别后置合并 | 新市场中心若存在必须引用有效新/现存城镇；新交易端点、商品和路径有效且相邻；否则丢弃该新交易，不拒绝整域 |
| 外交 | 至少两个可读取的新/现存国家；不足时成功空关系 | 邻接、文化、宗教、经济、海权、旧关系 | 国家 diplomacy/campaigns、外交摘要 | 显式锁国家对关系对象 | 新关系国家 ID 存在且成对唯一；无候选是空结果 |
| 军事 | 可读取国家；无国家时成功空结果 | 人口、经济、外交、城镇、地形、单位策略 | regiment、front、campaign、统计、图标 | 显式锁 regiment 对象 | 新军团所属国家存在、位置为有效有限点；无驻地候选可省略该军团 |
| 地区 | pack cells | 战争、宗教、军事、灾害、城镇、河流 | zones、cell 列表、统计、图层 | 显式锁 zone 对象 | 新 zone 只含有效 cell，ID 唯一；attacker/defender 等软引用可清空 |
| 洋流 | 海洋 Feature、有限边界；无海洋时成功空结果 | 风场、温度、旧 basin 身份 | current 对象、采样索引、气候影响缓存 | 显式锁 current 对象 | 新路径坐标有限并位于对应海盆；无可用海盆是空结果 |

## 5. 锁语义

### 5.1 捕获

锁捕获只允许验证：

- 锁记录能解析出受支持的 `kind` 和稳定 ID；
- 当前目标对象集合中能找到同 ID 对象时，可以做结构化克隆；
- 对外交国家对、军事军团等合成身份，能从原始存储中找到对应本体。

不得在捕获阶段验证对象的 cell、父国、首都、省会、burg、市场、商品、交易端点、路径、Feature、文化/宗教父系、attacker/defender 或任何镜像。这些字段即使错误，也属于锁对象的原样 before-image。

找不到对象的锁记录视为陈旧元数据：从本次捕获中跳过，并写入开发诊断 `staleLockReferences`；不向普通界面泄漏内部结构术语。

### 5.2 生成不可见

显式锁及其引用对象不得扩张成“支撑锁”或“保护闭包”。生成器收到的候选、占用 cell、blocked edge、endpoint、数量、扩张和评分集合中不得包含锁快照。锁不会使某个 Feature、国家、省份、城市周边、道路端点或经济链整体退出生成。

### 5.3 后置合并

合并按稳定 ID 执行：先让新对象避开保留 ID，再用锁快照覆盖对应槽或追加到稀疏集合。合并不调用生成器的 `prepare*Locks`、领域 validator 或评分函数。

锁本体必须逐字段保持 before-image。cell 归属、索引和跨域镜像只在它们属于目标域且能从锁对象自身安全恢复时重建；无法恢复时宁可留空或标记陈旧，也不得修改锁本体或拒绝其它对象。

## 6. 普通生成阶段关系

普通生成没有旧目标对象和锁，因此使用同一矩阵的“空目标生成”部分。固定阶段与降级行为如下：

| 阶段 | 主要读取 | 产出 | 软失败行为 |
| --- | --- | --- | --- |
| height/grid | 选项、种子、模板 | grid 基础层 | 基础层不可读才失败 |
| features | grid 高度/邻接 | 水陆连通与岸线 | 无陆地或无海洋均可产生相应空集合 |
| climate/currents | grid、Feature、世界选项 | 温度、降水、洋流 | 无海盆时空洋流；缺风场用默认模型 |
| pack/rivers/biomes | grid、Feature、气候 | pack、水文、生物群系/人口 | 缺河流候选为空河网；人口字段缺失使用地形权重 |
| society | pack | 文化初始对象 | 无合适候选为空文化或默认根文化，不抛软关联错误 |
| settlements-initial | pack、社会偏好 | 初始城镇 | 无适居陆地为空城镇；不得生成海上城镇 |
| politics | pack、城镇偏好 | 国家、省份 | 无城镇时允许陆地中心降级或空结果；无省会候选 `burg=0` |
| settlements-finalize | 城镇、政区、pack | 港口、路线、镜像 | 无端点为空路线；单个端点不可达只跳过该连接 |
| markers/economy | pack 与可选上游 | 标记、市场、交易 | 无城市/市场/商品时产生合法空集合 |
| religions/diplomacy/military/zones | pack 与可选上游 | 各下游域 | 候选不足时合法空集合；不因软引用缺失整图失败 |

完整新图的正常输入仍应达到现有丰富度基线。降级路径只用于缺失/局部异常输入，不能以“成功为空”替代正常生成质量。

## 7. 二十二个用户入口

| 入口组 | 入口 | 目标清空与后置合并范围 | 允许的软上游 |
| --- | --- | --- | --- |
| 正式 11 类 | Feature、路线、河流、城镇、国家、省份、标记、外交、宗教、军事、地区 | 各自主域；国家/省份/城镇入口可连带重建其明确声明拥有的路线与镜像 | 领域矩阵所列全部可选偏好 |
| 复合 6 类 | 高度基础、高度下游、全部高度、气候下游、世界洋流、海底重置 | 按 stage manifest 顺序逐域清空生成并逐域后置合锁，不得把前一阶段锁扩成后一阶段限制 | 旧下游对象和跨域镜像均不是前置条件 |
| 直接 5 类 | 洋流重生成、文化扩张、宗教扩张、市场单元归属、经济链重算 | 对应 current / culture assignment / religion assignment / cell market / economy 主域 | 对象定义可保留为非目标输入；陈旧 assignment、端点和镜像先清空 |

局部城镇/省份重生成的“范围”是用户选择的目标集合，不是正确性验证。范围对象的旧父级引用若失效，应按可读取的 cell 归属或显式选择 ID 确定；仍无法确定时忽略该旧对象并从所选范围空白生成。

## 8. 最小提交硬门

| 硬门 | 检查对象 | 失败码族 |
| --- | --- | --- |
| 基础容器可读 | 本入口实际使用的 grid/pack `i/h/p/c`、地图边界 | `regeneration_base_structure_invalid` |
| 稳定身份可提交 | 新生成未锁对象 ID 合法且域内唯一；锁合并后无重复槽 | `regeneration_identity_conflict` |
| 有限几何 | 新生成点、线、控制点坐标为有限数 | `regeneration_geometry_invalid` |
| 新城镇陆地 | 新生成未锁城镇落在有效陆地 pack cell | `city_regeneration_water_anchor` |
| 新路线物理/邻接 | 新陆路不穿海、新海路不穿陆，连续 cell 相邻 | `route_regeneration_path_invalid` |
| 新河流水文 | 新河流路径有效、陆地主体连续，不在海洋内部凭空延伸 | `river_regeneration_path_invalid` |
| 补丁与事务 | 写集、owner、revision、绑定、取消/过期、单历史、原子回滚 | 保持现有 engine / worker 协议错误码 |
| 锁 before-image | 找得到的显式锁对象本体逐字段未改 | `locked_object_removed` / `locked_snapshot_changed` |

以下项目明确不是全图提交硬门：镜像完全相等、首都/省会存在、父国/父文化/父宗教存在、国家/省份拥有非空领土、所有路线/河流/交易都可达、所有 cell 反向索引完整、统计立即一致、下游派生全部 fresh。它们由目标域局部重建、过滤、置空、陈旧标记或后续显式重生成处理。

## 9. 实现状态（第 365 项）

| 位置 | 已落实行为 | 固定边界 |
| --- | --- | --- |
| `runtime/regeneration-lock-protection.js` | 锁捕获只按稳定 kind / ID 找到并克隆对象本体；对象内部水陆、父级、路径、镜像和经济引用不在捕获阶段验证 | 陈旧锁记录忽略并进入诊断，不阻塞重生成 |
| `runtime/regeneration-lock-priority.js` | priority bundle 不再扩张跨域支撑闭包，显式快照是唯一锁输入 | 生成器看不到锁对象或其支撑对象 |
| `runtime/regeneration-constraint-bundle.js` | 分域保存显式 before-image，生成后按稳定身份恢复并只断言锁本体 | 锁后置合并不重复执行生成限制 |
| `runtime/regeneration-worker-task.js` | 十二类 Worker 入口先隐藏锁与旧目标，完成空白生成后恢复锁；全部锁定也正常执行空白生成流程 | 只保留写集、绑定、基础物理 / 结构和事务硬门 |
| 高度、气候、洋流世界 Worker | patch / replacement history 在 Worker 内捕获，复合阶段沿 manifest 顺序逐域清空生成并后置合锁 | 主线程不再承担 100k 地图历史深克隆，不放宽 owner / revision |
| `generator/settlements.js` | 路线寻路把零适居度陆地视为高代价而非不可通行，避免合法山地大陆整片被排除 | 新陆路仍不得穿海，路径必须邻接 |
| 普通生成器 | 政治、社会、经济、战争等软输入缺失时使用空集合、局部推导或逐对象跳过 | 正常 10k / 50k / 100k 丰富度必须保持，不得以大量空域换容错 |
| 四域 Worker validator | 只检查本次写集触及的对象和本文硬门；旧 source 中未触及的软错误不再反向否决操作 | 新写对象的有限几何、身份、边界和物理门仍严格 |
| 社会扩张与经济直接入口 | 扩张生成阶段隐藏锁，完成后恢复；经济 validator 只验证被 patch 触及的 market / deal | 指定存档的陈旧市场中心不再阻止单元归属或经济重算 |
| 洋流直接入口 | 纳入通用 Worker 重生成、写集、历史和基础几何校验 | 无海盆允许空结果；正常指定存档必须生成有效洋流 |

## 10. 验证要求

实现必须同时提供：

1. 确定性破损矩阵：空目标、截断数组、删除对象、陈旧父级、镜像冲突、非法旧路径、合法/内部错误锁、陈旧锁记录、基础容器损坏。
2. 对每类证明：旧错误未锁对象被丢弃；锁在生成输入中不可见；新对象按空白逻辑生成；锁后置逐字段原样；软错误不阻塞；硬错误精确回滚。
3. 普通生成基线：10k/50k/100k 正常地图的对象丰富度不低于既有确定性夹具允许范围，基础物理硬门为零失败。
4. 唯一指定存档 `krichars (3).webfmg` 的 production UI 终验：22/22 入口逐项核对结果数量、地理覆盖、基础硬门、锁 before-image、单历史、撤销/重做、Loading、console 与 WebGL。随机图不能替代该证据。
