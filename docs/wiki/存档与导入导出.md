# 存档与导入导出

完整地图格式为 `webgl-generator-map` v2，保存生成选项、Grid / Pack、对象、视觉配置、标签、备注、测量、锁定及派生状态。typed array 使用可恢复编码。可以导出普通 JSON 或 gzip 压缩文件，也可以保存到浏览器本地存储。

导入统一执行格式验证、版本迁移和兼容归一化。旧图迁移不应静默改变人口、地形、疆域或行政归属；需要改变事实的操作必须由用户显式执行。

GeoJSON 导出分 Cells GEO 与 Feature GEO；政治面可 dissolve，路线 / 河流有稳定字段字典。PNG 导出读取当前画面和选定 overlay；高度灰度 PNG 固定读取完整世界的 `grid.cells.h` 与 Grid Voronoi，0～100 映射 0～255，不受相机、主题和图层影响。

无头 CLI 可直接读取 `.json` 和 `.json.gz`，模块入口还接受 gzip-base64。无头读取从不覆盖输入文件。
