# 界面与基础操作

正式应用以地图画布为中心，常用动作留在左上工具栏，项目设置和领域管理通过浮动面板按需打开。理解“查看、选择、编辑”三种状态的区别，可以避免大多数误操作。

## 地图画布与相机

**入口**：页面中央的 WebGL 地图画布，以及左上工具栏的“适配视图”。

**用途**：浏览世界、缩放到局部、拾取对象，并观察专题、图层和编辑预览。

**关键操作**：

- 在地图上拖动和平移、使用滚轮缩放；需要重新看到整张地图时点击“适配视图”。
- 移动指针查看悬停信息。信息卡会按当前专题显示地形、气候、政治或对象摘要。
- 点击可拾取对象建立当前选择；选择后可出现对象详情、地图高亮或对应面板状态。
- 信息卡右上角的“查看全部快捷键”可展开文件、编辑历史、视图图层和面板快捷键。

**结果与副作用**：平移、缩放、悬停和普通选择不修改地图数据，也不进入撤销历史。相机状态影响“当前视口”导出范围，但不改变地图全幅。

**常见误区**：高亮只说明当前目标或预览范围；它不是已经应用的修改。闪烁定位是短暂反馈，不应作为对象是否存在的唯一判断。

## 全局工具栏

**入口**：地图左上角。工具栏可收起到窗口边缘，再通过边缘箭头展开。

- **控制面板**：打开项目、生成、视图、样式、图层、管理和单位七个页签。
- **适配视图**：将完整地图放回当前可视区域，只调整相机。
- **测量**：进入测量绘制流程。测量结果保存后进入“管理 → 测量对象”。
- **开发模式**：普通情况下隐藏，仅在明确启用调试后显示；它不属于日常制图流程。

工具栏的收起状态属于界面偏好，可跨刷新恢复。收起工具栏不会停止当前编辑模式；若要退出当前操作，应使用 `Esc` 或面板中的取消 / 停止按钮。

## 控制面板

**入口**：`工具栏 → 控制面板`。

控制面板的七个页签各有明确职责：

- **简介**：项目说明、本地保存、浏览器保存、云端存储、导入和导出。
- **生成**：地图名称、存档名称格式、种子、规模、尺寸、地形与高级气候。
- **视图**：视觉主题和十二类专题视图。
- **样式**：六类语义标签的字体、字重、颜色、描边、阴影和透明度。
- **图层**：地形水文、政治边界、地图对象、地区和标注辅助的独立显隐。
- **管理**：打开各领域面板，并执行有影响说明的受约束重新生成。
- **单位**：数字缩写、距离 / 面积单位、地图比例以及人口、军事和降水显示倍率。

切换页签只改变面板内容，不修改地图。浏览器会记住最后使用的页签和部分显示偏好。

## 浮动面板与对象表格

**入口**：控制面板“管理”页签、对象详情中的“打开对应面板”，或已登记的键盘快捷键。

**用途**：查看一个领域的统计、列表和详情，并执行该领域允许的编辑。

**关键操作**：

- 拖动面板标题栏调整位置；标题栏右侧提供撤销、重做和关闭。
- 多数对象表格支持文字筛选、排序、逐行选择、定位、列宽调整和批量选择。
- 逐行准星按钮用于定位；部分面板允许双击进入编辑，具体以按钮和二级编辑区为准。
- 对象下方的图标动作会展开重命名、颜色、备注、属性等二级编辑区；关闭二级区不会撤销已经应用的命令。
- 打开新的主领域面板时，界面会整理主面板关系；对象详情可作为辅助详情与主面板共存。

**结果、历史与持久化**：列表筛选、排序、列宽、面板位置和展开状态属于界面状态，通常不进入地图撤销历史；实际对象修改通过统一编辑命令进入历史。部分列表和面板偏好会保存在当前浏览器中。

**常见误区**：筛选为空只表示没有匹配行，不代表地图没有对象；可使用空态中的“清空筛选”恢复列表。表格复选框用于当前列表批量操作，不等同于地图上的唯一对象选择。

## 选择、定位、编辑和预览

这四种状态应分开理解：

1. **选择**保存当前对象，驱动详情和面板上下文。
2. **定位**移动相机并给出高亮，通常不改变对象。
3. **编辑模式**让后续地图点击或拖动成为画笔、放置、移动、改线等输入。
4. **预览 / 预检**显示候选范围、影响摘要或拒绝原因；只有点击明确的“应用”“确认”或“执行”后才提交地图命令。

`Esc` 会逐级退出当前弹出菜单、二级编辑、预览或编辑模式；它不会凭空撤销已经提交的地图命令。已提交修改使用标题栏撤销按钮或 `Ctrl+Z`，重做使用 `Ctrl+Shift+Z` / `Ctrl+Y`。

## 常见快捷键

- `Ctrl+S`：保存到浏览器。
- `Ctrl+Shift+E`：导出 PNG。
- `Shift+Home`：适配地图视图。
- `Shift+1 / 2 / 3 / 4`：高度、生物群系、外交、国家专题。
- `Shift+5 / 6 / 7`：切换道路、河流、城市图层。
- `Shift+G`：打开控制面板。
- `Shift+H / S / C / D / M / R / L / Q`：打开高度、国家、城市、外交、军事、河流、标签、测量对象面板。

在文本框、下拉菜单或独占弹层中，快捷键会让位给输入操作。将指针停在已登记的按钮上，也可看到延迟出现的快捷提示。
