# 教程：让两个大陆的高山区更自然

分别选中两个大陆的山地，记录海平面、主要山脊、盆地、山口、河源与沿海边界。用坡度 P90、粗糙度 P90、abruptCells 和 roughCells 判断问题是孤立尖刺还是整条山脉落差。

不要把所有山峰一起压低。优先削弱孤立突变、扩大丘陵—山地—高峰过渡带、限制相邻最大高度差，同时保持峰谷排序、分水岭连通和相对 relief。诊断会给出 slope / roughness P90 建议目标，但它只是验收口径。

实际执行优先走高度选区平滑、范围变换或地形程序的 inspector。修改后重建必要派生，并检查海陆、河流、湖泊、路线、城市和政治边界；最后在真实画面确认山脊仍清晰、梯度更连续且没有新断河或淹没陆地。
