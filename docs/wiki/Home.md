# WebGL 幻想地图生成器

WebGL 幻想地图生成器是一款从头实现的 WebGL2 幻想世界地图工具。它参考 Fantasy Map Generator 的生成流程、数据结构和地图表达，但正式应用、编辑器、存档与 API 均属于本项目自己的实现。

![固定山海地图与左上全局工具栏](assets/01-主界面与地图.png)

*图：主界面显示地图画布，以及控制面板、适配视图、测量和工具栏收起入口。*

## 可以用它做什么

- 从种子、地图规模、画布尺寸、地形模板和气候参数生成一张完整世界地图。
- 用高度、温度、降水、生物群系、文化、宗教、外交、政体、国家、省份、地区和人口等专题观察同一份地图数据。
- 管理地形、水体、河流、湖泊、洋流、国家、省份、城市、文化、宗教、道路、经济、外交、军事、地区、标记、标签、备注和测量对象。
- 通过选择、定位、高亮、预检、确认、撤销和重做完成可追踪的编辑；对重新生成对象使用锁定保护。
- 保存完整地图，在浏览器中保留临时存档，或导出图片、高度灰度图、GeoJSON、备注和测量数据。
- 通过浏览器 API、无头运行时和当前标签页受控桥进行分析与自动化，同时保留确认、版本检查和事务边界。
