# 安装与快速开始

要求 Node.js `^20.19.0` 或 `>=22.12.0`、pnpm 10 和支持 WebGL2 的现代浏览器。

```powershell
pnpm install
pnpm run start:app
```

按终端输出打开本地地址。应用完成加载后可新建地图、恢复浏览器保存或导入完整地图文件。Windows 机器的 `5109～5208` 端口可能被系统排除，项目 profiling 历史上使用 `5300`；普通 Vite 启动以实际输出端口为准。

首次进入建议依次：生成地图 → 适配视图 → 在控制面板切换图层 → 点击地图查看对象详情 → 打开领域管理面板 → 导出一份完整地图。开发模式只显示调试入口，不决定普通 API 是否存在。

生产构建：

```powershell
pnpm run build:app
pnpm run preview:app
```

`source/Fantasy-Map-Generator` 只是参考实现，不是正式应用，也不应被修改。
