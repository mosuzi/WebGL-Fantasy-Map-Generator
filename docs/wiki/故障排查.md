# 故障排查

- 页面无法启动：确认 Node / pnpm 版本、依赖安装与 Vite 实际端口；Windows 排除端口时换用允许的端口。
- 地图文件拒绝：查看结构化导入诊断，确认 type、version、map 和 typed array 编码；高于当前版本的文件不能强行降级。
- API 方法不存在：调用 `info.capabilities` 和 `info.describe`，不要使用 README 或旧日志猜方法名。
- 开发模式关闭后找不到 API：API 仍在 `window.webglGeneratorApi`；开发模式仅隐藏 UI。若根对象不存在，检查页面是否完成加载及 console error。
- 分析结果为空：确认使用 Pack / Grid 正确空间、对象 id 和区域交集；检查存档是否缺少相应派生数据。
- 修改后结果不一致：检查 history、revision、checksum、`derivedStale.systems` 和 regeneration locks；需要时撤销并重新预检。
- 画面与数据不一致：数据查询不能替代浏览器视觉验收；检查图层显隐、相机、标签 LOD、WebGL error 和 health events。
- Wiki 内容陈旧：在主仓库运行 `pnpm run audit:wiki` 与 `pnpm run audit:ai-docs`。
