# 教程：让高山无人区北侧平原追平南侧国力

找到自动无人区和两侧平原，把北 / 南平原分别与目标国家求交集，避免混入邻国。比较两侧面积、每 cell 人口、降水、宜居度、坡度、城市和路线，再用透明 powerScore 估计差距。

按自然承载、山口 / 路线、城市锚点、政治安全、人口分布的顺序找瓶颈。北侧自然条件接近但没有路线和城市时，应先建立网络；若自然条件显著差，直接灌人口会造成承载矛盾。

推荐目标是北侧 power ratio 达到南侧的 0.9～1.1、每 cell 人口同量级并具有可达城市锚点。高山无人区仍保持低人口屏障，政权疆域不变，南侧不因转移被抽空。powerScore 不是正式军事国力，最后还要检查市场、经济、军事和外交对象。
