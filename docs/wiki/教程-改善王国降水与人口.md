# 教程：在保留疆域和山地时改善降水与人口

以晴布赫斯王国为例，先记录不能改变的疆域、西部高山和南部丘陵。查询国家 id 后，将全境拆成核心平原、高山、丘陵和上风侧对照区；查看各区降水、海拔、坡度、宜居度、人口、城市和路线。

如果上风侧湿、连续山地屏障明显、核心平原干，雨影解释才较可靠；南部丘陵是否阻挡水汽取决于风向。若降水尚可但人口低且缺城市 / 路线，优先改善交通与聚落，而不是改气候。若降水、宜居度都低，再评估小幅气候参数或保持山脊关系的局部地形方案。

验收时疆域 cells 不变，西山南丘的相对高度不变，核心平原降水 P50、宜居度与人口承载改善。直接增加人口不能单独算成功。实际编辑前用公开 inspector，并在执行后重查人口、路线、城市、派生过期和画面。
