# 编辑器与安全修改

地图编辑不是直接改一组内部字段。正式界面把操作统一组织为“选择目标 → 预览或预检 → 执行命令 → 刷新派生内容 → 撤销 / 重做 → 保存回读”。这样做的目的，是让高度、疆域、人口、路线等互相依赖的系统在失败时能够完整回滚。

*图：高度编辑已启用，地图上的黄色高亮是已涂选的平滑范围；尚未应用，所以地图数据与历史不变。*

## 选择、定位与领域面板

点击地图对象会更新统一 selection。若对应领域面板已经打开，列表与详情会同步到该对象；面板未打开时，对象详情承担只读摘要和“打开领域面板”的跳转。列表中的“定位”会把相机移到对象范围并短暂高亮，不会修改地图。

各领域管理页共享以下操作习惯：

| 操作 | 结果 | 是否写地图 |
|---|---|---:|
| 筛选、排序、调整列宽 | 只改变当前列表的查看方式 | 否 |
| 单击行 | 选择对象并更新详情 | 否 |
| 定位 | 调整相机并高亮对象 | 否 |
| 锁定 | 把可重生成对象加入保护清单 | 是 |
| 重命名、改色、改属性 | 形成一条领域编辑历史 | 是 |
| 新增、删除、合并、拆分或迁移 | 先检查规则与影响，再形成一条事务历史 | 是 |

表格勾选框用于当前列表的多选操作，不等同于地图上的单一 selection。锁定多选还可以切到地图连续选择模式；退出模式后，列表与地图高亮会同步收束。

## 画布工具模式

画笔、两点连线、放置、移动和连续采点由统一画布模式管理。任一时刻只有一个编辑模式可以占用画布；进入另一个模式、关闭面板、按 `Esc`、换图或发生异常时，未提交预览会被清理。

常见模式包括：

- 高度、生物群系、适居度、国家、省份、文化和宗教的范围画笔；
- 新增、删除或移动国家、省份和城市；
- 绘制路线、添加河源、开挖湖泊、编辑水体拓扑；
- 放置地区、资源 / 通用标记和独立备注；
- 绘制与编辑测量路径；
- 在地图上选择重生成锁对象。

地图光标的圆、矩形、线段或控制点只是预览。只有面板明确显示成功、历史计数增加或对象列表变化，才表示写入已经发生。

## 预览、预检与确认

“预览”主要回答最终画面和影响范围是什么；“预检”还会返回稳定的拒绝原因、警告、受影响对象、是否需要确认，以及执行时必须匹配的 token 或 revision。两者都不应写入地图。

高影响动作通常包括删除国家 / 省份 / 城市、政治合并拆分、跨区域迁移、整图或局部重生成、地形跨海平面修改和完整地图导入。执行前应逐项确认：

1. 目标对象、cell 范围和当前地图 revision 是否仍与预检一致。
2. 会被替换、级联删除或重新归属的对象是否符合预期。
3. 是否存在锁定对象、受保护路线、城市或海岸对象冲突。
4. 操作完成后哪些派生系统会被立即更新，哪些只会标记为待更新。
5. 是否能够撤销；不能进入普通历史的换图操作，应先另存完整地图。

拒绝不是部分成功。领域命令在中途失败时应恢复对象、索引、派生标记和历史；不要看到部分画面变化就重复点击。

## 撤销与重做

浮动领域面板和主界面提供统一撤销 / 重做。一次画笔 stroke、一次批量删除或一次规则事务只形成一条历史；预览、筛选、定位和取消不进入历史。

撤销后需要同时检查对象数据和画面。如果命令涉及路线、河流、边界、标签或人口点，运行时会按命令的 `effects` 刷新相应 renderer buffer、overlay、对象面板和 picking 索引。换入另一张完整地图会清空旧历史，避免把旧文档命令应用到新文档。

## 重生成锁

重生成锁保护“对象身份及其关键引用”，适合国家、省份、城市、河流、路线、文化、宗教、地区、军事等会被生成器替换的对象。锁定入口出现在支持该能力的对象表格和控制面板管理页。

![国家专题地图与国家编辑面板](assets/06-政治与聚落.png)

*图：国家编辑面板显示国家统计、筛选、锁定、定位和对象列表；画布显示国家与省份名称。*

锁定不会自动保护任意 Grid / Pack cell 的高度、人口或所有跨领域派生。要保持某条山脊、海岸或区域人口，仍需显式冻结 cell 范围、对象集合和验收指标。若锁与目标重生成无法同时满足，操作应拒绝并说明冲突，而不是静默丢锁。

## 派生内容与更新顺序

状态栏或领域面板会显示待更新的派生系统。典型依赖如下：

- 高度改变可能影响陆水、岸线、水文、路线成本、生物群系、适居度和人口承载。
- 气候改变会重算温度、降水、生物群系与承载，并可能让人口、经济等统计需要复核。
- 国家、省份或城市改变会影响标签、路线、市场、外交、军事和地区上下文。
- 人口改变会同步农村 / 城市人口、行政聚合、人口点与市场需求摘要。

复杂修改宜按“有限地形 → 地理派生 → 气候 → 人口 / 政治 / 经济事务”执行。每个阶段都先保存或记录新基线，再进入下一阶段。需要在气候或地理重算中保持现有人口时，使用明确支持 `preservePopulation` 的正式入口；它不会自动证明其它 stale 系统已经正确。

## 安全编辑检查表

编辑前：

- 另存一份 `.webfmg`，记录地图名称和目标范围。
- 切到最能显示目标事实的专题，打开必要图层。
- 选中并锁定必须保持的对象；记录海陆、疆域、人口、路线和关键统计。

编辑中：

- 先预览 / 预检，小范围试做；阅读警告和拒绝原因。
- 避免同时打开多个相互竞争的画布模式。
- 每次成功后检查状态提示和历史，不用重复点击补偿未知状态。

编辑后：

- 用同一专题、图层和相机比较目标区与对照区。
- 检查历史、`derivedStale`、锁和受影响对象。
- 导出新文件并重新加载，确认视觉、对象和聚合统计仍一致。

自动化调用的同一套安全边界见 [API 与自动化](API与自动化)，完整文件保护与格式说明见 [存档与导入导出](存档与导入导出)。
