# 编辑器与安全修改

地图编辑统一遵守“预检 → 审阅 → 执行 → 验证”。危险操作会返回影响对象、警告、确认要求和拒绝原因；成功操作进入撤销 / 重做历史，失败必须原子回滚。

再生成锁可以保护国家、省份、城市、河流、路线、文化、宗教等稳定对象，但不等于自动保护所有 cell 高度或人口。编辑前同时记录目标 cells、对象锁、疆域、城市、路线和派生系统。

常见编辑器包括高度、人口、生物群系、国家、省份、城市、文化、宗教、河流、湖泊、路线、地区、经济、军事、外交、标签、标记、备注、测量和名称库。管理列表支持筛选、排序、定位、选中与双击进入编辑；对象详情是选择兜底入口。

API 写入不要直接改内部 map。先通过 `info.describe` 读取 schema 和副作用，再调用同领域 `inspect*` 与执行方法；高影响动作显式 confirm。无头只读 API 不写地图；独立无头写会话只开放人口调整、高度选区平滑和对象重命名的六个 inspect / apply 方法，默认写入新文件并要求 documentId、revision、inspectionToken 与 requestId。

跨领域修复的安全顺序通常是“有限地形修改 → 地理派生重建 → 气候调整 → 人口或政治事务”。可能重生成路线、河流、城市等对象时，先用再生成锁保护必须保持的对象，阶段完成后逐项验证并解除本次锁。气候与少数地理派生重算可显式保留当前人口，但仍需检查适居度、行政聚合和派生过期状态。

最终验收必须包含新存档回读。重复加载不能覆盖保存人口或累加未归属人口；视觉任务要关闭开发面板，以相同相机、主题和图层比较全图与目标局部。
