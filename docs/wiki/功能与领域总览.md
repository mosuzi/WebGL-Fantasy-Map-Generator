# 功能与领域总览

正式应用把能力分为控制面板中的项目与显示设置，以及“管理”页签中的五组领域面板。领域面板通常包含统计摘要、筛选、排序、对象表格、定位、详情和编辑动作；具体按钮会随当前选择和地图状态启用。

## 领域手册入口

- [地形、水体与水文](地形水体与水文)：高度、水体、河流、湖泊和洋流。
- [气候、生态与人口](气候生态与人口)：气候统计、生物群系、适居度和人口。
- [政治、社会与聚落](政治社会与聚落)：国家、省份、城市、政体、文化和宗教。
- [路线、经济、外交与军事](路线经济外交与军事)：路线、商品、市场、交易、关系和军团。
- [地区、标注与测量](地区标注与测量)：地区、标记、标签、备注、测量和名称库。

## 项目、生成与显示

- **项目文件**：入口在“控制面板 → 简介”。可保存到本地或浏览器、打开云端存储、导入完整地图或 GEO 数据，并进入快速 / 高级导出。完整地图导入会替换当前地图，应先保存未提交的工作。详见[存档与导入导出](存档与导入导出)。
- **地图生成**：入口在“控制面板 → 生成”。地图名称、种子、规模、尺寸、地形模板和高级气候共同决定新地图；生成会替换当前世界并建立新的编辑基线。详见[地图生成与项目设置](地图生成与项目设置)。
- **专题、样式、图层与单位**：入口分别在“视图”“样式”“图层”“单位”。这些设置主要改变地图的呈现、标签和数值换算，不等于修改地理对象。详见[专题图层与视觉样式](专题图层与视觉样式)。

## 地形环境

入口：`控制面板 → 管理 → 地形环境`。

- **高度编辑**：使用抬升、降低、画笔大小、强度和所选范围平滑塑造地形；普通模式还可预览重设海底。调试模式保留条件变换、全局平滑 / 扰动、复杂锁定选区、地形模板 / 程序和高度图导入等兼容入口。高度变化会让水文、生态、聚落或政治等派生内容进入待更新状态；完成后应执行“完成编辑并更新地图”。不要把高度专题的颜色变化误认为所有下游对象已经自动重建。
- **气候统计**：按温度带查看温度、降水、干湿陆地和大气摘要，并可先查看受气候影响内容的更新范围。气候源参数位于“生成 → 高级气候”；应用气候变化会重算直接气候结果，并提示后续世界内容是否待更新。详见[气候、生态与人口](气候生态与人口)。
- **生物群系**：查看各生物群系的面积、适居度、人口和城市覆盖，可用归属画笔或适居度工具作局部调整。应用会同步相关统计并标记依赖系统；水域不会因此获得人口承载。
- **水体与地貌**：查看海洋、湖泊、岛屿、岸线、港湾和引用异常；海岸编辑可雕刻 / 填补海岸、开闭海峡或连接湖海。应用前会检查水陆连通和受保护对象，并形成一条可撤销历史。
- **河流管理**：筛选、定位、重命名和调整河流宽度，或重新生成河流。重新生成会替换河网并影响水文引用，不是单纯的显示刷新。
- **洋流管理**：查看冷暖洋流、定位与高亮，既可只重新计算洋流，也可重算气候与世界。后一项影响更广且可能耗时，应先阅读范围说明。
- **湖泊管理**：查看湖泊统计，安全填平湖泊、修改真实河流出口，或在小范围扩展湖水 / 收回湖岸。出口和岸线修改均先预检再应用。

## 政治社会

入口：`控制面板 → 管理 → 政治社会`。

- **国家编辑**：查看国家面积、人口、首都和政体；可改名、配色、政体 / 国号和首都，或使用归属画笔。合并、拆分和领土变更必须先预检；重新生成国家会重建政治归属及相关下游内容。
- **政体管理**：按政体家族汇总国家，可为单个国家或当前分组套用政体，并跳转国家编辑或外交视角。政体变更会改变国家语义和国号，不只是表格分类。
- **省份管理**：筛选、定位、改名、配色、增加 / 删除省份并调整同国归属；可预览省会重评。重新生成省份受现有国家边界约束，并可能重建道路等派生内容。
- **城市管理**：查看城市、首都、省会、港口、人口和归属；可改名、改人口、选择城市剪影 / 配色、新增、移动或删除，并在安全条件满足时同步归属到所在地图单元。城市编辑会同步城市与底层聚落实体，并进入编辑历史。
- **人口统计**：按国家、省份、文化或宗教观察城乡人口；可对一个区域做增减，或在两个区域间转移人口。两种操作都先预检再确认，并会刷新承载、市场需求及相关统计。
- **文化管理**：查看覆盖、人口、城市和跨国家分布，编辑名称、颜色、继承父级、中心与扩张，或用画笔调整归属。树状总览用于理解继承关系；删除非空文化会处理关联对象，不能当作隐藏操作。
- **宗教管理**：查看覆盖、人口、文化和国家交叉关系，编辑名称、颜色、继承、中心、扩张与归属。树状总览和删除边界与文化相似，但作用于宗教字段。
- **外交管理**：选择一个国家查看双边关系、关系影响和外交历史，可切换外交着色并进入关系编辑。宣战、议和、附庸关系等操作会改变战争与关系记录，应按预检结果确认。

## 网络经济

入口：`控制面板 → 管理 → 网络经济`。

- **经济总览**：在商品、市场和交易三类视图之间切换，按国家、行政区域、市场、商品、买卖方筛选交易。市场页可调整市场归属并重算经济链；重算会更新供需、运距和价格压力，不会启动动态贸易动画。
- **军事管理**：按国家、态势和军团筛选，查看兵力、驻地、基地和兵种比例；可调整态势、位置、名称和比例。高级战报档案与轻量结算默认收起；项目不提供自动战役推进或动态军事 AI。
- **路线管理**：管理道路、小路和海路，可创建、删除、重算道路、调整类型 / 等级、端点和改线点。预检会检查陆路 / 水路地形与拓扑，应用后同步长度、picking 和导出数据。

## 标注对象

入口：`控制面板 → 管理 → 标注对象`。

- **地区管理**：创建事件、自然、自定义等地区，查看纹理含义，设置颜色、纹理、说明、覆盖方式及宜居度、通行、经济、防守影响。重新生成只替换未锁定的自动地区；图层页的“全部地区”只是批量显示开关。
- **资源点与通用标记**：在资源点和通用标记之间切换，新增、移动、删除并调整图形与配色。重新生成资源点不会删除手工标记；不要把资源和普通标记混为同一种生成对象。
- **标签管理**：管理国家、省份、城市和手工标签的文字、备注、显示优先级、隐藏状态与位置锁定。优先级参与碰撞筛选，不保证所有冲突标签同时显示。
- **备注总览**：集中筛选、导入、导出、定位、重命名和编辑对象备注及独立备注。孤儿备注仍可保留和导出，但原对象不存在时不能定位。
- **测量对象**：管理已保存的尺、路线、曲线和面积，支持定位、重命名、导出和删除。绘制入口在地图工具栏“测量”，这里负责保存后的对象管理。

## 系统工具

入口：`控制面板 → 管理 → 系统工具 → 名称库`。

名称库用于查看内置和用户名称样本、生成预览、导入 / 导出、复制、编辑参数，并绑定全局或文化命名来源。绑定名称库本身不会自动改写已有名称；只有明确执行按名称库重命名或替换时才会修改对象，并应先看预检范围。

## 所有领域共享的操作规则

- 点击表格行通常只选择对象；“定位”才会移动相机并高亮目标，双击是否进入编辑取决于具体面板。
- 多数列表支持筛选、排序、列宽调整和批量选择。筛选改变的是当前列表范围，不会删除未显示对象。
- 面板标题栏的撤销 / 重做对应地图编辑历史。视图、图层、筛选和面板位置等界面状态不一定进入地图历史。
- 删除、重新生成、合并、拆分、批量覆盖和其它高影响动作会显示范围或要求确认。保护对象时使用重生成锁定，而不是依赖当前选择或图层隐藏。
- 对象详情负责摘要、定位和跳转；全量列表、统计和批量管理仍在对应领域面板。

编辑前建议继续阅读[界面与基础操作](界面与基础操作)和[编辑器与安全修改](编辑器与安全修改)。需要理解字段、单位与聚合口径时阅读[地图数据与区域分析](地图数据与区域分析)。
