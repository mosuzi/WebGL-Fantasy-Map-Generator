# 功能与领域总览

## 自然世界

- 高度与地貌：Grid 高度、海平面、选区笔刷、范围变换、平滑、地形模板、海床重置及派生重建。
- 气候：纬度、经度范围、温度、降水比例、风带、大气与生物群系。
- 水文：河流、流域、汇流、湖泊、溢流和海洋洋流。
- 地区：事件地区、自然 / 自定义地区、自动无人区、底区 / 覆盖区与基础影响。

## 人文世界

- 人口与城市：农村 / 城市人口、城市规模与图标、首都 / 省会、迁移与转移。
- 政治与社会：国家、省份、文化、宗教、政体、外交和再生成锁定。
- 网络与经济：道路 / 海路、市场、商品、贸易流和经济派生。
- 军事：军团、驻地、状态、战斗和战区。
- 表达对象：标签、纹章、标记、备注、测量对象、名称库和视觉主题。

## 编辑和导出

各领域面板提供筛选、排序、定位、双击编辑和对象详情。修改统一进入可撤销历史；高影响动作先预检并确认。导出包括完整 JSON、gzip、Cells / Feature GeoJSON、当前画面 PNG、高度灰度 PNG、备注和测量对象。

完整 API 当前为 17 个浏览器命名空间、316 个方法；无头第一阶段另有 23 个严格只读方法。机器目录由主仓库 `pnpm run sync:ai-docs` 生成。
