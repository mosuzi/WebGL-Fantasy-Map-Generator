# 气候与降水

降水不是独立颜色层。它与纬度、温度、大气风带、海陆分布和地形屏障共同形成；山脉可能产生迎风 / 背风差异，但必须结合主导风向和两侧对照才能判断雨影。

控制面板的气候能力可读取整体气候、选项、温度、降水、纬度、大气和生物群系，并修改全局参数。修改气候参数后，下游生物群系、人口承载等可能过期，需要先运行重建预检，再执行明确的下游重建。

分析某个国家时，先用国家区域得到全境，再拆为高山、丘陵、核心平原和上风侧对照区。至少比较降水均值 / P10 / P50 / P90、海拔、坡度、宜居度与人口。低降水和高山共现只是线索，不能省略风向验证。

API：浏览器用 `climate.get*` 和 `climate.inspectDownstreamRebuild`；无头用 `climate.get`、`analysis.explainPrecipitation`。开发模式不会让普通气候 API 返回更多地图事实。
