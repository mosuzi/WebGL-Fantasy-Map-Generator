# 地图数据与区域分析

地图有 Grid 和 Pack 两层 cell。Grid 是基础生成网格，保存高度、温度、降水和 Voronoi 几何；Pack 是政治、人口、城市、路线及大多数业务对象使用的网格。两种 id 不可混用，Pack 的 `g` 字段映射回 Grid。

高度是 0～100 模型值，20 为海平面；坡度诊断使用相邻高度差，不是现实角度。人口由农村 cell 人口与城市人口组成。宜居度是人口承载输入之一，不等于最终人口。

无头区域可按 cells、国家、省份、地区、全部陆地以及交 / 并 / 差定义。分析返回样本数、均值、P10 / P50 / P90、城乡人口、城市、路线、政治归属和证据 cell。比较不同面积区域时必须同时看总量和每 cell 指标。

国力比较的 `powerScore` 是透明代理，组成包括人口、城市、路线和宜居度，仅用于方案比较；正式经济、军事和外交结论仍以各领域对象和规则为准。

处理“保持基本地理关系但改善局部结果”的任务时，先定义目标区、可比对照区和保护区，再固定 count、均值、分位数、对象集合和允许漂移。地形自然化分别检查每处山地的坡度、粗糙度、尖峰和山脊；跨山发展差距同时比较总量、每 cell 人口、城市、路线和代理分数。任何结论都应区分直接事实、空间共现与仍待验证的因果。

实际修改按“地形 → 地理派生 → 气候 → 人口 / 社会事务”排序，每一层完成后重新冻结基线。最终还要重新加载导出的存档，并用相同相机补全全图与局部 before/after；开发面板遮挡的截图不能作为地图验收证据。
